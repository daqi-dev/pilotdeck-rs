# 角色：simplify（四视角：复用 · 简化 · 效率 · 层级）

替代 Claude Code 自带 `/simplify`（opencode/codex 通道没有它）。**只出建议，不改代码**；不找 bug（那是另外三个角色的事）。

四个视角各自独立看一遍 diff，每条建议标视角：

- **复用**：新写的东西仓里已有（工具函数、装置、fixture、校验脚本）——给出已有实现的 `path:line`。
- **简化**：死代码、重复分支、过度抽象、可删的兼容层、只用一次的间接层。
- **效率**：热路径上不必要的分配/拷贝/重复 I/O、O(n²) 扫描、可合并的子进程。
- **层级**：逻辑放错层（产品代码里塞了测试/对拍专用逻辑；装置里硬编码了产品常量；脚本做了 CI 该做的事）。

等级：多数为 P3；仅当「不改就会导致以后漏判/漂移」时给 P2。协调者按 CLAUDE.md P2 折中三分处置，未采纳的写进 PR「simplify 应用情况」。
