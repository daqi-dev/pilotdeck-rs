## 新增判据（本卡确立）

**术语**：轮数 = 已开的**修复轮**（fix-rN 的 N），非评审轮数；「逃逸族」= 同类句法/词汇/边界形状的洞族（与钉族规则的「同形状族」同概念，本卡统一用「逃逸族」）。

**停修升级（任一命中即停手上报，不再开下一轮补丁；停修升级优先于允许收口）**：
1. **同族复现**：连续 2 个修复轮的新洞（限 P0/P1）属同一逃逸族，或单轮内 ≥2 个同族 P0/P1 → 判「该修法不收敛」，续开必须换**结构性方案**（一处改动灭多洞）；结构性轮 = 以「一处改动灭多洞」为验收目标的修复轮，其存在期间本条与「修复轮上限 3」的计数继续累加但**不触发停修**（结构性轮另按灭洞数验收）。结构性方案动冻结/判读语义的须人批（#2245 ② 同口径），不动语义的可 AI 代批。
2. 两家评审对「继续修 vs 停」分歧 → 实测仲裁，取严。
3. 结构性轮之后再出同族新洞 → 停手转人拍板（结构性方案已失败的标志）。

**允许收口（放行入队）的前置，缺一无效**：
- 末轮 P0=0、P1=0（尺子/冻结装置链按沿用节：P1 本就不放行）；
- 到点 P2 处置齐（沿用节 #2063 B 逐字口径；P3 不要求）；
- **末轮结果块真实存在**：每家谱系、每个必需角色的块齐且为 PASS 类（角色名明确、非 ERROR/NOT_RUN/PARTIAL），原始块路径可查；
- 停修升级各条均未命中或已被结构性方案消化。

**收口证明义务**：
- 末轮评审块盖最终 head + 按改动类别给验证：行为/尺子改动 → 负控 + 真实数据复算；纯文档/流程 → 免负控但写明改动类别与为何不可复算。
- **修法类型声明**（fix-rN 任务书与 PR 正文必填字段，三值枚举）：`枚举式`（附边界论证：词表封闭性论证，或反向负例清单证明修饰窗/边界不吞真发现）｜`结构性`（含「结构派生/自动派生」子类：须核到**测试真实遍历的词表**，#2245 r5 漏网根因）｜`不适用`（无行为/尺子改动的纯文档轮）。缺失/空/未知值 → 收货车道退回。
