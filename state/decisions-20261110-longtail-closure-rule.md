## 新增判据（本卡确立）

**术语**：轮数 = 已开的**修复轮**（fix-rN 的 N），非评审轮数。**洞归属 = 发现该洞的评审所对应的下一修复轮**（如复核 fix-r25 的评审发现的新洞由 fix-r26 修，归 r26；评审轮无编号时以「发现于 head sha + 其后首个 fix-rN」锚定）。「逃逸族」= 同类句法/词汇/边界形状的洞族（与钉族规则的「同形状族」同概念，本卡内统一用「逃逸族」，不改别卡用词）。

**停修升级（任一命中即停手上报，不再开下一轮补丁；停修升级优先于允许收口）**：
1. **同族复现**：同一逃逸族的新 P0/P1（按洞归属）**累计第 2 次（隔轮不清零）** → 判「该修法不收敛」，续开必须换**结构性方案**（一处改动灭多洞）；结构性轮 = 以「一处改动灭多洞」为验收目标的修复轮，其存在期间本条与「修复轮上限 3」的计数继续累加但**不触发本条停修**。结构性方案动冻结/判读语义的须人批（#2245 ② 同口径），不动语义的可 AI 代批。
2. **评审分歧**：两家评审**都出了有效结论**（状态 PASS）且对「继续修 vs 停」相反 → 实测仲裁，取严。非 PASS 状态（PARTIAL/TIMEOUT/ERROR/TOOLS_VIOLATION）不算结论，复跑；只有一家评审在飞时**本条不适用**（不构成停修升级）。
3. **结构性方案失败**：结构性轮之后再出同族新洞，或结构性轮验收不达标（开单时登记的同族洞未清零）→ 停手转人拍板。
4. **轮数轴兜底**：rN ≥ 3（含当轮）的修复轮**出现任何 P0**（含跨轮存活与新现，#2781 r3b#1，2026-11-12 落卡）→ 不再开下一轮修复，停手转人拍板。本条在 rN ≥ 3 时收窄覆盖 CLAUDE.md:76「P0 仍必须当轮修」（rN < 3 照旧当轮修；「出现」以该轮评审块登记为准）。**计数口径（#2781 r3-final，2026-11-12 落卡）**：计数值 = 该单登记的 fix 轮号 rN 累计值（**含本卡生效前已开的轮**，即术语节「轮数」的同一定义，不另立第二定义），**不因结构性轮重置**（与第 1 条「计数继续累加」同口径）；「本卡生效（2026-11-10 0:1x，同 :1 口径）」只是停修判据的适用起点，不参与计数——生效前已达阈值的链按立即适用段逐链登记处置，不追溯触发停修。#1953 的 r49/r50 为结构性轮，同样不重置计数。
5. **通道兜底（#2781 r3b#2，2026-11-12 落卡）**：**本条独立触发，不受第 2 条前置约束**。任一非作者评审谱系在**同一条修复链内**累计 2 个 P0/P1 修复轮不可用 → 停手转人拍板。**计数单位 = 谱系×轮**；**不可用判定（三前提齐才记 1 次）**：①该轮已按流程派发该谱系；②该谱系当轮全部角色已终态且任一角色非 PASS；③人工复跑 1 次后仍无有效块（无产出 / 空块 / 缺末行 VERDICT / 复跑后仍非 PASS——按 pr-gate 对块缺失的 fail-closed 口径）。**不计入且不打断计数**：只修 P2 的单家复核轮次（CLAUDE.md ④ 允许）；`state/decisions-20261107-review-block-whitelist.md` 允许的叙述路径（该卡口径的「不能出块」= 执行器无该 runner 实现、自证留档）；`<!-- pr-gate:waiver <理由 ≥ 8 字> -->` 纯文档/纯状态轮（字面以 `scripts/check-pr-gate.py` 为正本）；谱系已按 board 登记正式停用者（登记链接留档；本句为本卡口径，非被引卡内容）。**资源争抢类排除**：名额排队超时（SlotTimeout）、429 / 五小时配额耗尽、执行级 TIMEOUT 首次未出块的不计入——但复跑义务不因此免除；复跑未执行时该轮悬置（不计入亦不排除），最迟须在该链下一次派轮前补跑，逾期未补即记 1 次（fail-closed）。**累计**第 2 次、隔轮不清零，与判据 1 同模态。**计数登记**：各链**各谱系分别**计，当前值登记在立即适用段（未列链起算 0），每次命中/排除在跟踪单评论留档（board 行仅镜像；同一轮重复评论以先登记者为准）。N=2 为 AI 代批值，待人复核。

**允许收口（放行入队）的前置，缺一无效**：
- 末轮 P0=0、P1=0（尺子/冻结装置链按沿用节：P1 本就不放行）；
- 到点 P2 处置齐（沿用节 #2063 B 口径；P3 不要求）；
- **末轮评审覆盖齐**，按 CLAUDE.md 合并闸门 ④ 分轮次口径：修 P0/P1 的轮次 = 两家谱系、只修 P2 的轮次 = 一家非作者复核；并按 `state/decisions-20261107-review-block-whitelist.md`（PR #2108 已合）允许「一家真块 + 一家叙述」路径；纯文档轮可走 `<!-- pr-gate:waiver 理由 -->`（理由 ≥ 8 字）。真块要求（两件齐）：① `<角色>.md` 非空、含覆盖行、末行 VERDICT；② `summary.md` 的 `pr-gate:v1` 标记 head= 最终 head 且 roles 全 PASS（`check-pr-gate.py` 只认 PASS）。双谱系齐块由收货/协调者判定（pr-gate 逐块校验，不代查谱系）；
- 停修升级各条均未命中或已被结构性方案消化。

**收口证明义务**：
- 末轮评审块盖最终 head + 按改动类别给验证：行为/尺子改动 → 行为负控 + 真实数据复算；纯文档/流程 → 免行为负控但写明改动类别与为何不可复算。
- **修法类型声明**（fix-rN 任务书与 PR 必填，**只接受字面三值**）：`枚举式`（附边界论证：词表封闭性论证，或反向负例清单证明修饰窗/边界不吞真发现）｜`结构性`（须核到**测试真实遍历的词表**，#2245 r5 漏网根因；「结构派生/自动派生」等子类字样一律写 `结构性` 并附词表核验）｜`不适用`（**仅当 diff 只触及文档类路径，以 `scripts/ci_scope.py` 的既有分类语义为唯一口径**——其 `docs_only` 判定白名单只有 `state/board.md` 一个精确路径（fix-r1 收窄：`state/`、`docs/`、`.42cog/` 其余文件是尺子输入，按目录放行会假 PASS），勿在本卡另立第二套路径清单；根级行为文件（`rust-toolchain.toml`、`Cargo.toml` 等）同按该分类器归类——不在白名单即非文档面，改工具链钉版不得按「纯文档」免行为负控与真实数据复算；触及 `src/`、`scripts/`、`specs/`、`tests/`、`.github/` 任一即不许写【示例性说明，正判以分类器为准】，尺子与装置主栖 `scripts/`）。缺失/空白/子类字样/未知值 → 退回。

## 每次拍板抽一条原则

第 4 轮及以后**每一轮**（fix-rN，N ≥ 4）修复开单前必须先答「上一轮的洞是边界暴露还是修法本身缺陷」——判不出即停修转结构性或转人。答案写进该轮任务书与 PR 的「上轮残差判读」（无上一轮时允许字面值「无上一轮」，空答不算答）。
