# 收敛后的 P2 只修一批

**为什么**：2026-10-17 #185（九轮）、#182 补审（四轮）、loop-fix（六轮）都出现同一循环——两家已 P0=0 P1=0，按 P2 折中 a 档「当轮顺手修」改一处，改动又要两家确认一轮，确认轮再冒出新的边角 P2，再修再审。每轮约 20 分钟加三路评审调用，CLAUDE.md 明令「不许用流程马拉松替代开发」。

**怎么用**：两家首次同时无 P0/P1 时，把当轮所有 a 档 P2 一次修完（附测试与变异验证），只派**一轮**小增量确认。确认轮若仍无 P0/P1，就开 PR 合并；它新提的 P2 按 c 档开 `P2-跟进`（写明前置节点）或在 PR 描述登记，不再为 P2 开下一轮。确认轮报出 P0/P1 照常修。同一处 P1 修三次不过仍按规则挂起。
