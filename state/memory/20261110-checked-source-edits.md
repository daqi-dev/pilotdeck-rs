# 结构化源码改动必须核实命中

渠道 fixture 的机械替换曾因 rustfmt 换行而零命中，之后错误地发出候选。今后按函数或语义标签定位，写入前断言旧片段命中数，写后读回所有相关分支值，再生成内容 SHA；零命中立即失败，不得继续交包。Slack 当前生命周期计数应为 initial=1、refresh=2、reload=3，验证以实际网络连接为准。来源：Gateway 整合 r40 渠道候选。

冻结检查入口固定用 `python3 -I scripts/gateway-parity/check_frozen.py ...`；该目录含与标准库重名模块，不在非隔离模式下直接执行。非隔离导入失败只表示调用环境失败，不解释为冻结通过或修改冻结清单。
