**为什么**：2026-10-14 两次教训。#35 按评审建议收紧日期规则后对照 57/57 全过，却会让同日真实数据里 8 个场景永远无法计分；F2 的防 skip 规则在合成报告上全绿，真实基线报告却永远 FAIL。原文：`git show 4fd3ee5:CLAUDE.md` 第 117 行。

**怎么用**：改 `specs/*parity*`、`scripts/*parity*`、`check_*` 时，除对照/负例外，必须在最近一份真实基线报告上复算一次，把「真实数据上通过/计分的场景数」与改动前并列贴进 PR；数字变化要有解释。
