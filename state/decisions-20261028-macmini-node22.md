# 决策卡：macmini 上已有的官方预编译 Node v22.22.0 能否用于宿主负控（2026-10-28，暂不执行，待人拍板）

- **卡在哪**：macmini 宿主核验机系统 Node 是 Homebrew v26.10.0。凡是「重生成 / generator」类负控（要求 TS 基线用 Node v22.22.0 重算金样），在 macmini 上正控必然 INVALID，只能回本机 Node22 补跑（`phase-local-node22.sh`）。10-28 已发生在 #775、#166、#61、#946 等单，每次多一轮约 0.4 h，且有时要整轮重起。
- **现场**：macmini `~/opt/node-v22.22.0-darwin-arm64/` 是 nodejs.org 官方 darwin-arm64 预编译包解压目录（`~/opt` 目录 10-23 17:25 建，包内文件时间 2026-01-13 = 官方发布时间；未找到下载包或安装记录，**不确定是人还是早先会话放的**）。红线「不下载预编译二进制」→ 我们至今**没有用它**。
- **谁受影响**：所有含 regeneration 类负控的评审轮（关键路径 #743 / #745 也会碰到）；提速措施 C。
- **能否撤回**：能（只是改宿主脚本里的 PATH）。
- **动不动尺子 / 意向**：不动尺子；涉及红线解释 → 归人。

| 选项 | 做法 | 用户可感知差异 | 代价 |
|---|---|---|---|
| **A** 确认可用 | 人确认该包来历可信（或就是你放的），宿主脚本对 regeneration 类负控把 PATH 指向它 | 每个含重生成负控的评审轮少等约 0.4 h，不再整轮重起 | 无；需人确认来历 |
| **B（无法确认来历时建议）** 源码编译 | 在 macmini 从 Node v22.22.0 源码 tarball（校验官方 SHASUMS256 签名）编译到 `~/opt/node-v22.22.0-src/`，删掉预编译目录前先问你 | 同 A | 一次性约 1–1.5 h macmini CPU；编译期间宿主车道变慢 |
| C 维持现状 | 继续本机 Node22 兜底 | 每轮多 0.4 h，偶发整轮重起 | 无 |

- **建议**：若该包是你放的 → A；否则 → B（编译期间不占关键路径车道）。
