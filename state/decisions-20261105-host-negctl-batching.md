|---|---|

| 动不动尺子 / 意向 | 不动。冻结装置 / 尺子改动仍按原规则用真实数据复算、不适用本降频（见下「不适用」）。 |
| 选项与后果 | A 维持每修复轮宿主全量：远端不可达期间等于宿主链整体停摆或独占本机名额；B 完全不跑宿主：平台差异（FS 目录 st_size、macOS 签名、符号链接上限类）到收口后才发现，合后补单更贵；C（采纳）三层口径。 |
| 决定 | **三层口径（人 2026-11-05 点头）**：① 每 PR 保留本地（同平台）负控，worker 交付即跑；② 宿主全量负控从「每修复轮」改为「**家族 / 节点收口时批量一轮**」（如 A7.2 附件家族、A7-W4/W5 收口前各跑一次，一次验多个已合 PR——合并同类项）；③ **冻结装置 / 尺子类改动不降**，仍每次真实数据复算（沿用既有批准程序）。 |
| 验收口径 | 降频只改「宿主负控的时机」，不改「关节点须有宿主结果」：阶段 / 节点完成前宿主批次必须已跑且全绿（既有铁律「未清不得关该节点 issue」继续生效）；PR 验收步骤里「宿主链」项写「待收口批次」。 |

**原则**：宿主负控的价值在平台差异覆盖，不在逻辑复核——逻辑归本地负控与静态评审；因此按「收口批量」而非「每轮」排宿主，置信度损失小、吞吐换增益大；冻结装置与尺子永远是例外。
