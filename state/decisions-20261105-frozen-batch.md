# 决策卡 · 冻结装置登记改「发车制」批处理（2026-11-05 人批）

| 卡项 | 内容 |
|---|---|
| 卡在哪 | 冻结装置（gateway-parity 等）每有一张单改到装置字节，就要独立走一遍完整登记：写事件、`check_frozen.py --write`、`FROZEN.md` 更新、一次全量真实复算、一次 CI 重定标、一次登记评审。近两周同一装置上多单（#1194 / #1206 / #1221、#1355、#1363 冻结件条目…）逐单重复这套，登记本身吃掉的墙钟时间超过改动本身，且在 board 上表现为「订单一多就排队」。 |
| 谁受影响 | 改到装置哈希行文件（`acceptance.md` / `normalization.md` / `accepted-diffs.md`、`common.A2_SCRIPTS` 18 件、2 个 fixture、`scripts/a5-19` 5 件，共 28 行）的单与其协调者；不改装置的单、只新增 `diffs/<ID>.md` 的单**不受影响**（本来就零登记成本）。 |
| 能否撤回 | 能，且是纯流程改动：撤回即恢复「一单一次登记」，没有不可逆动作、没有数据删除、不碰远端资源。已登记的事件是 append-only 历史，不受撤回影响。 |
| 动不动尺子 / 意向 | **不动尺子语义**：不改阈值、分母、映射、归一化、差异账本、比较器；不改 `FROZEN.md` / `accepted-diffs.md` / `diffs/README.md` / `frozen/README.md` 任一冻结字节；不改 `check_frozen.py` 的任何检查规则（机器侧本来就支持多事件一次 `--write`，已实测）。意向范围内（加速重构与对拍的可信度）。 |
| 选项与后果 | **A 维持现状**：每单一次完整登记——每多一张单多一次全量复算（k=5 六轮）与一轮完整 CI（约 20–40 min）加一轮两家登记评审，吞吐随单数线性下降。**B 取消登记 / 放宽 `--write` 校验**：等于让装置哈希失去意义，尺子会假通过，碰红线，**不选**。**C（采纳）发车制**：一次登记周期承载 N 张单，一车一次 `--write`、一次 `FROZEN.md` 更新、一次车次复算、一次 CI 重定标；每张单仍各自一个事件文件、各自两家非作者评审、各自真实数据切片。 |
| 决定 | 采纳 C。规约正本 `specs/gateway-parity/BATCH-RELEASE.md`（新增可改载体）；本卡只记判断与原则，不复制规约正文。车次规模 1–5 单（0 单取消车次）；改检查规则语义的按 `frozen/README.md` 三套同步原子交付、不组车；改判分语义的即使已获批也独占一车，未获批不得上车；跨装置不同车；并发/生命周期类不同车（CLAUDE.md 人定「并发包不合成 PR」继续生效）。 |
| 验收口径 | 车次 PR 必须能被机器判：每个变化文件都有 `Change:` 边、能拼成唯一链（`check_frozen.py --base` 绿）；每单事件两谱系评审引用非空；车次复算产物在 `_tmp/<日期>-frozen-train-<n>/` 可点开且能逐单指回判据。N=1 的车次与今天等价，不算违规但也不算收益。 |
| 机检现状 | 已有机器规则覆盖「多事件一次 `--write`」：`check_registration` 按文件建边、允许多事件拼唯一链、拒绝缺边/重复边/陈旧边。**本次不需要改检查器**，故不新增工具类工单。 |

**可复用原则（一条）**：**批处理合并的是「登记与复算的次数」，不是「评审的强度」——凡是每张单各自承担的可核验义务（理由、证据、两家非作者评审、真实数据切片），一律不得随批量稀释。**

可机检的落点（已有，无需新增代码）：`check_frozen.py --base` 对每个变化文件要求唯一事件链；`read_events` 要求每个事件恰两条不同谱系、不同引用的评审。**边界要写清**：机器只验「边能拼成从 base 到当前树的唯一链」，不校验中间摘要对应真实单元增量——把 `a→b` 拆成 `a→x→b`，两条格式合格的事件同样能过。单元真实性与「空事件」靠 §6 的逐单 diff 核对、评审引用跨事件去重（§6 ⑤）与单级证据切片，机器绿不等于登记属实。

**人批与代批的边界**：发车制机制本身由人 2026-11-05 明确批准，随本卡与规约生效；本卡与规约的**文字细节**、车次编号、首批车次编排建议（`_tmp/20261105-frozen-batch/ROLLOUT.md`）属 AI 代批，待人复核，不阻塞规约生效。判分语义与检查规则语义的变更仍须人复核 / 签字，车次不改变这一点。
