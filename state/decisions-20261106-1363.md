## 实测（前提核对）

两条的登记前提都**没有被实测支持**：

- **#1**（`_tmp/20261106-issue-1363/item1/probe_variants.txt`、`probe_shapes.txt`）：四类畸形 `--source`（observation 是 list、`frames: null`、`frames: []`、顶层 JSON 是 list）× 两个合法 case，全部 `exit=1` 且写出 `verdict.json`：`FAIL/COVERAGE`、`FAIL/MALFORMED_OBSERVER`、`FAIL/FRAME_PUBLICATIONS`、`FAIL/CONTROL_EXECUTION`。原因是 `check_case` 在变异之前先跑 `observation_check(..., 'healthy-observation')`，畸形输入在那里就以 `ValueError` 拒绝，走不到 `AttributeError`/`IndexError` 路径。→ 登记描述的「非对象 JSON 以 traceback 退出」**不可复现**。
