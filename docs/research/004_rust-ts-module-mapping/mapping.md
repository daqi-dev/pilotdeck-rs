## 口径

- **Rust 产品行数**：该文件首个 `#[cfg(test)]` 之前的行数；`tests/` 目录不计。
- **TS 对应**：`路径:起始行-结束行`，相对 `resources/PilotDeck/src/`（例外单独标注）。整文件对应写 `路径:1-N`。
- **TS 行数**：各映射区间行数之和；**同一 TS 区间被多个 Rust 文件引用时重复计入**（如 `AgentLoop.ts` 的不同片段分别对应 turn / driver / budget 等十余个文件），个别合计存在 ±3 行内舍入误差。
- **比值** = Rust 产品行数 / TS 行数，一位小数；TS 为 0 记 ∞。
- 判断三档（判断依据来自逐文件回源读两边代码，非文件名比对）：
  - **对得上**：职责与行为对得上，多出的行属语言差异（类型声明、所有权、显式错误处理、JS 语义展开）。
  - **部分**：主体对得上，但明显一块（约 ≥25% 或一个独立机制）在 TS 里不存在（防御性校验、快照捕获、额外错误路径）。
  - **对不上**：该文件大部分行为在 TS 侧没有对应物 = 可能膨胀。
- 缩写：`AL` = `agent/loop/AgentLoop.ts`；`§schema` = `docs/pilotdeck-module-protocol-v2.schema.json`（相对 PilotDeck 根）。
