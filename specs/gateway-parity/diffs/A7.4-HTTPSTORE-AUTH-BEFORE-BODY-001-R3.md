## 类别

同原条目 `A7.4-HTTPSTORE-AUTH-BEFORE-BODY-001`（最新版
`A7.4-HTTPSTORE-AUTH-BEFORE-BODY-001-R2`），类别不变：鉴权与长度检查先于
读请求体（向安全偏离）。本条只更正该偏离在连接层的可观察后果：早退
`Connection: close` 响应写完后，Rust 现在做 bounded drain 再关，避免未读
请求体让内核以 RST 丢掉已写响应。

## 基线依据

同 R2 的 Node v22.22.0 实测：TS handler 在 `serveNodeRequest` 先收完 body，
Node 对未读 body 走 `_dump` 后仍保持连接。R3 另用 plain `node:http` 探针
记录早退 401 + 慢发送者的传输层字节
（`src/pilotdeck-gateway/tests/fixtures/user-dialog-http-store/lifecycle-matrix/node-lifecycle-matrix.json`）：

- `s4_early_401_slow_sender`：`writeHead(401); end()` 不读 body，peer 逐块
  慢发 3 MiB；完整 269 B 401 到达，连接保持 keep-alive（Node drain 未读
  body）；
- `s4_early_401_client_fin`：早退 401 后对端 FIN，401 完整到达，Node 再补
  47 B `HTTP/1.1 400 Bad Request\r\nConnection: close\r\n\r\n` 后 EOF。

## Rust 行为

`src/pilotdeck-gateway/src/user_dialog/http_store.rs`：

- 鉴权/长度预检仍在读 body 之前完成，早退响应仍是
  `Connection: close`（R2 行为不变）；
- `serve()` 返回后，若请求 body 未读完且响应是 `Connection: close`，
  `KeepAliveTimer` 置 `unread_body_close`；
- 连接任务在 hyper 的 `Connection` 结束后先释放 hyper 持有的 socket，再用
  建连时 `try_clone` 的副本做 bounded drain：100 ms 静默或 1 s 硬上限，
  然后释放最后一个句柄。这样内核接收队列为空，close 发 FIN 而不是 RST，
  已写响应不会被丢弃。实现不读、不解析、不落盘被 drain 的请求体。

## 范围

仅早退 `Connection: close` 且请求 body 未读完的连接（405/404/401/413、
body 读失败 500、body requestTimeout 408、HTTP/1.0 close）。鉴权顺序、
状态码、响应字节、body 上限、连接数上限不变。Node 的 `_dump` 无上限；
Rust 的 100 ms 静默 / 1 s 硬上限是资源保护，慢发送者超过 1 s 仍可能在
close 时留下未读字节（此时 RST 风险回到内核默认）。该取舍是安全侧既有
偏离的一部分，不引入新的 TS 行为差异。

## 机器判据

`src/pilotdeck-gateway/src/user_dialog/http_store_tests.rs`：

- `early_close_response_survives_byte_at_a_time_sender`：Content-Length
  3 MiB 的未认证请求，先发 512 KiB 再每 2 ms 发 1 KiB；客户端故意在
  250 ms 后才开始读（让 RST 有机会丢弃已排队响应），必须
  `read_to_end` 得 `Ok`、413 完整 body、`Connection: close` 且无
  `Keep-Alive`。修复前该用例 `Connection reset by peer (os error 54)`。
- `early_close_response_survives_shutdown_with_unread_body`：早退 401 已写、
  请求 body 未读时 `server.close()`；响应完整 401 + `Connection: close`，
  `close()` 有界返回（S4×E1）。
- 既有 `unauthorized_with_unread_body_closes_connection` /
  `oversized_content_length_rejection_closes_connection` /
  `oversized_chunked_body_rejection_closes_connection` 仍绿；drain 只发生在
  响应写完之后，不改变这些用例的响应字节。
