## Rust 行为

`src/pilotdeck-gateway/src/native_http/tests.rs`（test-only；产品代码
`http_proxy.rs` 本两轮零改动）：

- 6 s 空闲关闭族窗口收紧为 (5.99, 6.09] s 共六格：随本 PR 首笔（r1）三格
  `idle_state_no_request_stays_open` / `handler_execution_blocks_idle_close` /
  `pipelined_request_during_body`（probe 5_400/700 → 5_930/40）；随 fix-r1
  三格 `served_follow_up_head_silent_ends_at_idle_close` /
  `in_flight_request_disarms_rearmed_timeout` / `held_response_gets_no_headers_timeout`
  （尾窗 200 ms → 40 ms，消息加「not any later」）。九格共用命名常量
  `IDLE_CLOSE_PROBE_ADVANCE`（+5.99 s 探活推进）/ `IDLE_CLOSE_TAIL_WINDOW`
  （40 ms 尾窗），6 s 族全部裸字面量收编（防漂移；评审 simplify #4——
  700/200 ms 宽尾窗正是字面量彼此无关联的漂移产物）。
- 新格 `client_close_during_held_body_resolves_without_timer`（矩阵
  S4×E5，`#1250` fix-r1 遗留子格）：持体期（`held_body("part1-", "part2",
  release)`）客户端半关后放行持体，连接 future 裸 `task.await` 解出
  `Ok`、全程零 `advance()`；可读半关客户端收到补完的保留体
  （`…part2\r\n0\r\n\r\n`）再 EOF。
- **字节层分歧（本条目的登记主体）**：同格交错下 Node 在 FIN 同刻截断
  响应（保留体不送达，见上探针），本车道把保留体补完给仍在读的半关对端
  再 EOF；两家在连接 future 结果层一致（`Ok`、不挂、无残留计时——新格
  锚定的就是这一层）。产品侧是否复刻 Node 的 FIN 同刻截断属产品代码
  改动，**另单跟进**，不在本 PR（只改测试文件）范围（另见已开跟进
  #2380，其覆盖范围不因本条目改变）。
