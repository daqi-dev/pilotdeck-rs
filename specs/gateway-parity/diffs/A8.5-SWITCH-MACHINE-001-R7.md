## 类别

更正（补登记，#2788）：#2351（PR #2757，commit `2bdb5d9e3`，2026-11-09 合入）
变更了原条目及其 `-R1`…`-R6` 件所登记行为基础上的 `PhasedRun::drained()`
失败观测语义，合入时未按只追加规则同步更正件，本件补登记。该变更不改
任何差异格、判分豁免、阈值或负控分母——S2 的对外契约（`true`=预算内
drain 完成，`false`=预算到期有存量连接）不变，变化仅在「runner 自身
失败（panic/abort/drop 后重启不可达）时 `false` 的产生路径与时界」：
`drained()` 不再回退 `inner.lock().await` 读 `drained.unwrap_or(false)`
（该锁可被并发 `finish()` 持有——`-R2` 件之后最多一个 owner 尺度界、
之前无界），而是 runner 独占通知 sender、其退出即关闭 watch，全部
waiter 有界返回 `false`。语义差异详述见「Rust 行为」。本件沿 `-R6`
件先例（负控扩行需新增 `-R` 件登记），为该族第 7 件追加更正。

## Rust 行为

在原条目及 `-R1`…`-R6` 件行为之上，一处变更（#2351，PR #2757，
`2bdb5d9e3`），全部落在 `src/pilotdeck-gateway/src/native_ws.rs`：

- 构造与所有权：`run_phased` 的 watch 构造由
  `let (done, _) = watch::channel(None::<bool>)`（sender 存进
  `PhasedRun`、`runner` 只存 `AbortHandle`）改为
  `let (runner_done, done) = watch::channel(...)`（`:262`）——runner
  任务独占唯一 sender，`PhasedRun` 持有 `done: watch::Receiver`（`:539`）
  与 `runner: JoinHandle<()>`（`:542`）；`Drop for PhasedRun` 仍
  `self.runner.abort()`，弃置即中止的既有语义不变。
- `drained()`（`:566`）：waiter 由 `subscribe()` 改为 `clone()` 现有
  receiver；循环内先查已发布 verdict（sender 关闭后已发布的值仍可读），
  `changed().await` 报关闭（无 verdict 关闭 = runner 失败）时直接
  `return false`——删除旧回退
  `return self.inner.lock().await.drained.unwrap_or(false)`。旧行为下
  runner panic 后 waiter 需要 `inner` 互斥锁才能观测失败，而该锁可被
  并发 `finish()`（abort join + host shutdown，`-R2` 件语义）持有至
  owner 尺度界（`-R2` 之前无界）；新行为下失败观测不经过 `inner`，
  runner 任务结束（panic 展开 / abort）即关闭通知，全部 waiter 与
  后到 waiter 在 watch 关闭当拍返回 `false`。
- 文档语义随之更正：`drained()` 的 `false` 由「预算到期有存量连接」
  扩为「预算到期有存量连接，或 runner 未留 verdict 即退出
  （panic/abort）」，两种情形都由 `finish()` 报失败。
