## 类别

不可避免（类型边界差异：steer 邮箱的条目标识深入共享机器且为
`JsString`，非字符串 `itemId` 只能以 `String()` 强转文本落库）。除深数组
格外，单请求格的响应帧与 TS 一致（`accepted:true` / `cancelled:true`，无
自造错误）；深数组格（嵌套超 `js_value::MAX_ARRAY_DEPTH`）Rust 自造
`gateway_request_failed` + RangeError 文本（TS 原样嵌入、永不报错，见 §Rust
行为 1）。强转文本同时充当**取消/去重集合的判定键**（`seen` / `cancelled:
HashSet<JsString>`），因此**跨类型同文本交错下响应帧与投递结果都可与 TS
不同**（§交错 A/B），不止落库 mutation。全面 `JsValue` 化与兄弟车道
#1444（steer attachments，同文件同机器）冲突，留待该车道收敛时一并评估。

## Rust 行为

`src/pilotdeck-gateway/src/native_process/methods/steer.rs`
`item_id_string`：非字符串 `itemId` 走**未检查**的 `String()` 形
（`js_value::to_string_units`）——`5` → `"5"`、`[1,2]` → `"1,2"`、
`{toString:null}` → `"[object Object]"`、缺键 / `undefined` → 字面量
`"undefined"`、显式 `null` → 字面量 `"null"`；嵌套超过
`js_value::MAX_ARRAY_DEPTH`（2000）的深数组 →
`gateway_request_failed` + `Maximum call stack size exceeded`。除深数组
格外，响应帧在单请求格与 TS 一致（`accepted:true` / `cancelled:true`，
无自造错误）；差异：

1. 落库 mutation 与 `metadata.queueItemId` 携带强转文本（单请求格），
   以及深数组格（TS 原样嵌入、永不报错）；
2. **交错 A**：cancel 数字 `5` 后 steer `"5"` → Rust
   `{accepted:false,reason:"cancelled"}`（TS `accepted:true` 且投递）——
   响应帧分歧；
3. **交错 B**：steer `5` + steer `"5"` 后 cancel `"5"` → Rust 第二条被
   seen 去重**静默丢弃**（答 `accepted:true` 但不入队），cancel 移除的是
   数字条，drain 为空（TS drain 回 `[5]`）——消息静默丢失；
4. **缺席格**：缺席 `itemId` 折成字面量 `"undefined"` 文本，与真实字符串
   id `"undefined"` 互为别名（TS 的 `undefined` 值不碰撞）；缺席 steer 的
   `queueItemId` 是字符串 `"undefined"`（TS 的 `JSON.stringify` 丢键）；
   随后缺席 cancel 会把字面量条取消掉（TS 不会）。
5. **null 格**：显式 `itemId: null` 折成字面量 `"null"` 文本，与字符串
   id `"null"` 互为别名（TS 的 `null` 值不碰撞，drain 回 `[null]`）；
   null steer 的 `queueItemId` 是字符串 `"null"`（TS 原样嵌入
   `null`）；随后 cancel `"null"` 会把 null 条取消掉（TS 只取消字面量
   条，null 条存活）；
6. **claim 门**：durable 消费（`runtime/steer.rs`
   `TurnSteers::on_durable_message`）读 `metadata.queueItemId` 并以
   非空文本放行——缺席/null 格在入参边界已折成 `"undefined"`/`"null"`
   文本，所以一律走 claim，邮箱 mutation 落
   `{"mutation":"claim","itemId":<强转文本>}`；TS 以真值门过滤原始
   `queueItemId`，缺席/null/`0`/`false`/`""`/缺键全部跳过 claim
   （claim 门定标探针）。同一类型边界，随 §差异 1-5 留待 #1444 收敛。

`message` 仍原样 `JsValue` 嵌入 text 块（探针对齐，无差异）。

类型根源：`SteerMessage.item_id: JsString` 深入
`runtime/steer.rs`（`SteerMailbox` seen/cancelled `HashSet<JsString>`、
`TurnSteers`、persist_and_apply、authorizations），单侧改 `JsValue` 需要
级联整套共享机器。

## 范围

`steer_turn` / `cancel_steer` 的非字符串、缺席与显式 `null` 的 `itemId`
（合法 JSON 帧可达），含其交错组合（§交错 A/B）与缺席 / null 格
（§Rust 行为 4/5）。字符串
`itemId` 与单请求响应帧不受影响；sessionKey / runId / message /
attachments 等其余入参已按 #1604 探针逐格对齐（Map-miss /
turn_mismatch / 原样嵌入），无残差。`hook_async_result` / run 族 /
`active_turn_snapshot` 不涉及。

## 机器判据

`native_process::methods::tests::steer_item_id_coerces_to_text_for_the_
mailbox_identity`（`native_process/methods/tests.rs`，#1604 新增）：

- 单请求格：钉住 `5` / `[1,2]` / `{toString:null}` 三格的 `accepted:true`
  响应、邮箱 `item_id` 与 `queueItemId` 的强转文本（`"5"` / `"1,2"` /
  `"[object Object]"`），以及深数组格的 `gateway_request_failed` +
  RangeError 文本；
- 交错 A 格：cancel 数字 `5` → `cancelled:true`，随后 steer `"5"` →
  `accepted:false` + `reason:"cancelled"`，drain 0 条（TS 投递该条）；
- 交错 B 格：steer `9` → `accepted:true`，steer `"9"` → `accepted:true`
  （去重、静默不入队），cancel `"9"` → `cancelled:true`，drain 0 条
  （TS drain 回 `[9]`）；
- 缺席别名格：缺席 steer → `accepted:true`，字面量 `"undefined"` steer →
  `accepted:true`（互为别名去重），缺席 cancel → `cancelled:true`（把
  字面量条取消），drain 0 条（TS 保留字面量条）；
- 缺席强转格：缺席 steer 的邮箱 `item_id` 与 `queueItemId` 均为字符串
  `"undefined"`（TS 的 `JSON.stringify` 丢键）；
- null 强转格：null steer 的邮箱 `item_id` 与 `queueItemId` 均为字符串
  `"null"`（TS 原样嵌入 `null`）；
- null 交错格：null steer → `accepted:true`，字面量 `"null"` steer →
  `accepted:true`（互为别名去重），cancel `"null"` → `cancelled:true`
  （把 null 条取消），drain 0 条（TS 保留 null 条，drain 回 `[null]`）；
- claim 门格（差异 6）：缺席 / null steer 经 `start_turn` 装进 router 的
  drain 端口（TurnSteer 路径）后 `persist_and_apply`，注入的 recorder 落
  恰好一条 `claim` mutation，键为强转文本 `"undefined"` / `"null"`
  （TS 真值门不 claim，probe `output6.txt`）。
