## 类别

不可避免（类型边界差异：steer 邮箱的条目标识深入共享机器且为
`JsString`，非字符串 `itemId` 只能以 `String()` 强转文本落库；响应帧仍
逐字节一致）。全面 `JsValue` 化与兄弟车道 #1444（steer attachments，同
文件同机器）冲突，留待该车道收敛时一并评估。

## 基线依据

固定基线 cc7c4e65，Node v22.22.0 / ICU 78.2。探针
`_tmp/20261026-issue-1604/ts-probe/output.txt`（真实
`InProcessGateway.steerTurn` / `cancelSteer`，stub session 直接观察
`session.steer` 收到的原值）：

- s5：`itemId: 5` → `{"accepted":true}`，消息
  `{"turnId":"run-1","itemId":5,…,"metadata":{"purpose":"mid_turn_steer",
  "queueItemId":5}}` —— 原值嵌入，无强转；
- s6：`message: 5` → text 块原值 `5`；
- s8：`itemId: {toString:null}` → `{"accepted":true}`，`queueItemId`
  原值嵌入 `{"toString":null}`，无 ToPrimitive 失败、无任何错误。

TS `steerTurn` / `cancelSteer` 完全没有入参校验
（InProcessGateway.ts:1859-1893）；`SteerMailbox.cancel` 对未知
`itemId`（含非字符串，探针 m1/m2）一律记取消并答
`{cancelled:true}`。

## Rust 行为

`src/pilotdeck-gateway/src/native_process/methods/steer.rs:52`
`item_id_string`：非字符串 `itemId` 走**未检查**的 `String()` 形
（`js_value::to_string_units`）——`5` → `"5"`、`[1,2]` → `"1,2"`、
`{toString:null}` → `"[object Object]"`；嵌套超过
`js_value::MAX_ARRAY_DEPTH`（2000）的深数组 →
`gateway_request_failed` + `Maximum call stack size exceeded`。响应帧
与 TS 一致（`accepted:true` / `cancelled:true`，无自造错误）；差异仅在
落库 mutation 与 `metadata.queueItemId` 携带强转文本，以及深数组格
（TS 原样嵌入、永不报错）。`message` 仍原样 `JsValue` 嵌入 text 块
（探针对齐，无差异）。

类型根源：`SteerMessage.item_id: JsString` 深入
`runtime/steer.rs`（`SteerMailbox` seen/cancelled `HashSet<JsString>`、
`TurnSteers`、persist_and_apply、authorizations），单侧改 `JsValue` 需要
级联整套共享机器。

## 范围

仅 `steer_turn` / `cancel_steer` 的非字符串 `itemId`（合法 JSON 帧可达）。
字符串 `itemId` 与响应帧不受影响；sessionKey / runId / message /
attachments 等其余入参已按 #1604 探针逐格对齐（Map-miss /
turn_mismatch / 原样嵌入），无残差。`hook_async_result` / run 族 /
`active_turn_snapshot` 不涉及。

## 机器判据

`native_process::methods::tests::steer_item_id_coerces_to_text_for_the_
mailbox_identity`（`native_process/methods/tests.rs`，#1604 新增）：钉住
`5` / `[1,2]` / `{toString:null}` 三格的 `accepted:true` 响应、邮箱
`item_id` 与 `queueItemId` 的强转文本（`"5"` / `"1,2"` /
`"[object Object]"`，断言消息指回本条目），以及深数组格的
`gateway_request_failed` + RangeError 文本。TS 期望来自「基线依据」的
探针实测。收敛时机：#1444 收敛 steer 机器携带 `JsValue` 时，由该测试
按更正流程（`A7.2-STEER-INPUT-001-R<n>`）重写为原值嵌入格。
