## Rust 行为

`runtime/tools/builtin/web/fetcher.rs` 的 `FetchError::Other` 由只存 message 改为
`{ name: Option<&'static str>, message }`：

- `From<NetworkFetchError>` 保留 `Some("NetworkFetchError")`；
- body `BodyError::Terminated` → `Some("TypeError")`；`BodyError::Aborted` 经
  `network_error()` 仍为 `NetworkFetchError`；
- TS `throw new Error(...)` 站点 → `Some("Error")`；
- Rust/宿主特有错误（HTML 转换的内存准入失败）经 `untyped()` → `None`，不从 message 补造；
- `fetch_redirect` 的 `BodyError::Terminated → TypeError`、`Aborted → AbortError`、
  retry 的 `NetworkFetchError` 由测试 harness 按真实 typed outcome 绑定，行为不变。

`fetch_tool.rs` 继续只交付 message，与 TS `webFetch.ts` 一致。
