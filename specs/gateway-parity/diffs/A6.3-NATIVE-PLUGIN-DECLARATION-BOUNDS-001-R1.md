## 类别

资源限制更正：共享 JSON 值预检同时覆盖外部 hooks JSON，避免绕过 manifest 预检后先分配大树；原条目原字节保留。

## 基线依据

固定 TS cc7c4e6 的 PluginLoader 使用 JSON.parse 解析外部 hooks，未设值数量配额；原条目所引实采证明 hooks 普通目录/读取失败按 catch 处理。本更正不冒称新增精确限额是 TS 行为，真实 hooks 值边界基线实采及 Rust 验证待补原件。

## Rust 行为

manifest 与 hooks 文件共享一次 native staging 的字节和条目预算，两种 JSON 均在物化 JsValue 树前预检容器/标量，keys不计。单个目录项、manifest为 name/hooks 两字段、hooks为 ignored 数组时9994个scalar使总条目10000可通过，9995拒绝。特殊文件范围精确为成功打开后发现非regular且非目录的描述符，或已识别NOFOLLOW链接竞争；open本身普通错误仍走TS staged/catch。不宣称socket打开失败一定是安全错误。

## 范围

仅 native 磁盘插件及hooks声明；原条目discovery略过错误专指plugin目录，standalone技能沿其已有单独边界，不据此泛化。任意程序化gateway插件不在本条范围，不修改codec公用语义。

## 机器判据

native_hook_value_budget_applies_before_json_materialization 验精确两端；native-hook-value-budget 注错必须被超限断言杀死。既有 native-skill-filter 的真实首个差异为名称而非数量，失败marker绑定原oracle name断言，oracle原字节不变。当前仅实现，待mbp2运行；不将静态锚检查写成KILLED。
