## 类别

#1055 ①/② 修复：过期 BUSY 掩盖迟到清理错误、含 pending BUSY 的 record 永不回收（无界增长）、close/shutdown 丢失未消费准备/建立错误；修复自身生命周期保证。

## 基线依据

固定 cc7c4e653b15c8b2cec7bcf2d15d41d69396ae85、Node v22.22.0 真实 Router/Factory/AgentHandle 探针（`_tmp/20261026-issue-1218/deliver-resume1/ts-probes/1218-disposal-parity.mts`，原始输出贴该目录 `.raw.txt` 与本轮 RESULT）：迟到清理错误以同一 cached rejection 送达每个 awaiter 与迟到 attacher（无 busy 层可掩蔽）；recreate caller 无超时等 `previousDisposed`，Err 原样透传且失败后 replacement 留缓存、下一 caller 直接命中；失败创建根本不进 map（无 pending 记录可留）；close 返回原 disposer 错误；idle sweep 仅按 lastUsedAt 年龄回收。沿用 `session-disposal-retry/oracle.json` 的错误形状（rows[3] 嵌套 DISPOSE_1022）。TS 没有 Rust future drop/writer budget/pending token；本项不声称这些 Rust 组合与 TS Router 端到端一致。

## Rust 行为

owner 读到未消费 `SESSION_WRITER_BUSY` 时先判「销毁已结束」再判「正常 drain 完成」：drain 已以未消费清理错误结束时，`LiveSessionHandle::take_recreation_disposal_error()` 恰一次接管并把它交给紧随其后的 caller（替代再掩一轮 BUSY）；仅在干净（或已报告）完成时丢弃过期 BUSY 继续创建。idle sweep 对「BUSY 且前驱 recreation 已干净排空或以已报告的清理错误结束」的 record 可回收；不可重试错误（清理/准备/建立）继续保留。close/shutdown 在 evict 成功而 record 持未消费不可重试错误时返回/并入该错误，在 evict 失败时把 evict 错误与它一并聚合（不丢任何一个；同一清理失败可能在两个 cause 中双列）；BUSY 不由 close/shutdown 交付。发布于 watch 之前完成态的纳秒窗口回落到 BUSY 重放（有界）。

## 范围

修正 R3 的两条策略：R3 的 stale-busy 判定先丢弃后创建，清理错误迟到时再掩一轮 BUSY；R3 的 idle sweep 对含 pending 的 record 一律保留导致 BUSY record 无界增长。R3 其余保证不变：dispose 清理错误仍须交付外层 caller，不可重试错误仍保留到消费或显式 close/shutdown。不改变冻结判分，不增加评分豁免；TS 无「失败创建留缓存」对应物，close/shutdown 交付是 Rust pending 模型的补漏，不声称 TS 端到端一致。

## 机器判据

`factory_tests.rs` 的 `recreation_cancelled_timeout_late_cleanup_error_is_returned_to_next_caller` 验证 ①（取消 caller 超时 BUSY → drain 以嵌套 DISPOSE_1022 的 Err 结束 → 紧随 caller 收原错误非 BUSY，随后重试成功）；`recreation_cancelled_timeout_busy_is_retained_by_sweep_while_drain_pending` 验证 ② cell 6（BUSY 挂起、drain 未决时 sweep 保留，drain 干净结束后下一轮 sweep 回收）；`recreation_cancelled_timeout_busy_is_reclaimed_by_idle_sweep` 验证 ② cell 7（drain 干净结束后时钟推进 + sweep 回收，随后新建成功）；`recreation_cancelled_timeout_reported_cleanup_error_is_reclaimed_by_idle_sweep` 验证 ②（drain 以已报告清理错误结束 + sweep 回收）；`recreation_{cancelled,unconsumed}_consumed_owner_error_is_reclaimed_by_idle_sweep` 验证消费后可回收（含未消费阶段的保留断言）；`recreation_unconsumed_cleanup_error_is_returned_by_close` 回归 cell 8（close 把原 disposer 错误与同一未消费清理错误聚合，两 cause 同形）；`recreation_unconsumed_creation_error_is_returned_by_close_and_shutdown` 验证 cell 9/10（close 返回、shutdown 聚合未消费建立错误，shutdown 聚合形状与 TS `AggregateError("Failed to shut down all agent sessions.")` 同形）；`recreation_unconsumed_creation_error_is_aggregated_with_failed_disposal_by_{close,shutdown}` 验证 evict 失败 + 未消费建立错误的聚合（不丢任何一个）；`recreation_cancelled_timeout_busy_is_not_delivered_by_close_or_shutdown` 验证 cell 12（BUSY 不由 close/shutdown 交付，只返回 evict 结果）。`session-factory/negative_controls.py` 新增 `#1055 ` 前缀断言的配对源码变异（takeover 关闭、sweep busy 臂、sweep None 臂、sweep drain 门、combine 守卫、combine 双臂、busy 交付），完整名与专属断言由执行器绑定；沿用 ignored `disposal_retry_regenerates_identically` 守卫。
