## 类别

行为差异（功能缺失）

## 基线依据

undici 8.3.0 `EnvHttpProxyAgent`（`proxy.ts:131`）接受 `httpsProxy: proxyUrl`，对 `https:` scheme 的代理 URL 建立 TLS 隧道连接（ProxyAgent 默认 `proxyTunnel: true`）。

## Rust 行为

`ProxyConfig::new_with_extra`（`src/pilotdeck-gateway/src/runtime/model/http.rs:533`）：

```rust
if proxy.host_str().is_none() || proxy.scheme() != "http" {
    return None;   // https: proxy URL → None → 直连
}
```

`https:` scheme 不为 `"http"`，返回 `None`，调用方退化为直连。无错误报告。

## 范围

`https:` 代理 URL 下，TS 建 TLS CONNECT 隧道，Rust 直连目标端点。目标仍可达（无功能错误），但安全边界与 TS 不同。外部 https-only 代理场景无法穿透。
