## 类别

有意改进。TS `terminal()` 在线接受两类自相矛盾的输入并落盘（truthy 非对象 seed 投影成 `{}` 落盘；outcome=`result_unknown` 经 known 终态路径落盘、重开自降级为 result_unknown）；Rust 在线拒绝且不落盘，避免向磁盘写入与调用方声明不符的终态。

## 基线依据

cc7c4e6 的 `src/agent/modules/transport/sessionOperationLedger.ts:284-294`（`validateKnownTerminal` 只查 lastAppliedSequence 整数、result 的 session/turn、messages 为数组——不查 seedState 类型、不查 outcome 是否属于已知集合）、`:108-125`（`...(input.seedState ? { seedState: serializeAgentLoopSeedStateProjection(input.seedState) } : {})`：truthy 字符串 seed 经 `seedStateProjection.ts:31-40` 的属性选择投影为 `{}` 落盘；`outcome: input.outcome` 原样落盘）。实测（Node v22.22.0 + 基线 tsx 4.22.3，`_tmp/20261026-issue-201/probe-run-2.out` T2/T3/T3b）：三种输入 TS 在线均成功、事件 3 条落盘；`result-unknown-outcome` 重开恢复为 result_unknown（自降级）；无 streamId 的 result_unknown 重开抛 `Restored AgentLoop operation op-1 result_unknown lacks a stream id.`。金样：`src/pilotdeck-gateway/tests/fixtures/operation-ledger/deviation-{string-seed,result-unknown-outcome,result-unknown-outcome-no-stream}.jsonl` 及 `oracle.json` `deviationCases`。

## Rust 行为

`src/pilotdeck-gateway/src/storage/ledger.rs:226-228`（`Known terminal requires a known outcome.`，outcome=`result_unknown` 的 known 输入在写盘前拒绝）；`src/pilotdeck-gateway/src/storage/projection.rs:10-16`（serialize 对非对象 seed 抛 `Invalid sidecar seedState: expected an object.`）。两侧对落盘结果（`deviation-*.jsonl`）的恢复语义一致：Rust 能打开并按 TS 恢复结果恢复（string-seed 恢复 seedState `{}`；result-unknown-outcome 恢复 result_unknown；无 streamId 的重开拒绝，`ledger.rs:421-424` 与 TS 同文案含 operation id）；差异仅在线准入与是否落盘。

## 范围

仅 `terminal()`（known 终态路径）的在线准入：seedState 为 truthy 非对象（string/number/true/数组），或 `outcome` 取 `result_unknown`。TS 把它们落盘为 seedState `{}` / outcome `result_unknown`；Rust 拒绝、磁盘保持 start+accepted 两条、内存无终态，调用方可携带合法值重试。`resultUnknown()`（unknown 专用路径）两侧本就一致（成功落盘 result_unknown）。恢复路径对这些已落盘形态的判定两侧一致（含无 streamId 的同文案拒绝）。不再扩大到 `validateKnownTerminal` 已校验的字段（序列、result 会话匹配、messages 数组——两侧同为拒绝）。

## 机器判据

`storage::tests::online_admission_strictness_rejects_ts_accepted_inputs`（逐 case 断言 TS 金样 onlineError=null+entryCount=3，Rust 拒绝消息 + 磁盘 2 条 + 恢复 Incomplete，再断言 Rust 对 TS 落盘文件的恢复与 oracle restoreError/recovery 一致）；金样 `deviation-*.jsonl` 与 `oracle.json` `deviationCases`；`#[ignore]` 重建守卫 `operation_ledger_regenerates_identically`；负控 `tests/fixtures/operation-ledger/negative.py` 变体 M5/M6（在线放松 serialize 对象检查、放松 outcome 枚举守卫，断言负控失败）。复算：`cargo test -p pilotdeck-gateway --lib storage::`。
