## 类别

不可避免（已退役）。原条目登记的是「多个 descriptor 的 createdAt 排序且 key 含孤代理时返回 `requires_host` 错误」这一实现限制；#132 把该排序切到 vendored `compare_utf16_preserving_surrogates`、删除 `WorkspaceSnapshotError::HostRequired` 与 `requires_host` 后，本机即可给出 Node 的顺序。本更正登记差异退役与判据替换，不改变原条目其它结论。

## 基线依据

原条目的真实 TS 金样仍是本更正的基线：`src/pilotdeck-gateway/tests/fixtures/workspace-snapshot/oracle.json` 的 `hostBoundaryCases.unpairedSurrogateCollation.tsList`，来自 `resources/PilotDeck/src/storage/workspaceSnapshot.ts` 的 `createdAt.localeCompare` 降序，顺序为 `� →  → \ud800 → 𐀀`（`b-replacement` / `c-pua` / `a-lone-high` / `d-supplementary`）。该顺序与 `native-collation/oracle.json` 在 14 个 locale 上对同一组码位的升序结果互为逆序，说明两条记录描述同一套权重。

## Rust 行为

`src/pilotdeck-gateway/src/storage/workspace_snapshot.rs` 删除了 `keys` / `has_distinct_keys` / `requires_host` 预检与 `WorkspaceSnapshotError::HostRequired` 变体（连同 `impl WorkspaceSnapshotError { fn requires_host }`、`Display` 分支与 `runtime/snapshot.rs` 里投影成 `JS_HOST_REQUIRED` 的映射），`descriptors.sort_by` 改调 `compare_utf16_preserving_surrogates`。孤代理按 ICU4C implicit weight 参与比较，结果为上述 TS `tsList` 的逐字节一致顺序，不再返回错误。

## 范围

原条目的差异范围——多个 descriptor 的 `createdAt` 排序实际触发比较且 key 含孤代理——整体退役；原先「`has_distinct_keys` 为假时不报错」的例外也随之消失。未覆盖：仍直接调用 `collator.compare_utf16(...)` 的其它排序点（见 #132 跟进单，前置于 A8 退役 TS gateway）；transcript 与 archive 两处独立边界另见各自更正。
