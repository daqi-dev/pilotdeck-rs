## 类别

有意改进：Rust 宿主显式拒绝已结束的 run 与已释放 generation 的事件缓冲区访问，不把空事件列表当作关闭成功。

## 基线依据

cc7c4e6 `src/agent/protocol/events.ts:158-164` 的 createAgentEventBuffer 只有 emitter/drain，无 close；`src/agent/modules/transport/sidecarTurnComposition.ts:94-96` 仅传 session/turn。真实完整 TS 模块生成金样：`src/pilotdeck-gateway/tests/fixtures/interaction-events/generate.mts` 与 oracle.json。金样覆盖顺序和消费，无 generation-close API 可调用。

## Rust 行为

`src/pilotdeck-gateway/src/runtime/project/interaction_events.rs` 的 InteractionEvents / TurnEvents：每 session 的后一次 bind_turn 撤销先前句柄（即使 runId 相同）；generation dispose 后 emit、checked drain、bind_turn 明确报错。资源清理清空缓冲区且计数恰好一次。旧代在 registry 租约尚未 drain 时保持有效。普通有效轮次的顺序/消费与 TS 金样相同。

## 范围

仅 with_interaction 发布的独立 InteractionEvents 资源。Interaction 仍是无端口标记；permission/hooks/steer 未绑定。新增 checked drain 为宿主消费接口；旧 EventSink::drain 的兼容签名不能返回错误，#589 必须使用 checked drain。尚未接最终生产 LiveSession，不据此宣称 #586/#589 验收完成。

## 机器判据

`runtime/project/factory_tests.rs` 的 interaction_event_factory_binds_real_buffer_in_both_builder_orders、interaction_event_runs_revoke_exact_handles_and_reject_bad_identity、interaction_event_registry_keeps_old_generation_until_lease_drain；真实 TS oracle 重放，旧 run/错误身份/关闭后访问负控、两 builder 顺序与真实 registry reload/drain。命令：`cargo test -p pilotdeck-gateway --lib interaction_event -- --test-threads=4`（按任务卡设置 CARGO_TARGET_DIR）。
