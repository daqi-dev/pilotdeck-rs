## 类别

有意差异：补齐同 key 串行重建、shutdown registry 清理时机的逐字段登记；未批准，非已接受差异。

## 基线依据

Node v22.22.0、cc7c4e6 的 session-factory/oracle.json fenceMatrix 全48格。twice beforeload/afterload 时 TS registryAfterEvent=2、最终 first/second=3；publish 时 registryAfterEvent=3、最终 first/second=2。shutdown 事件后 TS registry 仍指 old=1，最终 first 报 Session router shut down during session recreation.。closeReturnOrders 保留两个真实返回顺序。

## Rust 行为

same-key 队列使 twice 在第一候选门闩处不另建会话：registryAfterEvent=old(1)，最终 first/second 都是首个新候选(2)。close 排在重建之后，first 先 fulfilled(2)，close 再完成；TS 主门闩格 first 被 scoped-service 缺失错误拒绝。shutdown 在调用时移除 registry，因此 registryAfterEvent=null，first 错误与 TS 完整一致。

## 范围

同 key 排队和提前移除 registry 的现有差异；本轮只补机器比较和登记，不改变 owner 行为。never 格无候选、SESSION_WRITER_BUSY 另归 WRITER-FENCE，不混作本条批准。

## 机器判据

factory_tests.rs::fence_matrix 在真实 boundary/event/result 构造同形观测，以 oracle clone 为底稿，仅按登记字段映射后整对象相等；48个 fence_* 各自独立执行，负控绑定实际 predecessor/registry/results 观测。

## 批准记录

未批准，非已接受差异。前置于 #589 关单；本轮不改变此状态，也不新增评分豁免。
