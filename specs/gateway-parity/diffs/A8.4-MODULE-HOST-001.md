## 类别

传输层差异（待批）：#1349 的 module-host 组件（`/api/module-host/describe`、
`/api/module-host/call`）挂在 #1209 原生监听器的同一 hyper 1.7.0 编解码
后面，继承 A8.4-NATIVE-HTTP-001 已登记的全部帧级/头级呈现差异（头名
大小写、chunk 大小十六进制、HTTP/1.0 状态行、空体 `content-length: 0`），
回放按同一组归一化规则折叠后 87 个 cell 中的 85 个字节一致，另 2 个
（http10 状态行、premature-close）钉死为已登记差异。本条新增登记 1 项
该组件路径上的残余：提前断连（声明了 Content-Length 但体未到齐即关闭）
的解析层应答字节。组件未接线（W0 #1305 拆分发、接线另单），差异仅
影响金样矩阵内被钉死的 1 个 cell，不构成对拍豁免。

## 基线依据

固定基线 cc7c4e653b15c8b2cec7bcf2d15d41d69396ae85，Node v22.22.0。真实
金样 `src/pilotdeck-gateway/tests/fixtures/module-host/oracle.json` cell
`premature-close`（声明 `Content-Length: 100`、体 0 字节即半关）实测：
TS 侧 Node 的 HTTP 解析器在体截断时越过应用层直接写
`HTTP/1.1 400 Bad Request\r\nConnection: close\r\n\r\n` 并关闭——这
是 `node_http_parser` 的罐装应答，`publicHostHttpTransport.ts` 本身一个
字节都没写（其请求体读取路径在 Node 里根本得不到被调用的机会）。
同类先例：A8.4-NATIVE-HTTP-001 第 3 项（裸 400 / `content-length: 0`）
与 CONNECT 的 handler-Err 零字节销毁，均为解析层应答 hyper 类型化
应答 API 无法产生的字节。

## Rust 行为

`src/pilotdeck-gateway/src/module_host.rs`：hyper 把截断体读成 body
error，`serve` 以 handler `Err` 呈现（`PrematureClose` 通道），原生监听
器对该 handler Err 的处理是零字节关闭——连接复位、一个字节不出。
两侧的传输层自身都不写字节（Node 是其解析器替它答，hyper 是其连接
层替它关），残余只是「解析器代答 400」与「零字节关闭」的字节差。

## 范围

仅 module-host 两 endpoint 的请求体读取路径（组件范围，未接线，
`native_process/{requests,services,assembly}.rs` 不受影响）。#1209 路由
兜底的 404 落 A8.4-NATIVE-HTTP-001，不在此条。归一化规则（date 掩码、
头名小写、删空 `content-length: 0`、chunk 大小小写）不折叠本项：该
cell 的应答是关闭行为而非可归一化字节。

## 机器判据

`src/pilotdeck-gateway/src/module_host/tests.rs`：
`premature_close_is_a_zero_byte_close` 钉死 Rust 侧字节（零字节、关闭、
注明 Node 代答 400 为本条残余）；`http10_close_delimited_response` 钉死
继承的 HTTP/1.0 状态行差异；其余 85 cell 逐个 socket 级回放归一化字节
+ closed 标志，`replay_cells_cover_exactly_the_oracle` 断言回放列表 +
钉死列表与 oracle cell 集合相等；ignored
`regenerates_identically("module-host")` 重生成完整金样；
`negative_controls.py` 17 个编译期开关各绑定正控 + 负控锚点 + 恢复
正控，非全 KILLED 退出非零。任何新的未登记差异会被逐 cell 回放或
钉死测试击落。
