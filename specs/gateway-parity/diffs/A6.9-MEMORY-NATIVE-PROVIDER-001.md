## 基线依据

cc7c4e6 `src/context/memory/createEdgeClawMemoryProviderFromConfig.ts:45-75`：缺少配置、disabled 或非 edgeclaw 返回 undefined；启用 edgeclaw 时构造 EdgeClawMemoryService 和 EdgeClawMemoryProvider。启用默认 service 的行为为读码推断，未实测：其构造器读取宿主 OpenClaw 配置及凭据，不在本包隔离探针中运行。

直接 import 基线的实测见本树 `_tmp/20261025-issue-587-pkg1/ts-probe.mjs` 与 `06-ts-probe-final.log`：missing/disabled 不创建；unsupported 经生产规范化产生 fatal；注入 native provider 可被会话 context 调用，dispose 恰调用一次 close。注入成功不代表默认原生 service 已移植。

## Rust 行为

`src/pilotdeck-gateway/src/runtime/memory/mod.rs` 的 `ProjectMemoryBundle::stage` 保留 `NativeProviderNotPorted`：启用默认 edgeclaw 时明确失败，不发布 generation。缺少/禁用配置跳过；应用 providerFactory 和 deprecated createProvider 的实际 resolver 通过 `Resource::Memory` 进入 `ContextStorageResources::create_session`。
