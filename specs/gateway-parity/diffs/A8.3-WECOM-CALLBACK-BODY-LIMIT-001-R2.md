## 范围

监听成功的前提有二：凭据齐备（`corpId` / `token` / `encodingAesKey` 与 `secret` /
`agentId` 均非空——取配置字段或 `WECOM_CORP_ID` / `WECOM_AGENT_ID` /
`WECOM_CB_SECRET` / `WECOM_CB_TOKEN` / `WECOM_ENCODING_AES_KEY` 环境变量回退任一
来源，`wecom_callback/mod.rs:87-136` `STRING_FIELDS` / `config_string`）且端口
bind 成功；**凭据缺失时**（`wecom_callback/mod.rs:257-273` 两处早退）**或 bind
失败时**（`mod.rs:285-288`，`http::listen` Err → 记 error 并返回 `NoopHandle`）
`start` 均记 error 并返回 `NoopHandle`、不起监听，> 1 MiB 的回调到不了该进程，
上限不可达、仍是零用户影响」；「渠道仍未构造」作废（构造经 `production_loader_mounts`
+ `assembly::start` 成立）。
