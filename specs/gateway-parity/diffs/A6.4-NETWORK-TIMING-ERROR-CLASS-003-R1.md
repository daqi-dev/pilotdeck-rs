## 类别

## 基线依据

固定 cc7c4e653b15c8b2cec7bcf2d15d41d69396ae85、Node v22.22.0。
旧 network-timing/oracle.json 的 16 格保持原字节；新增真实 SDK JSON/redirect-json 损坏 gzip

本树 `_tmp/20261026-issue-886/node-golden-expanded.log`。

与实际 SDK body 消费一致；#867 解码器语义不变。

GET/POST × idle/rejected × 四种时机的 TS 断言继续逐格执行；336 格集合不变。
父取消后 TS 完成而 Rust terminated 的四格仍保留，见 POST-HEADERS-PARENT-003-R1。

已知差异守卫仍校验剩余全部条目的 Rust 实际值与 ignore 集合。
