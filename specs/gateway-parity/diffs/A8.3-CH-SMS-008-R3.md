## 类别

更正（`-R2` 的三态归属与未知态登记，非差异变化）：`A8.3-CH-SMS-008-R2.md`
「类别」节第 1 条把三态的归属写反，且没登记 `Unknown` 的实际后果与零覆盖。
三条一起更正，`-R2` 原字节不动。

1. **归属写反**：`-R2` 说「只有 `AddrInUse` 判 `Unshared`（确证 v4 无人
   服务）」。实现与该文件自己的代码块相反：`Ok(()) => Unshared`（bind 成功
   说明 v4 没人服务，调用方回退 `0.0.0.0`）、`AddrInUse => Shared`（v4 已被
   占，`::` 正是双栈，保留 listener）、其余错误与建 socket 失败
   `=> Unknown`（保留 listener）。
2. **`Unknown` 的后果未登记**：只有当 `::` 本身是 v6-only 且 v4 探测以非
   `AddrInUse` 失败时才可达（IPv4 栈关闭、沙箱拦 `socket(2)` 或 `bind` 返
   `EACCES`、fd 耗尽）。此时实现保留只服务 v6 的 listener 并向调用方报启动
   成功，**IPv4 请求不可达**；Node 的 `listen` 会清 `IPV6_V6ONLY`，同一宿主上
   是双栈。这是 fix-r6 用「保留 listener」换掉「降级 v4-only」后留下的另一半
   代价，与第 2 条第三方占用误判同源：探测无法证伪宿主的 v4 可达性。
3. **零覆盖**：22 个编译期开关里没有探测分类项，`v4_port_state` 也没有注入
   缝，`Err(_) => Unknown` 在健康宿主上不可达，故「把 `Err(_)` 改回
   `Unshared`」这类回归不会被任何控制击落。

另：`A8.3-CH-SMS-008.md` 的「Rust 行为」节与原 `-R1` 一样只讲两态（冲突即
双栈、成功即 v6only），本条一并点名，读原条目的人不会仍拿到两态故事。

## Rust 行为

实现零改动（`src/pilotdeck-gateway/src/channel/sms/mod.rs` 的三态与
`bind_dual_stack` 的匹配臂同 `-R2` 引用）。本条只更正登记：

```rust
match socket.bind(address) {
    Ok(()) => V4Port::Unshared,                                   // v4 无人服务 ⇒ 回退 0.0.0.0
    Err(error) if error.kind() == AddrInUse => V4Port::Shared,    // v4 已被占 ⇒ 保留 ::
    Err(_) => V4Port::Unknown,                                    // 探测没跑成 ⇒ 保留 ::
}
// TcpSocket::new_v4() 失败同样 ⇒ Unknown
```

`bind_dual_stack`：`Shared | Unknown => Ok(listener)`，`Unshared => Err`。
