## 范围

新增判分面（全部在 `session_domain.py` retirement 分支内，`RETIREMENT_*` 常量与 `_retirement_*` 函数）：

1. **101 coverage**：每轮 executed 必须与 expected 全等（`COVERAGE`）；`timeout` outcome **不计入 executed**（计 missing，由 `COVERAGE` 抓）且任一 timeout 即触发 `EVIDENCE_BACKING` violation（`timeout lacks wire backing`）——「收请求永不答」的网关不得判覆盖通过（fix-r1，fail-closed；驱动侧 `timedOut` 只认驱动自身超时标记，真实错误消息含 "timeout" 字样不误归 timeout）；stream 形状下**任何非 timeout outcome（ok 与 error）必须有 ≥1 个同 id 的 receive 帧（event 或 response）**，否则 `EVIDENCE_BACKING` violation（`stream {status} without any receive frame`，fix-r2 R1——修复前 error+零接收帧仍判已执行）；驱动 stream 循环遇 `event.type==='error'` 记 error outcome（带 errorCode/message），`ok` 额外要求 `finalSeen===true`（fix-r2 A1）；executed 方法重复出现 FAIL（`DUPLICATE_EXECUTION`）；「统一 unavailable 凑数」FAIL（`UNIFORM_UNAVAILABLE`：全部 outcome 为 error CAPABILITY_UNAVAILABLE）；「透传/编造凑数」FAIL（`EVIDENCE_BACKING`：每个 outcome 必须有同 id 的 send/response(event) 线缆帧，ok↔response.ok 一致）；缺组 `MISSING_GROUP`、缺字段 `MISSING_FIELD`、0 测试 `ZERO_TESTS`、未知 skip `UNKNOWN_SKIP`、驱动非零退出 `ROUND_EXECUTION`，一律 FAIL。轮预算 = 101 × 每方法超时 15 s + 启动余量（fix-r2 A6：网关全挂时逐方法 timeout 判决可达，而非只剩顶层 FAIL）。
2. **入口清单**：HTTP 路由逐条 live 探测（404/不可达 = `NO_HIT`）、channel 监听器静态核验（`STATIC_VERIFIED`）、cron（配置 enabled + cron_* 方法**被应答**——executed 只计 ok/error，timeout 不算，fix-r2 A2）、background（background_* 方法被应答）；任一 `NO_HIT` → entryInventory `BLOCKED`，不静默通过。解析带**最小集下界**（`RETIREMENT_REQUIRED_ROUTES` 13 条 http 路由 + `RETIREMENT_REQUIRED_LISTENERS` 4 个 channel 监听器，fix-r2 R6）：解析缺条 → `BLOCKED`（rule `ENTRY_SOURCE`），不得「解析到几条算几条」地静默缩水分母。配置/凭据门控、轮内不可能命中的入口单列 `GATED`（fix-r2 R7，附门控证据：基线 file:line + 轮内配置缺该项；当前为 `/feishu/webhook`），`unhit` 只收「应当可达却 404」的路由，`GATED` 项留在报告且该面保持 `BLOCKED`，不得变成悄无声息的 PASS，也不自造状态。
3. **无 TS 宿主审计（TS 定标侧口径）**：进程普查（`ps` 中命中「本轮基线路径 + `dist/src/cli/pilotdeck.js`」的命令行必须全部在声明 owned 集内，`HOST_CENSUS`；普查锚定本轮 baseline 路径，宿主机上无关安装（运营者自跑的 PilotDeck、其他 checkout）不计数也不触碰；命中行按 argv 结构复核——argv[0] 须为 node/tsx 且该路径是被执行入口，`grep -rn`/`tail -f` 等命令行不误判为 TS 宿主，跳过行记录在 `census.skipped`，fix-r2 A7）；**fail-closed**（fix-r2 R3）：声明 pid 必须出现在普查 rows 且普查时存活（`declaredAlive`），空样本/死 pid → 非 PASS；网络（lsof established 对端必须全部 loopback，`NETWORK_FALLBACK`；同样 fail-closed：lsof 非零、空样本、未解析行 → `BLOCKED`，不得记 PASS；网络面在报告标注 `samplingScope: 'gateway-pid-only'` 与对端归属（全部属于本轮 gateway pid 自身），避免误读为已覆盖「其它 TS 宿主」，fix-r2 R5）；监听器（`LISTENER_EXPOSURE`，fix-r2 R9：网关必须恰好绑 `127.0.0.1:<gateway_port>`，`loopbackOnly` 为假即 FAIL，参与 hostAudit 聚合）；`JS_HOST_REQUIRED` 静态普查（`src/pilotdeck-gateway/src` 逐 file:line 记录，#132/#1265 的接生产判定属 Rust 侧轮）；native bin TS-upstream 配置审计 NOT_RUN（Rust 侧轮）。
