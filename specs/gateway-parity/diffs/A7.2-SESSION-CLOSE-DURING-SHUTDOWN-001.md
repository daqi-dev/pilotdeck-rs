## 类别

#1011 `SessionOwner` 的 `close` 在 shutdown 进行中的错误语义与 TS 不一致：Rust 返回整个 shutdown 的聚合结果，TS 的 `close` 从不返回 shutdown 聚合。#1215 fix-r2 评审 P1 实测发现并登记；本轮不改 #1011 生命周期代码，用单测钉住当前 Rust 行为并登记差异。

## 基线依据

固定 TS cc7c4e65 + Node v22.22.0 实测（真实 `SessionRouter` + 真实 `asAgentHandle` 会话，key `f` 的 dispose 拒绝 `fixture dispose failure`，与 mcp-gateway 金样 fixture 同款；探针与原始输出 `_tmp/20261026-issue-1215/fix-r2/probe/close-during-shutdown.mts` / `close-during-shutdown.out`，probe1–7）：

- shutdown 期间任意时机调 `close(key)`——同 tick（probe1）、驱动已登记后（probe2）、无关 key（probe3）、从未存在的 key（probe4）、驱逐已结算后（probe5）——均 **fulfilled**（`SessionRouter.ts:327-338`：`sessions` 已被 `shutdown()` 同步清空，else 分支 `await this.closingSessions.get(sessionKey)`，条目未登记/已结算时 await `undefined`）。
- 唯一的拒绝窗口是 shutdown 驱逐 mid-flight（probe7，dispose 被门控挂起时 `closingSessions` 仍持有该条目）：close 拒绝并透传**该 key 自己的** `Failed to dispose agent handle.`（AgentHandle.ts:290 聚合）。
- shutdown 自身才拒绝 `Failed to shut down all agent sessions.`（probe1–7 的一致旁证）；`close` 从不产生该消息。
- 无 shutdown 的普通 close（probe6）拒绝 `Failed to dispose agent handle.`——这正是 #1215 金样两个 close-fault 行的终稿。

## Rust 行为

`runtime/session/owner.rs:674-678`：`close` 在 `state.shutdown` 已置位（`shutdown()` 起始即同步设置）时直接 `wait_result(shutdown)`——返回**整个** shutdown 的结果。任一会话 dispose 失败时（`owner.rs:872` `aggregate("Failed to shut down all agent sessions.", …)`），任意 key 的 close（含从未存在的 key）都答 `Err("Failed to shut down all agent sessions.")`。#1215 网关适配层（`runtime/mcp/gateway.rs` 的 `close`）把该 message 透传为 `SdkMcpError::plain("Error", …)`。

## 范围

只登记读取侧差异与测试锚点，不修改 #1011 生命周期行为。对齐 TS 需要改 `close` 的 shutdown 分支语义（fulfilled / per-key 驱逐结果二态，且驱逐 mid-flight 窗口取决于 `closingSessions` 登记时机），属并发生命周期改动，须先行「状态 × 事件 × 时机」矩阵与全量负控，不在本轮范围；后续接线 PR 若在 shutdown 期间路由四控制方法，应以本条差异为准评估。#1215 的 53 行金样不含 shutdown 格（fixture 不建模 shutdown）。

## 机器判据

默认（非 ignore）测试 `runtime::mcp::gateway_tests::mcp_gateway_close_during_owner_shutdown_surfaces_the_shutdown_result`：ensure-session:f → `owner.shutdown()` → `set_mcp_permission_mode_override`（registry 在 override 路径不 close，组件 close 是第一个碰 owner 的端口），断言错误消息为 `Failed to shut down all agent sessions.`。负控 `close-message-hardcoded`（`src/pilotdeck-gateway/tests/fixtures/mcp-gateway/negative_controls.py`，变异 `runtime/mcp/gateway.rs` close 的 `map_err` 为字面量 `Failed to dispose agent handle.`）绑定该断言必须被杀：shutdown 竞争下字面量永不等于聚合消息。沙箱已证变异可编译且单测以专属消息失败、恢复后字节相同；全量负控由协调者在宿主提交后运行。TS 侧行为以 probe 原始输出为准（读码推断仅用于机制注解：`SessionRouter.ts:327-338` 与 `beginEviction` 的 `closingSessions` 登记/清除）。
