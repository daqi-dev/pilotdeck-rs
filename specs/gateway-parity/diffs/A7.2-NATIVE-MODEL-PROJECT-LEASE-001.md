## 类别与范围

既有 native isolated profile 单项目限制的模型解析边界补齐；不改变通用 Gateway 或 session_model_get 的多项目合同，不增加判分豁免。

## TS 依据

固定 cc7c4e653b15c8b2cec7bcf2d15d41d69396ae85 的 GatewaySessionModelBundle.resolveTurnModelSelection 先解析注册项目，再按该项目读取模型选择。真实 createDialogProjectRegistry、磁盘注册表与模型 policy 的新增17格原件在 `src/pilotdeck-gateway/tests/fixtures/native-model-selection/registry-oracle.json`；key_other、key_home 均为 default。可重跑入口 registry.mts，原始输出位置见同目录 README。

## Rust 行为与机器判据

native submit 的 workspace_id 已只允许 options.project，实际会话 acquire(None) 也只持该项目租约。resolve_model_selection 现在先完成原项目合法性校验，再拒绝与所持租约不符的已注册项目或 General，返回 CAPABILITY_UNAVAILABLE；不能接受 A 项目却读取 B 配置。未知项目仍保持 PROJECT_NOT_FOUND 优先次序。

`native_model_selection_fallback_reads_are_bounded` 驱动独立子进程的 foreign/home 两格验证这一边界；alias/relative 两格验证同项目的词法归一化。其余模型参数矩阵比较原15格和新增14格。此差异不宣称原生进程已能动态服务多个项目。
