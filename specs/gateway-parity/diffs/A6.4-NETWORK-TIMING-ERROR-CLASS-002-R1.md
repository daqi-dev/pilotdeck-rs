## Rust 行为

真实公开 `UrlFetcher` 经测试注入的回环 HTTP transport，接真实 shared
`network::exchange` 的 `ExchangeFuture::io`；保留实际 socket 结果后在 poll 门交错父取消。
`web/fetcher.rs::FetchError::Other` 现在携带 TS `Error.name`：父取消/重试中止经
`From<NetworkFetchError>` 保持 `Some("NetworkFetchError")`，body `Terminated` 保持
`Some("TypeError")`。这 11 格的 TS/Rust 六个 observable 字段现已完全相同。
