# A6.5-MCP-PROXY-SOCKS-001 · MCP / 模型代理：socks5: / socks: 代理 URL 退化为直连

**类别**：行为差异（功能缺失）  
**批准状态**：待批（登记于 #576，理由见下）

## TS 基线

undici 8.3 `ProxyAgent` 通过 `socks5-proxy-agent`（`proxy-agent.js:143`）支持
`socks5:` / `socks:` 代理 URL，建立 SOCKS5 隧道再转发目标请求。

## Rust 现状

`ProxyConfig::new_with_extra`（`src/pilotdeck-gateway/src/runtime/model/http.rs:533`）：

```rust
if proxy.host_str().is_none() || proxy.scheme() != "http" {
    return None;   // socks5:/socks: proxy URL → None → 直连
}
```

`socks5:` / `socks:` scheme 不为 `"http"`，返回 `None`，退化为直连，不报错。
行为与不可解析 URL 相同（`url::Url::parse` 失败时同样 `?` 退出）。

## 差异描述

`socks5:` / `socks:` 代理 URL 下，TS 走 SOCKS5 隧道，Rust 直连目标端点。

## 批准理由

SOCKS5 支持需引入额外依赖（`tokio-socks` 或同类 crate）；#576 对依赖引入有评估要求。
当前直连退化行为有意登记，待依赖评估完成并批准后实现。
