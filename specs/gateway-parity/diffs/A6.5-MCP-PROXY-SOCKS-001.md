## 类别

行为差异（功能缺失）

## 基线依据

undici 8.3 `ProxyAgent` 通过 `Socks5ProxyAgent`（`proxy-agent.js:143`）支持 `socks5:` / `socks:` scheme 代理 URL，建立 SOCKS5 隧道转发请求。

## Rust 行为

`ProxyConfig::new_with_extra`（`src/pilotdeck-gateway/src/runtime/model/http.rs:533`）：

```rust
if proxy.host_str().is_none() || proxy.scheme() != "http" {
    return None;   // socks5:/socks: proxy URL → None → 直连
}
```

`socks5:` / `socks:` scheme 不为 `"http"`，返回 `None`，退化为直连。行为与不可解析 URL 相同（`url::Url::parse` 失败时同样 `?` 退出）。

## 范围

`socks5:` / `socks:` 代理 URL 下，TS 走 SOCKS5 隧道，Rust 直连目标端点。SOCKS5-only 代理环境无法穿透。
