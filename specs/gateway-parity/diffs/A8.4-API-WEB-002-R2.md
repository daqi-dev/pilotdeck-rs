## 类别

更正（计数 + 写路径收口）：原条目「机器判据」节记载
`negative_controls.py` 的 `api-web-nofollow-off` 是「第 7 个开关，共
7 个」——#2354 接线后开关总数为 10（本文件不重复 001-R1 的名单）。
另按 #2354 fix-r1 收口原条目登记的 fail-closed 承诺在写侧的一处破口：
`node_write_refusal` 里残留的 `fs::metadata(target)` follow-stat 预检
（#1764 的 EISDIR 判定）位于 `test_hook` 竞态缝之后、NOFOLLOW 走查之前，
换入根外链接且根外同名叶恰为**目录**时答 500 EISDIR 而非本条登记的
403 `workspace_boundary`（评审 DS concurrency#2 / boundary#2 /
anthropic concurrency#1）。fix-r1 删除该预检：EISDIR 由写自身的
`openat(O_WRONLY)`（armed 走 `overwrite_at`，非 armed 走 `fs::write`）
天然返回，报文字面路径；窗口内换链一律 403，原条目「任何在校验后被
换入的链接都 fail-closed 为 403」的登记自此在写侧完整成立。

## Rust 行为

`src/pilotdeck-gateway/src/api_web/files.rs`：`node_write_refusal`
（`:849`）只保留 NUL 参数校验（先父目录后全路径，与 TS 的
`mkdir`→`writeFile` 参数校验序一致）；EISDIR 不再预检——armed 走查
`write_beneath`（`:365`）里 `overwrite_at` 的叶 `openat(O_WRONLY)`
对目录天然回 EISDIR，`path: "."` 一类落在钉住根本身的形态由
`:386` 的空 beneath 特判以同一 Node 文案拒绝，非 armed 形态由
`fs::write` 自身回。报文一律用 `resolve_safe_writing` 的**字面**
target（TS 参数拼写），不再用 `canonical_prefix` 解析后的路径。
负控联动：`api-web-node-write-refusal-off` 自 fix-r1 起绑 NUL 路径
探针（见 001-R1），`api-web-nofollow-off` 增绑第 9 条探针
`write_rejects_a_component_swapped_to_an_outside_directory_leaf`
（`tests.rs:1435`，换链指向根外目录叶，断言 403）。

## 范围

仅写路径的错误分类与报文拼写：①竞态窗口内换入链接指向根外目录叶
从 500 EISDIR 改为 403 `workspace_boundary`（写出本就失败关闭，
无逃逸面变化）；②目录目标（含 `path: "."`、根内目录符号链接目标）
的 EISDIR 报文路径从 canonical 解析形改为字面形。四个既有 #1764
测试（根写、子目录写、NUL、嵌套 NUL）字节不变——夹具根是 canonical
的且字面 == 解析形，短路径渲染两侧一致。读/枚举路径与原条目登记
不变；EISDIR 之外的 Node 诊断、`refusal` 的 ELOOP→403 映射不变。
