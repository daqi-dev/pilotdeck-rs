## Rust 行为

`runtime::session::factory::tests::same_key_ticket_blocks_before_publication` 使用无文件 I/O 的工厂、首创建 semaphore gate、Tokio paused clock。第二个 owned task 必须被 poll 后虚拟截止才会到达；首个尚未发布时第二次工厂进入信号必须未到，prepare=1。放行后两者复用同 identity。分别覆盖保留首 caller 与 drop 首 caller（owned creation 继续）两格；前驱在整个观测窗口不完成，只在观测后显式放行作清理，所有等待有界。
