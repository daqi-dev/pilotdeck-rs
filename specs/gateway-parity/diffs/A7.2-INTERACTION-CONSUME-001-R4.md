## 类别

bug 修复（纠正入口混同的行为描述与验收缺口）。#750 ③ 的「TS 一律静默丢弃」推断不能用于放宽 wire 校验；本更正保留已与实测一致的 Rust 行为。

## 基线依据

固定 cc7c4e6、Node v22.22.0，完整原模块内存执行，仅追加私有导出，不手抄实现。生成器及72格金样：`src/pilotdeck-gateway/tests/fixtures/sidecar-payload/`；原始输出 `_tmp/20261026-issue-822/ts-corrected.log`。

`protocol.ts:330-335` + `agentLoopSidecarClient.ts:567-569,660-684`：真实握手后的 wire 普通/final 非对象 payload 均报 `MISSING_EVENT_FIELD / Event sequence, final, and payload are required.`，不消费后继；并非丢弃继续。绕过 wire 直接调用 `readAgentEvent:1310-1317` 也报 `Sidecar event payload is not an AgentEvent.`。`readFinalTerminal:1338-1350` 报 terminal payload 错误；仅 cancelled + 已取消原因为 compaction_persistence_failed 的私有 reader 合成 aborted，真实 wire 仍先拒非对象。

`hostAgentEventBridge.ts:35-49` → `sidecarDefaultModuleDispatcher.ts:197-201,471-483` 是另一入口：event.emit 拒坏 event 后，bridge 吞已知调用失败，合法后继继续投递。该行为不适用于 wire 或 Rust 的 StreamHandler 内部应用回调。

## Rust 行为

`pilotdeck-protocol/src/module.rs::validate_module_message` 保留 wire 拒绝；`runtime/turn/live.rs::StreamHandler::event` 保留非 final 非对象拒绝、final 委派 inner，不把测试 fake inner 的接受称为终态 parser 接受。`host/modules/event.rs` 保留模块拒绝；`pilotdeck-transport/src/notifications.rs::InstructionBridge` 保留已知负响应后继续。路径均相对于 `src/`（gateway路径位于 `pilotdeck-gateway/src/`）。本单只更正产品注释并补回放/负控，无产品行为变更。

## 范围

缺失、undefined、null、boolean、number、string、array 与合法对象正控；按 wire-event / wire-final / embedded-reader / terminal-reader / terminal-cancelled / host-bridge 区分。两个私有 terminal reader 是诊断入口：Rust 的真实非对象 wire 输入在 decoder 前置拒绝，不新增绕过生产校验的入口。不涉及 #821 pump、心跳、身份或对象内容合法性，也不关闭 #589 / A7.2 实效验收。
