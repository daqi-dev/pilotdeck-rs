## 类别

不可避免（保守回退引入的已知向宽差异）。`html_compat` 只建模旧 `in select` / `in select in table` 与 `<search>` 改名两条规则；foreign content（`<svg>`/`<math>` 根及其 integration point）、`PLAINTEXT`、script data escaped / double escaped 这三种结构会改变 tokenizer 状态或 select 上下文，本模块不再逐个补 tokenizer 状态，而是在第一个未建模结构处停止改写，把剩余字节原样交给 html5ever。停止改写后 html5ever 的现行规则与 domino 2.2.0 仍可能不同；本条只登记这些残留差异，不声称已对齐。

## Rust 行为

`src/pilotdeck-gateway/src/runtime/tools/builtin/web/html_compat.rs`：

- `:126` 主循环在发出当前标签前调用 `unmodelled`；命中时 `:127` 把 `html[i..]` 原样追加并结束改写。
- `:245` `unmodelled`：非 select 上下文里的非自闭合 `<svg>`/`<math>` 根、`<plaintext>` 起始标签，以及任意上下文里会进入 script data double escaped 的 `<script>`。
- `:307` `script_enters_double_escape`：只把 `<!--` 之后、`-->` 之前出现 `<script` + 分隔符（tab/LF/FF/CR/space/`/`/`>`）视为 double escape；普通 `<!--`（未闭合或已闭合）不触发回退，`<style>` 是 RAWTEXT、无 escapes 态，也不触发。
- `:370` `closes_select_in_table`：旧 `in select in table` 关闭集只含 caption/table/tbody/tfoot/thead/tr/td/th；表作用域跟踪只数真正打开的 `<table>` 元素（`<tr>`/`<td>`/`<th>`/`colgroup`/`col` 等不计数），所以关闭集里的非 table 标签关闭 select 但不改变深度。

回退点之前已经按旧 select/search 规则改写的前缀保持原样；回退点之后不再丢标签、不再改名。

## 范围

仅覆盖「在第一个未建模结构之后仍有需要旧规则改写的 `<select>`/`<search>`」且实测与 TS 不同的输入形状，即上表六类：foreign 根之后的选择器、double-escaped script 之后的 `<select>`、以及 double-escaped script 位于 select 内时其后的 `<h1>`。不覆盖：

- foreign content 本身的 `<select>`/`<search>`：`foreign-svg-select-hr`、`foreign-svg-select-h1`、`foreign-svg-select-img`、`foreign-svg-select-table`、`foreign-svg-select-option-hr`、`foreign-math-select-hr`、`foreign-p-svg-select`、`foreign-svg-space-slash`、`foreign-svg-unquoted-slash` 已逐字节对齐；
- integration point：`foreign-svg-foreignObject-select-hr`、`foreign-math-annotation-select-hr` 已对齐；
- PLAINTEXT：`plaintext-html-after`、`plaintext-script-label` 已对齐（PLAINTEXT 之后全部是文本，回退即 TS 结果）；
- colgroup/col：`table-select-colgroup-h1/option/nested-select` 已对齐；
- 自闭合 foreign 根与 select 内的 `<svg>`/`<math>`：`control-foreign-svg-selfclose`、`control-foreign-svg-quoted-slash`、`control-svg-inside-select` 证明不会误回退。
