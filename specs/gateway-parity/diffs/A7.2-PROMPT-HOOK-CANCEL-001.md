## 基线依据

cc7c4e6 TurnRunner.ts:230-241,443；Node v22.22.0 真实 TurnRunner + HookRuntime + LifecycleRuntime 探针 `src/pilotdeck-gateway/tests/fixtures/turn-prompt-hooks/generate.mts`。金样 abort-pending / drop-pending：callback 不处理 abort 时，abort 和 generator.return 均不能结束未完成的 next；显式放行 callback 后 next 才交付 user_prompt_submitted，return 才结束，无 loop/complete。原始记录 `_tmp/20261026-issue-741/prompt-ts-boundaries.log`。

## Rust 行为

Recording 保留 prompt transition，因此取消单次 next 借用不重入 hook。取消整个 turn 则中断等待 hook，释放其 dispatch future，复用现有 execute 前 aborted_streaming 收尾；真实 TurnHooks 撤销绑定并清理正在执行的命令。Drop 整个流取消 transition、无可见终态，也不补写 turn_result；下一轮仍通过旧 TurnHooks 的清理屏障。

## 范围

只覆盖 accepted 后 UserPromptSubmit pending 期间取消/Drop。正常 pass/block/callback throw/timeout/dispatch reject 的事件及 transcript 按 TS 金样对齐。SessionStart/Setup/End、steer、artifact、metadata/title 不在本切片。既有执行前取消、Drop 完成语义分别参见 A7.2-TURN-ABORT-001 与 A7.2-LIVE-DROP-COMPLETION-001；本项扩展到 prompt dispatch 等待窗口。
