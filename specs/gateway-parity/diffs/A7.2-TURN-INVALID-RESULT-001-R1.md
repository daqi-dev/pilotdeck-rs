## 基线依据

缺 sessionId 以及 sessionId=42/null/false/数组/对象时 TS 仍写 success 终态；缺 turnId（含 own Undefined）与旧 number/array 整体 result 一样静默 dedup，不闭合 step/turn。Undefined 整体 result 抛读取 turnId 的 TypeError；turnId=42/null/false/数组/对象时抛 `Durable turn <JS String(value)> has not started.`；turnId 自带非 callable toString 时抛 `Cannot convert object to primitive value`。后两类使用原身份进入 catch 闭合 turn。

## Rust 行为

保留原条目错误终态策略。缺失/非法 sessionId、缺 turnId 使用 `agent_invalid_state` / `Turn result identity mismatch.`，关闭原身份 step/turn，并产出唯一 error 终态。Undefined 和非字符串 turnId 对齐 TS 实测错误文案；复用既有 JS UTF-16 字符串转换器（其极深数组边界沿用 A6-JSVALUE-DEPTH-001，不新增深度一致性声明）。I/O 持续失败仍返回错误，不伪造完成。

## 范围

仅独立 TurnRunner 已成功 start/accept→Complete（TS startTurn:142 清空完成标记；不覆盖 turnAlreadyStarted 跳过 start 或另一轮交错完成），低层 Recorder 对象调用合同不变。量化差异为旧 number/array/session 六格，以及缺 session/turn 和 sessionId 五种非字符串值及 own Undefined turnId 的十六格。量化对齐为旧 null/other-turn 四格，加 Undefined 与 turnId 六种非字符串值的十四格，另有孤立 surrogate 字符串 turnId 两格。缺失字段指 own 字段缺失；自定义 prototype、getter、显式 Undefined sessionId 字段和任意组合未由本更正宣称逐格验收。完整 LiveSession/StreamIntegrity 接线不在本独立交付范围。
