## 类别

判据登记缺项（机器判据与实现同步；冻结装置判分登记，非产品行为差异）：基础条目
`A8.6-RETIREMENT-001.md` 范围 §5 只登记了「轮预算超限（`subprocess.TimeoutExpired`/
`TimeoutError` → `ROUND_BUDGET`）→ 全 16 判分面 BLOCKED、报告不塌键」，没登记
**任何采集期 `EvidenceError`**（HOST_CENSUS / ROUND_EVIDENCE / CLEANUP /
PORT_CONFLICT / ENTRY_SOURCE 等规则）与采集期形状错误
（KeyError/TypeError/AttributeError/ValueError/OSError）同样以该 rule 输出
全 16 面 BLOCKED。该行为由 #1355 r1 收口轮实现（`session_domain.py`
`retirement_report` 包装层）；本更正把机器判据与实现同步，不改阈值、分母、
场景、比较器、归一化。

## 范围

- 规则集：HOST_CENSUS / ROUND_EVIDENCE / CLEANUP / PORT_CONFLICT /
  ENTRY_SOURCE 等采集期 `EvidenceError`；采集期形状错误（KeyError/
  TypeError/AttributeError/ValueError/OSError/RecursionError）→
  `ROUND_EVIDENCE`；fix-r6 增 MemoryError（采集期内存耗尽不塌报告，
  DS r5 concurrency）。
- 报告仍输出全部 16 判分面：methodCoverage / entryInventory / hostAudit /
  controls / coldRestartRollback = BLOCKED 或 NOT_RUN，
  executionStatus=BLOCKED，expected / executed / rounds / topology /
  portAudit / processAudit / cleanupAudit / baseline / reason / failure
  均在。
- 不改：k=5、分母、归一化、比较器、差异账本；`ROUND_BUDGET` 既有语义与
  基础条目原登记不动。
