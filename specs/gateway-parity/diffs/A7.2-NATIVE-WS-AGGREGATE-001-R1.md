## 类别

安全修复范围更正：#1079 fix-r1 将完整帧解码后的待处理文本也纳入跨连接输入预算。
原条目仅计 decoder backing，排除业务输入，允许最多 64 连接 × 64 pending × 100 MiB
的文本在宿主等待而不计费（该乘积是上界推算，并非实际分配试验）。本更正不回写原条目，
不修改冻结尺子或默认代理。

## 基线依据

固定基线 cc7c4e653b15c8b2cec7bcf2d15d41d69396ae85，Node v22.22.0。
`src/gateway/server/websocket.ts:53–79` 先消费完整帧再同步投递文本；
`GatewayWsConnection.ts:74–115` 的 hello 授权早于 describeServer await，
普通请求不因 socket close 而取消。
真实 `native-ws-caps/generate.mts` 对 GatewayServer 实际构造的 transport 发确定性 data 回调，
逐个业务 gate 挂起 4 个完整 1 MiB 文本：entered=4、buffered=0、closed=false；
完成一项后 pending=3，关闭 socket 后仍 pending=3，释放其余 gate 后 completed=4。
金样 `src/pilotdeck-gateway/tests/fixtures/native-ws-caps/oracle.json`；原始输出
`_tmp/20261026-issue-1079/fix-r1/ts-probe.log`。不以 RSS/GC 推断物理存储。

## Rust 行为

每 NativeWsServer 的 256 MiB semaphore 同时计入 decoder backing 和已解码、已准入的
待处理文本 UTF8 字节。String 分配前计算 invalid UTF8 replacement 后的精确长度并预留。
预留与原 backing 同时占额，因此预算也覆盖这两份存储重叠的窗口；失败只关闭争用连接，
code=1009、reason=`aggregate input limit exceeded`，不等待前驱释放。

`HostedConnection::enqueue_with_input_permit` 将 String 和许可一起交给宿主作业，覆盖队列等待、
同步 receive prefix 和业务 await。完成回执发出前先释放输入再退费；入队失败、宿主取消时
按同一字段顺序释放。丢弃 admission/completion waiter 不取消独立宿主作业，也不提前退费。
物理 EOF / 协议关闭先退 decoder，仍运行的业务请求继续计账；业务完成或宿主真实取消才退，
完整连接 drain 结束后全部归还。沿用 #749 有界 drain，不通过取消业务来假装释放输入。

## 范围

更正原范围中排除“已解码 payload、业务请求”的表述：持久待处理文本已纳入同一个跨连接预算，
包括 host 作业队列和 `requests` 等待期间，直到其实际业务完成或取消。
这仍不是进程 RSS 上限：短暂解码 payload Vec、JSON 解析后的业务对象及业务自身创建的副本、
分配器元数据、每连接 8 KiB 读取块与输出不按物理字节计入；每项 pending 在整个业务生命周期
持续占用其输入文本字节的预算，不能靠 decoder 清空或 waiter 取消绕过。
新旧 backing 和文本预留重叠可能提前拒绝稳态可容纳的请求，这是无等待资源准入的取舍。
只影响 opt-in loopback NativeWsServer；不同实例预算独立，公共无预算 HostedConnection::enqueue
及单帧上限保持既有语义。

## 机器判据

`native_ws::caps_tests::complete_large_requests_share_aggregate_budget` 在宿主业务挂起时连续发送
三个完整大帧，验证共享余额、独立 ping、第四帧争用 close1009 与完成后退款。
`completed_request_refunds_before_waiter_reap`、`eof_releases_input_before_pending_business`、
`pending_requests_release_on_shutdown_and_abort` 覆盖正常完成、EOF 保留业务收费、drain/abort 取消。
`runtime::turn::gateway::tests::native_ws_queued_input_outlives_cancelled_admission_waiter`
以专属宿主 gate 验证队列阶段 caller 取消和关闭宿主入队失败。
`lossy_request_reservation_matches_node_bytes` 对拍 Node replacement 样本；
既有 ignored `regenerates_identically("native-ws-caps")` 守卫完整金样。
caps negative_controls 为新增分支配单点变异，逐项 no-run、正控、nonce 负控、恢复正控后汇总，
共享执行/回执模块均列入 HEAD 守卫，未提交源码不绕过该守卫。
