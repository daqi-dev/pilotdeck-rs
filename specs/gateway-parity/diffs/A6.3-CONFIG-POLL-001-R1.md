## 类别

更正件（#1791 / #1819 第 16 条）：只更正原条目 A6.3-CONFIG-POLL-001 的描述与判据文字，不改变其登记范围，不新增偏离条目，不增加任何判分豁免。原条目本身仍是「实现限制（宿主文件监视机制）」：`fs.watch` 被轮询采样替代。

## 基线依据

同原条目：`pilot/config/PilotConfigStore.ts:107-139` 对现存路径/缺失路径的 parent 使用 `fs.watch`，通知后 debounce（默认 250ms）；事件驱动，任何一次写入都产生事件。固定基线 cc7c4e653b15c8b2cec7bcf2d15d41d69396ae85。

## Rust 行为

更正原条目「默认每 20ms 采样 metadata 和至多 CONTENT_SAMPLE_LIMIT 的文件内容，再 debounce」一句：#1739 起每次采样**先取 metadata-only 指纹，与上次相同就不读内容**，只有 metadata 变化（或一次不完整采样，#1792）才走到内容读（被监视配置文件本体至多 1 MiB，其它目录项与超限文件始终只按 metadata）。该「内容变了、metadata 未变」的漏检格由 `A6.3-CONFIG-METADATA-SHORTCUT-001` 单列登记（其更正件 `A6.3-CONFIG-METADATA-SHORTCUT-001-R1.md`），本条不再覆盖。

另两句口径更正（#1736 / #1792 引入，不构成新的可观察差异）：

- 去抖上限 1 h（`effective_debounce`）已由 `A6.3-CONFIG-DEBOUNCE-CEILING-001` 登记，不属本条；`poll_interval` 的 10 ms – 60 s 夹取是纯实现细节，TS 侧没有对应旋钮，不构成新的可观察差异。
- #1792 修复后「读失败被当成内容未变」不再属于本条口径：一次 stat / `read_dir` / 内容读失败算**不完整采样**，不提交 metadata 指纹，下一 tick 重试直至完整样本落地；读恢复后无需 metadata 变化即可补报。

## 范围

同原条目：仅 watcher 触发的 reload 次数、时机、version/changedPaths；手动 reload 不受影响。净零遗漏的触发条件更正为「**采样间内容与采样 metadata 均相同**才不触发 identity reload」；「内容变了但 metadata 未变」的漏检格已由 `A6.3-CONFIG-METADATA-SHORTCUT-001` 单列，本条不再覆盖。大文件超出内容样本、目录其它项只按 metadata，不保证所有文件系统均能发现瞬态变化（同原条目）。

## 机器判据

同原条目：`tests/config_store.rs::config_store_replays_real_typescript_oracle` 保障已覆盖 reload 行为；真实短突发验收须在同一文件系统记录 `fs.watch` 通知和 Rust 采样时间线，比较 version 和 changedPaths，尚未穷举 tick 相位 / ctime 粒度。补两点：

- 轮询上限与去抖上限的行为由 `config::store::tests` 的 `huge_poll_interval_is_clamped_and_keeps_sampling`（含 `MAX_POLL_INTERVAL == 60 s` 字面 pin）、`two_hour_debounce_is_clamped_to_the_one_hour_ceiling`、`overlong_debounce_is_clamped_and_reloads_within_the_bound`、`overflowing_debounce_does_not_kill_the_watcher` 钉住，负控绑定见 `tests/fixtures/config-store/negative_controls.py` 的 `poll-ceiling-removed` / `two-hour-debounce-ceiling-removed` / `debounce-ceiling-removed` / `overflowing-debounce-double-restore` 行。
- 不完整采样的重试语义由 `config::store::tests::transient_read_failure_is_retried_until_the_content_is_seen` 与 `startup_read_failure_is_retried_until_the_content_is_seen` 钉住（负控行 `incomplete-sample-committed` / `startup-incomplete-committed`）。

复算命令（树根）：`LANG=en_US.UTF-8 cargo test --manifest-path src/Cargo.toml --offline -p pilotdeck-gateway --lib config::store::tests`；负控 `LANG=en_US.UTF-8 python3 -I src/pilotdeck-gateway/tests/fixtures/config-store/negative_controls.py <新证据目录>`。
