## Rust 行为

`runtime/plugins/loader.rs` 的 StyleBudget 沿用 native 请求共享64MiB读取字节与10000条目限额：目录枚举每个 entry 计一项，manifest 每次实际读取的字节计一次。`loader/native.rs` 在创建 JsValue 树前进行有界词法预检；JSON容器与标量值各计一项，key字符串不计，重复key出现的每个值都计入，忽略 metadata 同样计入。预检不建立第二棵树；合法语法与字符串含义仍由既有 codec 校验。输入达到限额可通过，超过任一项返回 `STYLE_RELOAD_LIMIT` 并拒绝整个本次 native staging，旧 publication 保持。有限额的无效JSON可能先得到资源拒绝，不承诺其与无界JSON.parse错误优先序一致。

一次 native staging 每个 manifest 读取、解析和计费各一次；已解析结果传入贡献加载，不以“校验+加载”重复收费。仅一个目录项的单插件 `{"name":"p","ignored":[0,...]}`：9996个scalar使共享条目总计10000，可通过；9997个使总计10001而拒绝。无其他文件/贡献时64MiB合法manifest可通过，64MiB+1拒绝。该精确边界随其它实际目录项/文件读取共同消耗，不是每插件独立配额。

容器深度沿共享 `crate::js_value::MAX_ARRAY_DEPTH`，超限返回 `NATIVE_PLUGIN_DEPTH` / `Maximum call stack size exceeded`。manifest/hook文件的描述符为NONBLOCK/NOFOLLOW；目录等普通文件读取错误依TS staging/catch处理；FIFO/socket/device和已识别的链接换入拒绝为 `NATIVE_PLUGIN_UNSAFE`。静态合法路径别名与显式外部hook regular文件仍可读。特殊文件向安全偏离不冒称普通TS错误等价。
