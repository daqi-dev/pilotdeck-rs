## 类别

bounded-work

## 基线依据

SkillManager.scan 调用 buildSkillScanFolder 时，对每个含 SKILL.md 的目录执行 `fs.readdir(dir, {recursive: true})` + 逐条 stat，累计文件数与总大小。TS 实现无上限：自指链接导致指数扇出，实测不终止（OOM 或超时）。

基线：`OpenBMB/PilotDeck@cc7c4e65`，出处 `src/extension/skills/SkillManager.ts:674-692` buildSkillScanFolder 的 tree_files 循环。

## Rust 行为

Rust 实现增加累计 listed 条目总数上限 **8,388,608**（0x80_0000，产品常量 `TREE_FILES_CAP`）。超限返回显式错误 `tree_files_limit_exceeded`，经 scan_folder 传播给 scan 调用方。

实现：`src/pilotdeck-gateway/src/skills/import.rs:218-262` tree_files_capped。每次 `listed.push(path)` 后立即检查 `listed.len() > cap`，超限返回 `SkillError::manager("tree_files_limit_exceeded", ...)`。

scan_folder 调用 `tree_files_capped(dir, TREE_FILES_CAP)?`，错误经 `?` 传播；scan 调用 `scan_folder(&path, &name)?`，错误继续传播至调用方。

测试通过参数传入小值覆盖边界，避免全局 static 导致并发测试干扰。

## 范围

| 输入 | TS 行为 | Rust 行为 | 一致性 |
|---|---|---|---|
| 正常技能目录（<10K 条目） | 返回计数 | 返回计数 | 逐值一致 |
| dag-10（3071 条目） | 返回 1024 文件 | 返回 1024 文件 | 逐值一致 |
| dag-15（98303 条目） | 返回 32768 文件 | 返回 32768 文件 | 逐值一致 |
| dag-20（131071 条目，全 ELOOP） | 返回 0 文件 | 返回 0 文件 | 逐值一致（仅列根 SKILL.md） |
| 自指链接 | 不终止（timeout/OOM） | 报错 tree_files_limit_exceeded | **向安全偏离** |
| 超 8M 条目 | 不终止或返回（取决于内存） | 报错 tree_files_limit_exceeded | **向安全偏离** |

动机：TS 在自指链接输入上不终止（#547 实测 RSS > 2 GB 被杀）。8M 上限远大于正常技能目录（常见 <1000 条目），足够 TS 能完成的输入（dag-15：98303 条目正常返回），同时有界拒绝病态输入。

## 机器判据

测试：`cargo test -p pilotdeck-gateway --lib skills::import::tests`

夹具生成器：`tests/fixtures/skills-tree-files/generate.mts` 带溯源守卫（baseline commit 与 sourceSha256 校验），跑两次逐字节一致。
