## Rust 行为

`native_process/assembly.rs` 的同一生产装配先实际 dispose session factory，再实际 dispose project registry。测试观察器在实际 dispose 返回后注入故障或门闩，不替代资源。
双错误时两项都会调用，project 错记录到 stderr，返回 session 首错；仅 project 失败则返回 project 错。session 永不完成仍由已有 host drain deadline 返回明确错误。成功/失败返回值与 TS 吞错策略仍存在差异。

## 范围

只覆盖显式 `--native` 的上述生产资源清理及既有有界关闭；A4 默认路径和冻结阈值不变。TS 的 session MCP registry 与 Rust 的 session factory 不是同一个实现类，此矩阵验证两项资源的装配顺序及失败处理，不能外推所有资源内部行为。
