## 类别

不可避免（暂未接线）。Rust ledger `open` 的校验范围对齐 TS Ledger 构造器（不跑域校验）；TS 完整恢复链里属于 `SessionRuntime.restore` 的 `validateSessionDomainLog` 尚未接入 ledger 打开路径，接入是后续 host/runtime 接线 PR 的前置事项。

## 基线依据

cc7c4e6 的 `src/session/events/SessionRuntime.ts:108-117`（`restore()` 依次跑 `validateSessionEventLog` + `validateSessionDomainLog`）、`src/session/events/SessionDomainValidation.ts:76`（`validateSessionDomainLog`）、`:112`（`isDomainEntry` 跳过非域条目）、`:662-689`（域条目类型表）；而 `src/agent/modules/transport/sessionOperationLedger.ts:37-39` 的 Ledger 构造器只跑 `restore(entry)` 循环（`:193-237`，仅信封+身份+终态形状），不跑域校验。实测（Node v22.22.0 + 基线 tsx 4.22.3，`_tmp/20261026-issue-201/probe-run-2.out` T5）：started+tool_call 的 transcript 在 TS `SessionRuntime.restore` 抛 `tool_call requires an active turn turn-1.`，而真实 TS Ledger 构造器接受。金样：`src/pilotdeck-gateway/tests/fixtures/operation-ledger/domain-invalid.jsonl` 及 `oracle.json` `domainScope`（`runtimeRestoreError` 非空、`ledgerConstructorError` 为 null）。

## Rust 行为

`src/pilotdeck-gateway/src/storage/ledger.rs` 的 `open` 只跑 reader 信封校验 + ledger 恢复循环（与 TS Ledger 构造器同范围），`domain-invalid.jsonl` 可打开且 `recover` 为 Incomplete；域校验器本身已移植在 `src/pilotdeck-gateway/src/storage/session_domain.rs`（`DomainState::next`，含 `DOMAIN_TYPES` 类型表，`transcript_adapter.rs:1085-1111`），对同一 log 以 `tool_call requires an active turn turn-1.` 拒绝，与 TS 同文案。接线（打开时对恢复条目跑域状态机）留给接入 host/runtime 的后续 PR，该 PR 必须先消除本条。

## 范围

仅「打开 ledger 时是否运行会话域校验」这一接线范围。事件日志层校验（信封、序列、entryId 链）两侧一致；ledger 存储契约（start/accept/terminal/result_unknown/recover）两侧一致。受影响输入：含域非法条目（如 turn 外 tool_call、turn 重复等）但信封合法的 transcript——Rust ledger 层当前可开（同 TS 构造器），调用方若需要域级保证须自行运行 `DomainState`；接入后由接线层统一拒开。本条不是对域校验语义的偏离（`session_domain.rs` 与 TS 逐条一致，见 A6.2-TRANSCRIPT-DOMAIN-001 及其金样），只是未接线范围的登记。

## 机器判据

`storage::tests::ledger_open_skips_domain_validation_like_the_ts_constructor`（ledger 层按 TS 构造器范围打开 + `DomainState` 对同一 log 以 oracle 记录的 TS 文案拒绝）；金样 `domain-invalid.jsonl` 与 `oracle.json` `domainScope`；`#[ignore]` 重建守卫 `operation_ledger_regenerates_identically`；负控 `tests/fixtures/operation-ledger/negative.py` 变体 M8 `domain-skip-tool-call`（删 `transcript_adapter.rs` `DOMAIN_TYPES` 类型表中的 `tool_call` 项，绑定上述测试里 `DomainState` 折叠必须报错的 `#201 the domain-invalid log must fail domain validation` panic，断言负控失败；ledger 打开路由本身无变体——无接线路由变更，接线前的范围登记）；域校验器自身的负控沿用 `tests/fixtures/session-domain/negative.py`、`adapter-negative.py`。复算：`cargo test -p pilotdeck-gateway --lib storage::`。
