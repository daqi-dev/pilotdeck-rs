## 类别

向安全偏离。R2 的「范围」写明「独立技能 SKILL.md 不在本条范围（见 #594）」。#594 把独立技能 SKILL.md 的读取改为与插件三类贡献相同的加固路径（`read_markdown`：`open_beneath` 逐级 NOFOLLOW + 打开后句柄复核），本更正补登由此产生的对 TS 可观察差异。原条目与 R2 其余内容不变。

## 基线依据

cc7c4e6 的 `src/extension/plugins/loading/PluginCommandLoader.ts`：`loadStandaloneSkill`（:33-43）`readdir` 后按 `/^skill\.md$/iu` 取名，`loadMarkdownContribution`（:64-77）在 :68 按词法路径 `readFile`，枚举与读取之间不复核、跟随符号链接；`PluginLoader.ts:14-27` 的 `loadSkillFromPath` 把它包成单技能插件。独立技能是单文件：`readFile` 失败即 Promise 拒绝，整个技能加载失败（无「跳过」粒度）。真实 TS 金样 `src/pilotdeck-gateway/tests/fixtures/plugin-loader/standalone-toctou.json`（生成器 `generate-standalone-toctou.mts`，源码身份守卫覆盖 `PluginCommandLoader.ts`，两次生成逐字节一致）：把 SKILL.md 换成指向根外的符号链接（leaf-symlink）或根外文件的硬链接（leaf-hardlink），TS 读到根外内容 `SECRET`；换成根内符号链接（in-root-symlink）TS 跟随读到根内目标 `# In-root target`；FIFO（static-fifo）TS readFile 阻塞（1000 ms 探针截止仍未返回）；socket（static-socket）TS open 失败（`Unknown system error -102`，syscall open），整次加载被拒；`readdir` 成功后、`readFile` 前删除 SKILL.md（deleted-after-check）TS readFile 拒绝为 ENOENT / open。未改的正常 SKILL.md 读到 `# DOCX skill`。既有 `plugin-loader/oracle.json` 的 `skills-root-only` 另记：SKILL.md 本身是目录时 TS readFile 报 EISDIR（illegal operation on a directory, read）。

## Rust 行为

`src/pilotdeck-gateway/src/runtime/plugins/loader/markdown.rs` 的 `load_standalone_skill`：仍先 `sorted_entries` + `is_skill` 定位 SKILL.md（无 SKILL.md 时报 `Standalone skill '…' has no SKILL.md.`，与 TS 同），随后 `read_checked_skill` 复用 `read_markdown`（与插件三类贡献同一函数，不复制逻辑）。`read_checked_skill` 先取 skill 目录与叶的 canonical 并取检查时 (dev,ino)；叶解析为目录（或指向目录的链接）时保留 TS 的 EISDIR（目录读取不会泄漏根外字节）；其余交 `read_markdown` 逐级 NOFOLLOW 打开、打开后按检查时 (dev,ino) 与类型复核。单技能无可跳过的兄弟：`read_markdown` 返回 `Ok(None)`（根外链接 / ELOOP、FIFO / socket / 设备、换入其他 inode）即整技能失败，产出按 Node readFile 形态的 EACCES（`node_io::read_file`）；返回 `Err`（如检查后删除的 ENOENT）按 TS 原样传播；根内链接则跟随读取、与 TS 一致。命令路径（`path` 字段）保留词法 `directory/SKILL.md`，与 TS `join(skillDir, entry)` 一致。仅 Unix；非 Unix 保持原按路径读取。

## 范围

独立技能（`loadSkillFromPath` → `loadStandaloneSkill`）的单个 SKILL.md 读取。可观察差异：① 检查后（或静态）叶被换成根外符号链接、或换成其他 inode 的硬链接：TS 读到根外 / 被换入内容并返回技能，Rust 整技能失败（EACCES）；② FIFO SKILL.md：TS readFile 阻塞，Rust 整技能失败且不阻塞；③ socket SKILL.md：TS open 失败拒绝整次加载，Rust 整技能失败（两者都整技能失败，错误码不同）。与 TS 一致、非偏离的两条：④ 检查后删除 SKILL.md：TS 与 Rust 均 ENOENT 使整技能失败；⑤ SKILL.md 为目录：TS 与 Rust 均 EISDIR。粒度与 TS 一致——独立技能单文件，任一失败即整技能失败，不存在「跳过某条保留兄弟」。根内符号链接按 TS 跟随读取，不被过度拒绝。本条仅覆盖独立技能；插件 commands / skills / output-styles 见 R2。仅 Unix；非 Unix 保持原按路径读取。
