## 类别

传输层差异（待批）：#1348 的 api-web 组件（`/api/web/projects`、
`/api/web/projects/:key`、`/api/web/projects/:key/files/*`）挂在 #1209
原生监听器的同一 hyper 1.7.0 编解码后面，继承 A8.4-NATIVE-HTTP-001 已登记
的全部帧级/头级呈现差异（头名大小写、chunk 大小十六进制、HTTP/1.0 状态行、
空体 `content-length: 0`），回放按同一组归一化规则折叠后 78 个 cell 字节
一致，`http10` 钉死为继承的状态行差异。本条新增登记 1 项该组件路径上的
残余：files 分支上项目 key 的坏百分号（`decodeURIComponent` 在 describe 的
try 之外）在 TS 侧是 unhandled rejection 的表现。组件未接线（W0 #1305 拆
分发、接线另单），差异仅影响金样矩阵外被独立测试钉死的 1 格与矩阵内被
钉死的 1 格，不构成对拍豁免。

## 基线依据

固定基线 cc7c4e653b15c8b2cec7bcf2d15d41d69396ae85，Node v22.22.0 / ICU
78.2。TS 侧 `adapters/web/httpRouter.ts`：describe 分支的
`decodeURIComponent(key)` 在 try 内，坏百分号落 404 `project_not_found`
"URI malformed"（金样 cell `project-describe-badpct` 实测）；files 分
支的同一调用在 try 外，`URIError` 逃出 route handler 成 unhandled
rejection——服务器一个字节不写、连接保持打开，客户端只能等超时。该格因此
不在金样里（README「不在金样里的一格」）。HTTP/1.0 一格：Node 对
HTTP/1.0 请求始终写 `HTTP/1.1` 状态行 + `Connection: close` + 无 framing
的 close 定界体，金样 cell `http10` 实测；先例 A8.4-NATIVE-HTTP-001 与
A8.4-MODULE-HOST-001 的同名继承项。

## Rust 行为

`src/pilotdeck-gateway/src/api_web.rs`：files 分支上 key 的坏百分号同样是
`decode_uri_component` 的 `Err`，但不复制 Node 的挂起——按任务书映射成 500
`internal_error` "URI malformed"（`project_key_malformed_percent_is_500`
钉死），理由是零字节挂起不可复用 `serve` 的应答通道且会占住连接直到超时。
HTTP/1.0 一格：hyper 1.7.0 对 `Version::HTTP_10` 写 `HTTP/1.0` 状态行，
其余（`Connection: close`、无 framing 的 close 定界体）与 Node 一致
（`http10_close_delimited_response` 钉死）。

## 范围

仅 api-web 三类路由的 key 解码路径与状态行呈现（组件范围，未接线，
`native_process/{requests,services,assembly}.rs` 不受影响）。`/api/web`
（无尾斜杠）落 native 纯文本 404 属 #1209 路由兜底，不在此条。归一化规则
（date 掩码、头名小写、删空 `content-length: 0`、chunk 大小小写）不折叠
两项：一个是行为差异（挂起对 500），一个是状态行差异。

## 机器判据

`src/pilotdeck-gateway/src/api_web/tests.rs`：
`project_key_malformed_percent_is_500` 钉死 Rust 侧 bytes（500、
`{"error":{"code":"internal_error","message":"URI malformed"}}`、连接不
关）并注明 TS 侧 unhandled rejection 为本条残余；
`http10_close_delimited_response` 钉死继承的 HTTP/1.0 状态行差异；其余
78 cell 逐个 socket 级回放归一化字节 + closed 标志，
`replay_cells_cover_exactly_the_oracle` 断言回放列表 + 钉死列表与 oracle
cell 集合相等；ignored `regenerates_identically("api-web")` 重生成完整金
样；`negative_controls.py` 6 个编译期开关各绑定正控 + 负控锚点 + 恢复
正控，非全 KILLED 退出非零。任何新的未登记差异会被逐 cell 回放或钉死测试
击落。
