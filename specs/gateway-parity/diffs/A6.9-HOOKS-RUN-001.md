## 类别

有意改进：按 #586 本包要求收紧生产 hooks 的 run/generation 回执与关闭边界。登记不等于批准或判分豁免。

## 基线依据

cc7c4e6 `src/cli/SessionInteractionBundle.ts:136-169,278-284` 构造 session HookRuntime，追加并注册 gateway permission callback；`src/agent/modules/transport/sidecarTurnComposition.ts:85-96` 逐轮绑定 lifecycle；`src/extension/hooks/execution/AsyncHookRegistry.ts:104` complete 仅按 id 查找，未检查 generation。`tests/fixtures/interaction-hooks/probe.mts` 真实 import 基线，oracle.json 的 difference 记录 generation 1→2 后旧 id completion 仍返回 true。

## Rust 行为

`src/pilotdeck-gateway/src/runtime/project/interaction_hooks.rs` 以 factory generation 为资源边界，每个 run 建独立 HookRuntime。新同 session run（包括复用 runId）关闭旧绑定；receipt 同时持有私有 run identity 与 pending descriptor generation，不能用相同 id/generation 串入另一运行时。外部取消、权限绑定替换、handler dispose 或 generation dispose 均撤销端口；配置命令保留既有 shell TERM/drain，不因调用方 future 被丢弃而直接截断。重复 close/complete/cancel 不重复释放或交付。

## 范围

只影响 Resource::InteractionHooks 的生产 bind_turn 路径；旧直接 LifecycleRuntime/HookRuntime API 及其原金样不变。与 TS session-scoped runtime 不同，结束 run 即丢弃该 run 未交付 pending，不延续到下一 turn。关闭/过期 dispatch 返回明确 HostError，回执 complete/cancel 返回 false。permission callback 仅在同代同 session/run 且 gateway/canPrompt 时安装；关闭 hooks 同时关闭其配对 permission run。正常在途旧 generation 持租约可继续，租约排空后拒绝。

## 机器判据

`runtime/project/interaction_hooks/tests.rs`：`configured_hooks_and_permission_callback_match_real_ts` 比较完整 TS 正控；`async_receipts_match_ts_and_reject_duplicates_old_runs_and_generations` 验证旧 run/旧代/错 descriptor generation；`permission_wait_is_cancelled_once_and_foreign_permission_is_rejected` 验证取消与迟到答复；`replacing_permission_revokes_hooks_before_next_hooks_bind` 验证替换窗口；`real_shell_cancel_runs_term_trap_before_runtime_drain` 使用真实 TERM trap。`runtime/project/factory_tests.rs` 的 interaction_hooks 两项验证 builder 顺序、真实 rollback 与 generation lease drain。
