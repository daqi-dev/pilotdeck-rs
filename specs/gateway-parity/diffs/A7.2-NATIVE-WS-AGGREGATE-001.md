## Rust 行为

`src/pilotdeck-gateway/src/native_ws.rs` 的每个 NativeWsServer 默认最多 64 个连接：
accept 后、spawn/HTTP 握手前无等待准入，覆盖 HTTP 半握手、已升级 WS 与其业务 drain；
满额直接关闭新 TCP（无 HTTP 503 / WS close 帧），不生成拒绝任务。
先回收完成任务再 accept，避免持续接入令 JoinSet 完成记录无限积累。

跨连接 decoder backing 容量预算为 256 MiB。扩容分配前同时预留新 backing，旧 backing
在替换完成前持续计账；split 后未消费 tail 仍计原 backing，不能按逻辑 len 提前退费。
完整消费且 Frame 已释放时清空 backing 并返还额度；EOF、协议错误、预算拒绝、任务取消均归还。
读取结束先释放输入资源，再等待既有业务清理。申请失败只向争用连接发 close1009，原因为
`aggregate input limit exceeded`，原有连接保留，不等待前驱释放。

## 范围

仅 opt-in、127.0.0.1 的 NativeWsServer 实例；多个实例各自拥有预算。
这是 decoder 存储预算，不是整个进程 RSS 上限：每连接另有 8 KiB 读取块，已解码 payload、
业务请求和输出继续受既有单帧 / pending / 输出限额约束。分配器元数据不计入预算。
HTTP 解析器受连接数上限约束，尚未升级时不使用 decoder 预算。
不修改 TS、代理 Decoder、既有单帧上限、冻结语义或 #1071 默认入口。
