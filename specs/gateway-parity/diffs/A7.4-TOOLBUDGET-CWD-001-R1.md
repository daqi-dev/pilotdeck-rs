## 类别

更正（#897 消除原条目登记的两处未消除差异）：原条目「Rust 行为」段记录的**报错时机**（错误延迟到轮次流首次轮询）与**前置取消掩盖**（首次轮询前取消返回 Aborted、错误不出现）两点，经 #897 修复后不再成立。原条目的第一处分歧（Node `process.cwd()` 进程级缓存 vs Rust `std::env::current_dir()` 实时读）**不受本更正影响，仍然登记**。

## TS 依据

cc7c4e6 的 `src/cli/ProjectSessionFactory.ts:125-163`：`createSession` 的 try 块内先 `createStorage`，再 `resumeAgentSession`（其内部 `resumeAgentSession.ts:74` 调 `extendDependencies`，即 `ProjectSessionRuntimeBundle.ts:509-539` 的 `SessionContextRuntimeBundle` 组合，其第一条语句构造 tool-result budget，`SessionContextRuntimeBundle.ts:83-89`）；失败时 catch 先由 `resumeAgentSession.ts:121-135` 关闭已建 storage，再由 createSession catch 释放 prepared resources 后原样 rethrow。

Node v22.22.0 三探针实测（tsx 真跑基线源，wt-897 的 `_tmp/20261026-issue-897/ts-probe-raw-output.txt`，探针 `_tmp/20261026-issue-897/ts-probe-897.mts`）：(a) 相对目录 + 已删除 cwd：构造器抛 `ENOENT: no such file or directory, uv_cwd`（cwdReads=1）；(b) 绝对目录 + 已删除 cwd：真实 `SessionContextRuntimeBundle.compose()` 成功（cwdReads=0，短路）；(c) 真实 `ProjectSessionFactory.createSession`（prepare/createStorage 按基线 spec 同法打桩，extendDependencies 跑真实 bundle compose）：Promise 被 reject、消息为原始 uv_cwd 文本、`released==1`、`storageDisposed==1`、调用序 `["createStorage","restore","extendDependencies"]`。诚实边界：prepare 为打桩（生产 prepare 需完整运行时），但 throw 位于 createSession 的 await 链内，时机判定有效。

## Rust 行为

`src/pilotdeck-gateway/src/runtime/session/factory.rs`：`FactoryOptions` 新增 `tool_results_dir: Option<ToolResultsDir>`（按 sessionKey 解析每会话目录）；`construct()` 在 storage 创建与 restore 之后、`(prepared.host)(binding)` 之前执行 `ToolResultBudget::new(ToolResultBudgetOptions::new(dir))`，失败原样 `RuntimeError`（消息逐字节）并落入既有回滚分支：storage `close_owned` 后释放 prepared resources（顺序对齐 resumeAgentSession 的 rollback + createSession catch；`PreparedResources::drop` 是异步兜底，不作为判据）。会话句柄不再产生，`get_or_create` 返回 Err，无轮次槽被占用，前置取消无从掩盖。生产接线 `native_process/assembly.rs` 传入与每轮 `SessionTools::turn` 相同的目录（`native_process/tools.rs::session_tool_results_dir`，两处共用防漂移）；生产 project 恒为绝对路径，预检恒成功，无生产行为变化。每轮组装（`TurnHostFactory::assemble`）保留自己的实时 cwd 读——**原条目登记的 cwd 缓存差异（创建时健康、之后删除的场景，矩阵第 6 格）不变，仍按原条目登记**。

## 范围

`ProjectSessionFactory` 组合期预算预检（create 与 recreate 共用 construct 路径）；目录解析 helper 与每轮端口的共享。原条目的六格矩阵中：格 1/2/3（相对 + 删除 cwd 的 create/submit/cancel-before-poll）由延迟报错收敛为创建期拒绝；格 4/5（健康 cwd、绝对路径）行为不变且补齐创建期正例；格 6（创建后删除，Node 缓存 vs Rust 实时读）超出 #897，仍属原条目第一分歧。轮次租约（每轮 acquire 当前代）不动。
