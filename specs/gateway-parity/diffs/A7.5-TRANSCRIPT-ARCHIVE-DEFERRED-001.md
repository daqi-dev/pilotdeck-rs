## TS 依据

TS 基线 cc7c4e6（`resources/PilotDeck` @ `cc7c4e653b15c8b2cec7bcf2d15d41d69396ae85`）：

- `src/cli/createLocalGateway.ts:1021`：`new InProcessGateway(router, { … })` 的 options 对象**无条件内联**注入两个回调——`exportSessionTranscript`（`:1162` 起）与 `restoreSessionTranscript`（`:1315` 起），默认装配即注入，不存在「未注入」的默认形态。
- `src/gateway/client/InProcessGateway.ts:2241-2248 / :2250-2257`：handler 仅在 options 回调缺失时抛 `CAPABILITY_UNAVAILABLE`（"export_session_transcript is unavailable." / "restore_session_transcript is unavailable."）；默认 CLI 两回调都注入，该 guard 不可达（coverage-manifest 两方法 `branches.unconfigured` 按读码同结论登记，ledger.json 模板 `BabEnQ`（export）/ `DCLdbg`（restore））。

- 广告：`src/gateway/client/InProcessGateway.ts:2103-2105`——`options.exportSessionTranscript && options.restoreSessionTranscript` 都在时 describe 才列 `session_transcript_archive`；默认装配两个都注入，故 TS 默认 CLI 广告该名。录制件 `src/pilotdeck-gateway/tests/fixtures/native-management/oracle.json` 三态 `contract.capabilities`（各 50 名，`emptyStorage` / `missingStorage` 同）都含 `session_transcript_archive`。
- coverage-manifest 对两方法登记为 `status: BLOCKED` 的读码登记（`scenario_ids.driver: NONE`，`delivery_package: A7.5` / `work_package: S3`），本条同样按读码结论登记，不声称有真实 TS 运行金样。

## Rust 行为

`src/pilotdeck-gateway/src/native_process/methods/history.rs:9-17`：两个 wire 方法名照常注册进 A7 method 注册表（`METHODS`，家族 handler `AfterAdmission`），路由与项目准入层（`requests.rs:219-230`，非本进程项目先拒、错误面属隔离层与本条无关）都在。`:30-38` 的 `unavailable()` 使处理器（`:50-57`）对两方法在任何实际执行之前直接返回 `RequestError { code: "CAPABILITY_UNAVAILABLE" }`，message 为「export_session_transcript is not configured. Wire `exportSessionTranscript` via createLocalGateway.」/「restore_session_transcript is not configured. Wire `restoreSessionTranscript` via createLocalGateway.」——delegate 未移植，没有成功返回路径，也没有转发给 TS 的兜底。

`src/pilotdeck-gateway/src/native_process/capabilities.rs:175-179`：`session_transcript_archive` 列在 `NOT_ADVERTISED`（理由「export/restore_session_transcript are not ported (methods/history.rs answers CAPABILITY_UNAVAILABLE)」），`capability_table_covers_every_recorded_name` 钉住 advertised == recorded − 声明例外，故 describe 恒不广告该名；`unserved_history_methods_are_not_promised`（#1352）再从方法名一侧挡「广告一个只能失败的调用」。

## 范围

只影响 `export_session_transcript` / `restore_session_transcript` 两个 WS 方法、`session_transcript_archive` 广告位，以及依赖 portable archive 的客户端（会话转录的导出/恢复能力发现与使用）。不影响 S3 的 fork_session / replace_last_turn / finalize_last_turn_replacement（真实现，`methods/history.rs:78-89`）。`read_session_messages` 与 `read_subagent_messages` 同为「路由在、恒未配置」的方法，不并入本条（本条只覆盖 export/restore 对的 `CAPABILITY_UNAVAILABLE` 面）：前者 `history.rs:60` 硬编码 `None::<&dyn SessionHistoryReader>`（全仓无生产 `impl SessionHistoryReader`，仅 `runtime/turn/read_tests.rs` 测试实现），`runtime/turn/read.rs:293-302` 恒回 not configured 错（`code` 映射 `gateway_request_failed`），无成功路径，manifest 登记 BLOCKED / S3；后者 stub 契约按 #1308 fix-r1 定形 `gateway_request_failed`（`history.rs:72-77`），manifest 登记 BLOCKED / U10（`specs/product-coverage/entries.json:567` unsupported）。gateway-parity 差异账本对两者均无条目——同型未登记差异与直测缺口由 #2633 承接，前置于各自移植收口。不影响 `native_transcript_archive` 双名（native_archive_manifest/entries/artifact 真实现，`capabilities.rs:98-109`）。同表其余 `NOT_ADVERTISED` 例外不在本条范围：`apply_flag_settings` / `update_settings` / `reload_output_styles`（settings 委托未移植，OPEN 跟踪单 #1671）与 `sdk_session_config`（wire 协议无同名请求，#1305 注册表不路由该名），其差异登记归各自跟踪单另行判定。与 `A7.8-ALWAYS-ON-DEFERRED-001`（-R2 后撤回：控制态已真实现）当年的登记形态同型（路由在、拒绝如实），差异是 TS 侧该对方法**默认即注入**（不是 always-on 的三态可选注入），故默认 CLI 下两边行为分歧更大：

| 场景 | TS 表现（默认 CLI） | Rust 表现 | 用户感知 |
|---|---|---|---|
| describe | capabilities 含 `session_transcript_archive`（InProcessGateway.ts:2103-2105，两回调默认注入） | 不含（NOT_ADVERTISED，capabilities.rs:175-179） | 能力发现层少一名，客户端看不到转录归档入口 |

## 机器判据

组件直测（均已存在于 `origin/main`，随常规 CI 跑）：

- `native_process::capabilities::tests::unserved_history_methods_are_not_promised`（`capabilities.rs:324`，#1352）：CAPABILITIES 表任何名都不得 promise 这两个方法名。
- `native_process::capabilities::tests::capability_table_covers_every_recorded_name`（`capabilities.rs:364`）：recorded 每名须「在 CAPABILITIES 表或列入 `NOT_ADVERTISED`」+ 表内名不得凭空发明（cron/always-on 除外）+ 三态录制名一致——`session_transcript_archive` 只能经该例外豁免，删掉例外即红；把名直接加进表该测试不红（名本身是 recorded），由按行内容的 `capability_methods_are_registered` / `unserved_history_methods_are_not_promised` 拦。
- 家族守卫（不单独钉本条）：`capability_methods_are_registered` / `unregistered_method_suppresses_advertisement`：注册表面与广告联动。
- `native_process::methods::tests::registry_matches_current_methods`（`methods/tests.rs:46`）：两方法名在注册表独立盘点内。
- `native_process::methods::tests::session_domain_reconciles_with_coverage_manifest`（`methods/tests.rs:187`，断言在 `:207`）：A7 delivery-package 方法与 coverage-manifest 对账防漂移（`negative_assert_eq!(a7.len(), 52)`——50 项核心会话域之外还含 U9 `hook_async_result` 与 U10 `read_subagent_messages`，非「50 项清单」）。
