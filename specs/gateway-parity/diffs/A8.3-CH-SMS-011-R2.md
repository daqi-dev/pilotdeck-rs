## Rust 行为

`src/pilotdeck-gateway/src/channel/sms/mod.rs`（#2026 决策 C，PR #2247）：
连接任务收进 accept 循环任务内的 `tokio::task::JoinSet`；`stop()` 为
`shutdown.send(true)` → `server.task.await`（**含 drain**，
`timeout(STOP_DRAIN_LIMIT = 60 s, …)`）→ 清 client；超时截断时 `JoinSet`
drop **abort** 剩余连接任务。变异开关 `sms-stop-no-drain` 在分支内
`std::mem::forget(connections)`，以泄漏集合复现 #2026 前 detach 形状。细节与
行号锚见 `A8.3-CH-SMS-014`「Rust 行为」，本条不重复。
