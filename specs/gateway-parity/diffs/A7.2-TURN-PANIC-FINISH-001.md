## 类别

有意改进：worker panic（JoinError）臂原为无上界 `publisher.finish().await`，host future 挂死时 turn / admission / completion fence 永久挂起（#1721 条目 10）。修复改为「abort 预算内有界 drain + 无条件 `close_live()` 硬关」，与 timer 路兜底（`specs/parity/diffs/6-R1.md`，#1721 条目 9）同款「宁可 durable/wire 分叉也不永久挂死」取舍。

## 基线依据

固定 cc7c4e653b15c8b2cec7bcf2d15d41d69396ae85，Node v22.22.0。`src/gateway/client/InProcessGateway.ts` 真实实测（探针 `_tmp/20261026-issue-2498/ts-probe-2498.mts`，输出 `ts-probe-2498.out`，接线为 turn-submit 金样生成器同款真实组件）：pump 抛错后 pump finally 无上界 `await Promise.all(pendingRunRegistryWrites)`（InProcessGateway.ts:1789）完成才 `queue.close()`（:1790）；帧只在 append 的 `.then` 里入 live 队列（`enqueueGatewayEvent`，:1216-1245，append-then-enqueue :1221-1227）；非超时路外层 finally `await pump.catch(() => undefined)`（:1838）。实测：append 晚沉降（探针 B）→ 两帧 failure（agent_status + error `gateway_submit_failed`）照常投递、turn 正常收口（ended=true、active=false、afterCalled=true）；append 永不沉降（探针 A）→ TS 挂死（ended=false、active=true、afterCalled=false），无帧投递、queue.close 永不执行。

## Rust 行为

`src/pilotdeck-gateway/src/runtime/turn/submit.rs:678-680`（manage 臂 worker JoinError 分支）：先照常 claim-guard 记录 failure 两帧，随后 `timeout(abort_turn_timeout_ms().max(1_000) 预算, publisher.finish())` 有界 drain，超时即无条件 `close_live()`（幂等、立即）。`close_live` 之后才沉降的 append 由 `PublicationWrite::finish` 的 `if !state.closed`（`src/pilotdeck-gateway/src/runtime/turn/publish.rs:257`，:266/:272）丢弃——durable 已有行（append 本身已完成），wire 只看到流结束；预算内沉降的帧照常投递，与 TS 一致。turn / admission / fence 在预算内有界释放，永不因挂死的 host future 永久占用。

## 范围

仅 turn submit 的 worker panic（JoinError）臂。timer 接管路径的关闭语义是 `specs/parity/diffs/6-R1.md`（#1721 条目 9）既有判定，本轮不动；pump 正常完成路径（worker 自身 `finish()` 关闭投递）不变；预算内（含 panic 时刻已沉降/预算内沉降）两帧投递与 TS 逐字节一致，非本条差异。差异仅在「append 沉降晚于预算」与「append 永不沉降」两格：前者 TS 等到沉降再关（帧投递），Rust 按预算硬关（帧被丢）；后者 TS 永久挂死，Rust 有界收口。不修改 TS 金样或冻结判分器。

## 机器判据

`src/pilotdeck-gateway/src/runtime/turn/submit_tests.rs::panicked_worker_closes_delivery_within_abort_budget`（交错格体系，注入 mock `Session::submit` panic + registry append 闸门）：格 panic-drain / panic-budget（预算内沉降，含时钟已推进 500ms）断言两帧 failure 照常投递；格 panic-close（时钟推进 1100ms 超预算后沉降）断言 wire 无 failure 帧（被硬关丢弃）、turn 在预算内收口。负控 `src/pilotdeck-gateway/tests/fixtures/turn-submit-panic-close/negative.py`（mutating_sources 体系，四个变异体：回退无界 finish / 去 close_live / 去 drain / 去 `.max(1_000)` 下限，各自命中一格的 #2498 断言红；提交后由协调者在宿主跑）。
