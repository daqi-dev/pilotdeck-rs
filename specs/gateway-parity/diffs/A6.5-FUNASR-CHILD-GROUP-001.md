## 类别

子进程生命周期保护；已知行为差异，未批准，非已接受差异。修复取消/服务退出时转写 wrapper 的后代仍运行或持有输出管道的风险。

## 基线依据

固定 `cc7c4e653b15c8b2cec7bcf2d15d41d69396ae85` 的 `src/extension/plugins/builtin/funasr/funasr-local-mcp.mjs:118-131` 使用 `spawn(command, commandArgs, { windowsHide: true })`，没有 `detached`；读取 stdout/stderr 后等待 `close`，该函数未配置进程组终止。此为源码可确认的事实，未声称已复现所有 TS 后代泄漏场景。原文件 SHA-256 由 `native-funasr-mcp/oracle.json` 记录。

## Rust 行为

`src/pilotdeck-gateway/src/runtime/mcp/funasr.rs` 在 Unix 用 `install_child_detach_session` 为转写运行时建立所属进程组，持有未回收 leader 的退出身份，取消时先终止该组再回收；正常 leader 退出但后代持管道的路径也按有界清理处理。其他 MCP 服务器的进程组策略未由本条改变。

## 范围

只覆盖 Rust 内置 FunASR helper 启动的本地转写运行时及其后代。支持边界以实际目标平台测试为准；不把 Windows 或无 WNOWAIT 平台算 Unix 验证通过。组的建立/停止可能被子进程观察到，因而不能声称与 TS 原生 spawn 逐项相同。

## 机器判据

`runtime/mcp/funasr_tests.rs` 的 wrapper/worker 取消测试要求秒级收尾并验证后代退出；独立评审要求补正常 leader 先退出且 worker 持管道的成功路径。13 项协议金样必须继续通过。正式新头实际运行及负控记录待接续，当前登记不冒充已完成全部清理证明。
