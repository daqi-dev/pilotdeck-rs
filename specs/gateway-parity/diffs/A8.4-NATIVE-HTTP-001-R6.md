## 类别

更正（归一化规则陈述收窄）：原条目「基线依据」末段「回放比较对两侧
统一归一化（date 掩码、头名小写、删 `content-length: 0`、chunk 大小
小写；状态行不折叠）」把「删 `content-length: 0`」写成两侧统一删的
blanket 陈述。#2153（fix-r1 9d08fa1a3 / fix-r2 861992d24，PR #2770 已合）
之后实际实现是**登记格集**：`src/pilotdeck-gateway/src/native_http/tests.rs`
的 `PARSER_ADMISSION_CELLS` 常量（**11/88** cell），重放归一化仅对这
11 个登记格丢弃 hyper 补的 `content-length: 0`，其余 77 格该行逐字比对。
收窄不改任何判分语义（88 cell 全绿前后一致：金样 TS 侧本就一处
`content-length: 0` 都没有——对
`tests/fixtures/native-http-basic/oracle.json` 全文 grep 该串 0 命中，
删行只发生在 Rust 侧的 11 个登记格），改的是**漂移检出面**：若某个
未登记格长出该行（如 #2776 的 health HEAD 变异），收窄后的逐字比对
当场击落，blanket 删则会掩盖。原条目第 3 项（裸 400 上 hyper 补
`content-length: 0`）的登记内容与批准状态不变；本件不新增、不撤销
任何对拍豁免。

## 基线依据

与原条目一致：固定基线 cc7c4e653b15c8b2cec7bcf2d15d41d69396ae85，
Node v22.22.0，真实金样 `oracle.json`（88 cell）。本轮复算（#2777，
2026-11-10，独立于测试代码从 oracle 原始 JSON 重算）：88 cell 里恰有
**11 格**是裸解析器 400——状态行 `HTTP/1.1 400 Bad Request`、body 空、
头集合 ⊆ {`connection`}（即 TS 侧无 content-length、hyper 侧补
`content-length: 0` 的第 3 项形态）：`bad-method-foo`、
`bad-method-get`、`bad-method-getx`、`non-ascii-path`、
`non-ascii-query`、`garbage`、`pct-target`、`authority-form`、
`abs-scheme-nonalpha`、`empty-request`、`connect-nonascii`。该集合与
`PARSER_ADMISSION_CELLS`（`native_http/tests.rs:102`）逐项相等。其余
77 格的期望字节不含 `content-length: 0` 行（全文 grep 0 命中），故
「仅登记格删该行」与其余格的逐字比对等价于金样本身。

同族车道各自的登记面不变（本件不涉）：api-server 车道两格
（`unknown-method` / `missing-host`，A8.3-API-SERVER-005）、webhook 车道
一步（`PARSER_ADMISSION_LABEL` = `unknown-method`，录制侧 `generate.mts`
同一常量语义，A8.3-CH-WEBHOOK-004 范围表已指向本条目）、module-host /
module-host-approvals / api-web 车道各自的登记步，见各自条目。

## Rust 行为

`src/pilotdeck-gateway/src/native_http.rs` 生产路径不变：裸 400 走
`http_proxy::empty()`，hyper 对已知长度空体自动补 `content-length: 0`
（原条目第 3 项，已批接受差异）。收窄只发生在重放端
`src/pilotdeck-gateway/src/native_http/tests.rs`：选择点集中在
`fn parser_admission(id)`（#2789），读 `PARSER_ADMISSION_CELLS` 常量；
`normalize` 仅在 `admitted && name == content-length && value == "0"`
时丢弃该行（#2776 的 `native-http-served-head-cl0` 变异证明：未登记的
health HEAD 响应被手工塞入 `content-length: 0` 后，重放比较当场红，
即豁免面收窄有端到端牙齿）。
