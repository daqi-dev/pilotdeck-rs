## 类别

运行时环境差异（待批）：#1339 的 sms channel 读环境变量（authToken 链、
`TWILIO_WEBHOOK_PORT` 等）经注入闭包，生产默认 `std::env::var`；非
UTF-8 的环境值两侧不同——Node 把它读成含 U+FFFD 的替换字符串（视同
已设），Rust `std::env::var` 返回 `Err(NotUnicode)`、按闭包语义视同
未设。

## TS 依据

固定基线 cc7c4e653b15c8b2cec7bcf2d15d41d69396ae85，Node v22.22.0 /
ICU 78.2。`_tmp/20261026-issue-1339/probes/env-nonutf8.out` 实测：向
子进程注入字节 `41 ff 42` 的 `TWILIO_AUTH_TOKEN`，
`process.env.TWILIO_AUTH_TOKEN` 为长度 3 的字符串
`"A�B"`（码点 41 / fffd / 42）。`SmsChannel.ts:64-66` 的
`String(this.extra.authToken ?? ... ?? process.env.TWILIO_AUTH_TOKEN ...)
` 链会采用该替换串。

## Rust 行为

`src/pilotdeck-gateway/src/channel/sms/mod.rs`：env 读取经
`SmsChannelOptions.env: Arc<dyn Fn(&str) -> Option<String>>` 注入；
`register()` 默认 `std::env::var(name).ok()`——非 UTF-8 值返回
`None`，视同未设置，token 链落到下一环（最终空串）。除该边界外，
取值优先级链（extra.authToken ?? extra.apiKey ?? env.TWILIO_AUTH_TOKEN
?? extra.token）与 TS 逐字节一致。

## 范围

仅环境变量读取边界；`extra` 配置链、端口号强制（含 `0x4978` 十六进制
coercion）、publicUrl / host / path 解析不受影响。测试经注入闭包读取
per-case env（oracle `env` 字段），不走进程环境。

## 机器判据

`src/pilotdeck-gateway/src/channel/sms/tests.rs`：oracle 用例
`start-env-config`、`auth-token-chain`、`auth-token-apikey` 钉取值链
字节；`start-extra-coercion`、`start-port-out-of-range`、
`start-port-nan` 钉 coercion。非 UTF-8 环境边界无 Rust 用例（注入闭包
测试形态下不可达），登记为差异待批，不冒充已对齐。

改为 `var_os` + 有损解码（复刻 Node 的 U+FFFD 语义），由协调者裁定。
