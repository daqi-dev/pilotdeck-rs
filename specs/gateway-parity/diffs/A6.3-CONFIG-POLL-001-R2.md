- **A1 过渡拍**：完整采样之后的首个遮蔽拍（`SampleStatus::Obscured` 且 `obscured_fingerprint.is_none()`，没有上一遮蔽采样可比）额外把 target（被监视配置文件本体）的指纹与 `complete_target_fingerprint`（每个 Complete 拍提交、模式翻转时清空）比较，有差即报——遮蔽起始与 target 改写落在同一拍时不再等遮蔽解除后才报。仅 target 可比：遮蔽折叠采样里其它条目的哈希来自失败读，与完整采样不可比；后续遮蔽拍仍由折叠链（`observe_obscured`）覆盖，至多报一次；恢复拍仍与最后完整采样比较、有差再报一次（R1 已登记形状，不变）。
- **A4 混合拍**：metadata 采样遮蔽、**同一拍**折叠采样完整的混合拍，按**完整观测**处理：落空到完整路径，与 `fingerprint`（最后完整指纹）比较并提交为新基线，不延后、不污染遮蔽折叠链。修前该拍被当遮蔽拍处理：改写延后一拍才报，且完整折叠值被写进遮蔽链基线，后续可读性抖动与之比较产生假报。
