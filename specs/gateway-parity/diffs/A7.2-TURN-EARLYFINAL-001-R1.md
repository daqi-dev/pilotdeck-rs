## 类别

有意改进：保留无 loop 前缀的提前 final 拒绝；本更正登记 pr5d 已实现边界，不增加判分豁免。

## 基线依据

cc7c4e6，Node 22.22.0，真实 `pilotdeck-agent-loop-sidecar.ts` + 确定性 model port。`tests/fixtures/turn-runner/sidecar.mts` 复用既有生成器，原始输出在本树 `_tmp/20261026-issue-741i/ts-expanded/sidecar-{success,early-final,completed-warning}-raw.json`。正常 wire 从 model_request_started 开始，四个 model_event、assistant_message、stop_requested、非 final turn_completed，最后 module final。隐藏全部非 final 帧、重排 final sequence=0 时 TS 仍成功。

## Rust 行为

`runtime/turn/live.rs::StreamIntegrity` 改为 AgentLoop 前缀/失败/完成状态：success/max_turns 需要 loop 前缀，error 需要 loop 前缀及 turn_failed；宿主 start/accept 不作为 sidecar 证据。普通 host drain 事件也不能建立 loop 前缀。接收与交付计数不等时拒绝非 aborted final，防止有界取消清理丢弃已接收的 loop 尾帧后误报成功。

旧条目“仍要求宿主生命周期”已过时。HostClient 既有重复/丢 sequence 拒绝，以及 wire 非 final completed 抑制均未改。正常 completed 后继续读取 warning/final；直接泄漏到 StreamIntegrity 的 completed 和 start/accept 均拒绝。取消/drop 的已有差异仍按原条目，未在本更正批准。

## 范围

仅 LiveSession 的 lifecycle + AgentLoop 事件流。真实 AgentSession 外壳的 session_started/setup_completed/session_ended，以及 pr5e 的 user_prompt_submitted/instructions_loaded 不纳入本包宿主事件投影；原始完整序列保留，不声称整个 session 已对齐。提前 final 为已登记 TS/Rust 差异，不把 TS success 改成 error 金样。

## 机器判据

`live_stream_tests.rs::real_ts_sidecar_stream_starts_with_loop_events`、`real_ts_sidecar_completed_warning`、`real_ts_sidecar_early_final`、`real_ts_sidecar_gap`、`real_ts_sidecar_duplicate` 实跑真实进程。`slow_consumer_with_a_blocked_callback_still_exits_bounded` 覆盖已交付前缀后尾帧永久 pending，再取消；`forwarding::forward_completed` 保留 session 层异常 completed 的拒绝。共享 turn-runner oracle 的 ignored 重生成守卫覆盖新增行。源码变异脚本位于交付证据目录，提交前 immutable baseline 拒绝，提交后由协调者在宿主串行运行，不冒充负控已通过。
