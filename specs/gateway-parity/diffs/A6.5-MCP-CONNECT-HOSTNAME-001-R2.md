## 类别

更正（PR #697 评审 fix-r1 的两条 P2：失败路径重解析无界、单复数判定在去重前）。

## 基线依据

node v22.22.0（macOS，固定基线 dist 与锁定依赖同 R1）实测
`_tmp/20261025-issue-681/fix-r1/ts-probe-dup.out`：把 `dns.lookup` 注入为
返回重复 A 记录（`[127.0.0.1, 127.0.0.1]`）与单条记录（`.invalid` 保留域
主机名，系统解析永不真命中；下游 net.js 去重与 undici `onConnectTimeout`
均为真实 Node 代码，等价于 `/etc/hosts` 重复行或 DNS 重复 A 记录的输入）：

- 重复解析 + TLS 停滞（`handshakeTimeoutMs: 30000`，10 s）：
  `Connect Timeout Error (attempted address: dup-probe.invalid:64720, timeout: 10000ms)`
  —— 单数、URL 主机名。Node 在去重后才判单复数（`toAttempt.length === 1`，
  node v22.22.0 `lib/net.js:1518`，本地副本 `node-v22.22.0-net.js`），
  单地址走普通单连接、不记录解析，undici 回退到连接器收到的 URL 主机名。
- 单条解析 + TLS 停滞：同上单数形状（`single-probe.invalid:64720`）——
  R1 里「单地址主机名显示 URL 主机名」的读码推断由此实测补上。
- 重复解析 + 拒连（10 ms）：
  `connect ECONNREFUSED 127.0.0.1:64718`——去重后一条，仍显示解析地址
  而非主机名。

## Rust 行为

`src/pilotdeck-gateway/src/runtime/mcp/http.rs`：

- `timeout_cause` 改为先 `node_attempt_order` 去重、再用去重后的长度判
  单复数（R1 用去重前的 `resolved.len() > 1`，重复解析会误入复数分支，
  输出「复数标签 + 单条列表」的混合形）。
- 失败路径的 `tokio::net::lookup_host` 套上 `RESOLUTION_DEADLINE`（1 s，
  比 `MCP_CONNECT_TIMEOUT` 低一个量级、远低于握手时限）：连接已经失败，
  查询只为拼文案，停滞的解析器（正是导致失败的那种停滞，macOS / glibc
  系统解析超时常见几十秒）不得再拖一轮把最终报错换成
  `MCP handshake timed out`。到期即回退 `None`，文案退回 URL 主机名形状
  （即引入解析前的行为）；被取消的 `spawn_blocking` 解析线程不被等待。
  解析器经 `resolved_attempts_with` 注入以便测试。

## 范围

仅失败路径（拒连 / 连接超时两分类）的文案构造与重解析等待；成功路径、
分类逻辑、IP 字面量跳过解析、streamable 的 cause 剥离均不变。健康解析器
（< 1 s）行为与 R1 完全一致；唯一新增的可观察差异是「解析超 1 s 仍停滞」
时退回主机名形状，此前该场景会额外阻塞一个系统解析超时。

## 机器判据

- `runtime::mcp::http::tests::hostname_connect_timeouts_list_attempted_addresses`
  新增重复解析断言（`[127.0.0.1:P, 127.0.0.1:P]` → 主机名单数，金样即
  上述实测原文）；
  `duplicate_resolutions_dedup_in_refusal_texts`（拒连重复解析去重一条）。
- `stalled_resolution_falls_back_within_the_deadline`（paused 时钟）：永不
  应答的注入解析器必须在 `RESOLUTION_DEADLINE` + 50 ms 哨钟内回退 `None`，
  外层哨钟是负控锚点；另覆盖解析报错回退 `None`、正常解析透传、IP 字面量
  不触解析器（触即 panic）。
- 负控（2026-10-25 实跑，`_tmp/20261025-issue-681/fix-r1/`）：①去掉内部
  `tokio::time::timeout`（直接 await）→ `stalled…` 红（外层哨钟
  `Elapsed`）；②单复数判定改回去重前长度 → `hostname_connect_timeouts…`
  红（`attempted addresses: 127.0.0.1:64720` vs 金样单数主机名）；恢复后
  44 个模块内用例全绿。
