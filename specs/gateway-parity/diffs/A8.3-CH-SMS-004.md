## 类别

协议形状差异（待批）：#1327 的 `ChannelStartDeps` 没有 gateway 字段，
#1339 的 sms channel 因此经构造参数（`SmsChannelOptions.gateway`）注入
A7 入站端口，生产 loader 挂载传 `None`；`deliverCronResult` 同理不挂
`ChannelAdapter` trait，在 `SmsChannel` 具体类型上暴露。

## TS 依据

固定基线 cc7c4e653b15c8b2cec7bcf2d15d41d69396ae85。
`SmsChannel.ts:58-59` `start(deps)` 直接取 `deps.gateway` / `deps.logger`；
`protocol/ImCronDelivery.ts` 经组件接口的 `deliverCronResult` 投递
cron 结果（regex `^(.+):(general|s_[0-9a-fA-F-]{36})$`、
`chatId ? chatId : undefined` 链）。

## Rust 行为

`src/pilotdeck-gateway/src/channel/sms/gateway.rs` 定义
`SmsGateway`（`submit_turn` / `respond_elicitation` / `permission_decide`
+ `TurnEventStream`）作为 A7 入站端口；`mod.rs` 经
`SmsChannelOptions.gateway` 注入而非 `ChannelStartDeps`。生产
`register()` 传 `None`：无 gateway 时消息按 TS 同款日志失败
（`process_message` 返回 `TypeError: Cannot read properties of
undefined (reading 'submitTurn')`，进 `handleIncoming` 的 catch）。
`deliver_cron_result` 挂在具体类型上（`ImCronDelivery.ts` 语义原样）。

## 范围

仅注入形状与生产接线；oracle 回放全部经注入的 mock gateway 走同一
A7 接纳器语义（submitTurn / respondElicitation / permissionDecide 的
请求与事件序列逐格对齐），消息处理本身不受影响。真实 A7 入站单落地时
替换该挂载点（`gateway.rs` 即为挂载点）。

## 机器判据

`src/pilotdeck-gateway/src/channel/sms/tests.rs`：47 个 oracle 用例
全经注入 `SmsGateway` 回放（rpcs 记录 submitTurn / respondElicitation /
permissionDecide 请求逐字节比较）；`loader_mount_builds_sms_channel`
断言 loader 挂载可构建 sms adapter；`cron-delivery` / `cron-after-stop`
钉 `deliverCronResult` 语义。生产无 gateway 路径未单测（等真实 A7
接线单补）。
