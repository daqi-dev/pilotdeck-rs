## 类别

有意改进（issue #1316 明示二选一：「同域入口打到同一 owner，或显式返回未开放」，本条取后者）。

## 基线依据

TS 基线 cc7c4e6：`src/gateway/server/GatewayServer.ts` 的 `handleHttpRequest` 只路由
`/health`、`/auth/local-token`、静态资源，其余一律 `not found` 404；
`src/gateway/user-dialog/HttpGatewayUserDialogStore.ts:17` 定义
`STORE_PATH_PREFIX = "/v1/gateway-user-dialog-store/"`，但网关端口从不挂载该 handler
（仓库内无生产调用点，仅测试/独立服务器使用）。即：TS 对该前缀返回
404 `text/plain; charset=utf-8` / `not found`。

## Rust 行为

`src/pilotdeck-gateway/src/native_http.rs` `route()`：路径以
`crate::user_dialog::http_store::STORE_PATH_PREFIX`
（`/v1/gateway-user-dialog-store/`）开头时，返回 503
`application/json`，body
`{"error":"not_yet_open","store":"gateway-user-dialog-store"}`，其余路由（含兄弟路径
`/v1/gateway-user-dialog-storex` 与通用 404）不变。

## 范围

仅网关原生监听器的非升级 HTTP 路由，前缀匹配须为整个路径前缀；不影响 WS、
`/health`、`/auth/local-token`、静态回退与默认代理。A7.4 的 user_dialog
WS 方法（user_dialog_list 等）不受影响，仍走各自的家族处理器。

## 机器判据

`src/pilotdeck-gateway/src/native_http/tests.rs::user_dialog_store_entry_is_explicitly_not_yet_open`
（503 + content-type + body 字节 + 兄弟路径仍 404）。负控：删除该分支后该测试
KILLED（`tests/fixtures/session-assembly-1316/negative_controls.py`）。
