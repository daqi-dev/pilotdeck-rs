## 类别

传输层差异（未批准，非已接受）：#1209 为原生监听器的非升级 HTTP 分支
（`/health`、回环 `/auth/local-token`、静态回退、最终 404）引入 hyper 1.7.0
作为 HTTP/1.1 编解码器后，无法经 hyper 公开 API 消除的 5 处字节级差异。
路由语义（状态码、content-type、体字节、连接关闭与否）与 TS 逐字节一致；
差异全部是已登记的帧级/头级呈现差异，未修改冻结尺子或默认代理路径
（`native_process.rs` 与 `serve_connection_with` 的代理字节不变）。

## 基线依据

固定基线 cc7c4e653b15c8b2cec7bcf2d15d41d69396ae85，Node v22.22.0。
真实金样 `src/pilotdeck-gateway/tests/fixtures/native-http-basic/oracle.json`
（82 cell，四服务器 a/b/c/d，date 掩码后的原始响应字节）：

1. 头名大小写：TS 混合——`GatewayServer.ts:96` 源码字面 `content-type`
   小写，Node 自动头 `Date`/`Connection`/`Keep-Alive`/`Transfer-Encoding`
   大写；hyper 头统一 Title-Case（`content-type` → `Content-Type`），
   差异收敛到每个响应恰一处。
2. chunk 大小十六进制：Node 小写（`b`），hyper `encode.rs` 的 `{:X}`
   大写（`B`），无扩展点。
3. 裸 400（llhttp 方法表/target 形态拒绝）：TS 无 content-length，
   hyper 对已知长度空体自动补 `content-length: 0`。
4. HTTP/1.0 状态行：Node 恒回显 `HTTP/1.1`，hyper 回显 `HTTP/1.0`
   （HTTP/1.0 客户端不进金样矩阵，记录在案）。
5. keep-alive 空闲超时：Node 5 s 后关连接，hyper 无空闲超时
   （金样矩阵不依赖该超时；后续包跟进）。

回放比较对两侧统一归一化（date 掩码、头名小写、删 `content-length: 0`、
chunk 大小小写），并有独立测试钉死 hyper 实际字节，未登记差异不可能被
归一化吞掉。

## Rust 行为

`src/pilotdeck-gateway/src/native_http.rs`（`http_proxy::serve_connection_native`，
`title_case_headers(true)` + `auto_date_header(false)`，与代理路径共享
私有 helper）：llhttp 方法表（Node `http.METHODS` 正本）与 target 形态/
字节检测在 handler 层复刻裸 400 + 关连接；WHATWG URL 规范化为静态层的
穿越防线，`path.resolve` 折叠 + contains 守卫为纵深防御；Node 式头序
（content-type、Date、Connection: keep-alive、Keep-Alive: timeout=5）、
未知长度流式体恒 chunked、HEAD 无帧。CONNECT 以 handler Err 实现零字节
销毁，等价 TS 的 `socket.destroy()`。

## 范围

仅 opt-in 的 `NativeWsServer` 非升级分支（`with_static_root` 配置静态根；
生产默认无静态根、恒回环，`bind` 签名不变）。不含 `/api/web/`、approvals、
module-host（A8.4 后续包），不改默认代理路由。上述 5 项差异仅指明呈现层，
不作为对拍豁免：任何新的未登记差异会先被钉死测试（大写 B、CL:0、
Title-Case）或逐 cell 回放击落。

回放（归一化字节 + closed 标志）；`registered_transport_diffs_stay_pinned`

各自绑定正控 + 负控锚点 + 恢复正控，非全 KILLED 退出非零。
