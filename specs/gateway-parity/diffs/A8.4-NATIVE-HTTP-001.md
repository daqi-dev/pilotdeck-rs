## 类别

传输层差异（未批准，非已接受）：#1209 为原生监听器的非升级 HTTP 分支
（`/health`、回环 `/auth/local-token`、静态回退、最终 404）引入 hyper 1.7.0
作为 HTTP/1.1 编解码器后，无法经 hyper 公开 API 消除的帧级/头级呈现差异
（下列基线依据中 5 项）。金样矩阵内（88 cell）路由语义（状态码、
content-type、体字节、连接关闭与否）与 TS 一致（date 掩码归一化后响应
字节一致；帧级呈现差异即上述 5 项）；矩阵外的解析层
差异（字符集、尺寸上限）另立 A8.4-NATIVE-HTTP-002 登记，不在本条。
未修改冻结尺子或默认代理路径（`native_process.rs` 与
`serve_connection_with` 的代理字节不变）。

## 基线依据

固定基线 cc7c4e653b15c8b2cec7bcf2d15d41d69396ae85，Node v22.22.0。
真实金样 `src/pilotdeck-gateway/tests/fixtures/native-http-basic/oracle.json`
（88 cell，四服务器 a/b/c/d，date 掩码后的原始响应字节）：

1. 头名大小写：TS 混合——`GatewayServer.ts:96` 源码字面 `content-type`
   小写，Node 自动头 `Date`/`Connection`/`Keep-Alive`/`Transfer-Encoding`
   大写；hyper 头统一 Title-Case（`content-type` → `Content-Type`），
   差异收敛到每个响应恰一处。
2. chunk 大小十六进制：Node 小写（`b`），hyper `encode.rs` 的 `{:X}`
   大写（`B`），无扩展点。
3. 裸 400（llhttp 方法表/target 形态/非字母 scheme 拒绝）：TS 无
   content-length，hyper 对已知长度空体自动补 `content-length: 0`。
4. HTTP/1.0 状态行：Node 恒回显 `HTTP/1.1`，hyper 回显 `HTTP/1.0`
   （HTTP/1.0 客户端不进金样矩阵，`http10_close_delimited_response`
   钉死测试记录在案）。
5. keep-alive 空闲超时：Node 5 s 后关连接，hyper 无空闲超时
   （金样矩阵不依赖该超时；后续包跟进）。

回放比较对两侧统一归一化（date 掩码、头名小写、删 `content-length: 0`、
chunk 大小小写；状态行不折叠）；归一化会折叠的每个维度（状态行、
Date 缺席、HEAD 无帧、Title-Case、大写 chunk、`Content-Length: 0`）
都有钉死测试锁住 hyper 实际字节，金样矩阵内新增未登记差异会被逐
cell 回放击落。

## Rust 行为

`src/pilotdeck-gateway/src/native_http.rs`（`http_proxy::serve_connection_native_with_shutdown`，
`title_case_headers(true)` + `auto_date_header(false)` + `max_headers(2048)`，
与代理路径共享私有 helper）：llhttp 方法表（Node `http.METHODS` 正本）、
target 字节/形态、scheme 纯字母检测在 handler 层复刻裸 400 + 关连接；
`Connection: close` 与 HTTP/1.0 请求按 Node v22 应答 `Connection: close`、
无 Keep-Alive、应答后关连接；停机经 watch stop 通道下发，已服务过的
连接由 hyper `graceful_shutdown()` 关闭（等价 Node `server.close()` 的
idle 关闭），从未发字节的连接不关；WHATWG URL 规范化（绝对形式保留
`//` 路径）为静态层的穿越防线，`path.resolve` 折叠 + contains 守卫 +
根词法规范化为纵深防御；Node 式头序（content-type、Date、
Connection: keep-alive、Keep-Alive: timeout=5）、未知长度流式体恒
chunked、HEAD 无帧。CONNECT 以 handler Err 实现零字节销毁，等价 TS 的
`socket.destroy()`。

## 范围

仅 opt-in 的 `NativeWsServer` 非升级分支（`with_static_root` 配置静态根；
生产默认无静态根、恒回环，`bind` 签名不变）。不含 `/api/web/`、approvals、
module-host（A8.4 后续包），不改默认代理路由。上述 5 项差异仅指明呈现层，
不作为对拍豁免：任何新的未登记差异会先被钉死测试或逐 cell 回放击落。

## 机器判据

`src/pilotdeck-gateway/src/native_http/tests.rs`：88 cell 逐个 socket 级
回放（归一化字节 + closed 标志，回放统一绑 127.0.0.1，`c` 的非回环路由
经 `Config.loopback` 注入）；`replay_cells_cover_exactly_the_oracle` 断言
回放列表与 oracle cell 集合相等；`llhttp_methods_match_the_oracle` 断言
方法表与 `http.METHODS` 相等；`registered_transport_diffs_stay_pinned`、
`rejection_and_head_bytes_stay_pinned`、`http10_close_delimited_response`
钉死 hyper 实际字节（Title-Case 头、`B\r\n` chunk、裸 400 的
`Content-Length: 0` 与无 Date、HEAD 无帧、HTTP/1.0 状态行与 close 应答）；
`stop_closes_idle_keep_alive_connections` 与
`stop_waits_for_never_requested_connections` 钉死停机语义；
`native_listener_delegates_plain_http_to_the_router` 端到端证明委托接线。
`regenerates_identically("native-http-basic")` ignored 守卫重生成完整金样。
`negative_controls.py` 11 个编译期开关（方法表、target 形态、target 字节、
URL 规范化、回环判定、404 体、contains 守卫、connection-close 判定、
根词法规范化、停机 idle 关闭、头数上限）各自绑定正控 + 负控锚点 +
恢复正控，非全 KILLED 退出非零。
