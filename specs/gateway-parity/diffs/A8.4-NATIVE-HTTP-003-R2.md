## Rust 行为

`src/pilotdeck-gateway/src/native_http.rs`：`serve_static` 对未命中路由的目标
按 `node_join` 拼出候选路径后调用 `is_file`（`tokio::fs::metadata`），未命中
再回退 `index.html`；`content_type_for` 按请求拼写的扩展名查 `CONTENT_TYPES`。
故「路由比较在内存中进行」成立，「不涉文件系统」不成立——静态回退这一跳会
碰文件系统。

`src/pilotdeck-gateway/src/native_http/tests.rs`：回放期望选择里
`serves_upper_txt` 用 `node_join` + `contained` + `std::fs::metadata` 探测
夹具根，同样是文件系统访问（只在 `static-upper-lower` 一个 cell 上参与选
期望）。

实际影响仅为覆盖措辞：大小写变体的完备性由 #1383 新增守卫
`only_the_registered_cell_has_a_case_variant_fixture_hit` 机检，当前 oracle
下唯一命中仍是 `static-upper-lower`；本条不改变该判据、阈值与分母。
