## 类别

追加登记（范围：原条目未登记组件内 Node path 语义私有副本的留驻与
原因，本件补登；原条目及 -R1 的全部技术结论不变）。#1691 P2-2
要求 `files.rs` 的 `node_normalize`/`node_relative`（仓内第 3 份
Node `path.normalize`/`path.relative` 实现）「接线时统一或登记差异」；
接线由 #2354 完成（见 -R1），统一未做——留驻 `files.rs` 是有意决定，
本件登记该副本的存在、留驻原因与语义分叉。

## 基线依据

固定基线 cc7c4e653b15c8b2cec7bcf2d15d41d69396ae85，Node v22.22.0，
与原条目一致。TS 侧语义即 Node `path` 模块 POSIX 版。仓内三份 Rust
副本（#1691 P2-2 归因，行号为 origin/main `b284b6e3b4` 实核）：

- `src/pilotdeck-gateway/src/api_web/files.rs:667` `node_normalize`
  （`:704` `node_relative`）：前导 `..` 保留、尾斜杠保留为标记
  （`""` → `"."`、`"sub/../"` → `"./"`）——三份中唯一逐字对齐 Node；
- `src/pilotdeck-gateway/src/runtime/tools/builtin/mod.rs:137`
  `normalize`：`..` 无条件 pop（`parts.pop()` 对空前缀为 no-op），
  前导 `..` 被吃掉＝root-clamp，与 Node `path.normalize("..") === ".."`
  不符；
- `src/pilotdeck-gateway/src/runtime/permission.rs:1240`
  `normalize_path`：前导 `..` 保留（相对路径），但尾斜杠标记丢失。

三份细节互不相同、不可互换；互换即引入 Node 语义偏差。

## Rust 行为

`node_normalize`（`files.rs:667`）与 `node_relative`（`:704`）为
`files.rs` 私有 fn，服务边界检查与路径解析（`:539`/`:544`/`:556`/
`:563`）。留驻原因（#2354 worker RESULT §3 草案 B，PR #2435 正文
「差异账起草」引用）：

1. 与 `pilotdeck-transport` 的 `system_clock`（`format_epoch_iso`
   等，`src/pilotdeck-transport/src/system_clock.rs:62` 起）不同域
   ——后者是 `Date#toISOString`/时区解析，#1691 P2-1 的 toISOString
   已收编至彼（fix-r1 删 `files.rs` 本地 `to_iso_string` 改调共享件）；
   路径归一化不属该域，不能顺势收编。
2. `project_files.rs` 冻结不能导出：同文件 `node_base64_decode`
   已按此口径留私有副本（`files.rs:769` 注释「that frozen file
   cannot be edited to export it」，#1348 起既有先例），本件沿用
   同一判定。
