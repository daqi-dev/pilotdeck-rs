## 机器判据

`src/pilotdeck-gateway/src/channel/sms/tests.rs`：55 个 oracle 用例中
54 个有 `replay_cases!` 重放 cell，全部在注入 mock `SmsGateway` 下回放，
`expected.rpcs`（dispatch 用例为 submitTurn / respondElicitation /
permissionDecide 请求序列，非 dispatch 用例为空数组）与其余记录字段
逐字节比较；第 55 个 `port-busy-preflight` 无重放 cell，只由

比较。`loader_mount_builds_sms_channel` 断言 loader 挂载可构建 sms
adapter；`cron-delivery` / `cron-after-stop` 钉 `deliverCronResult`
语义。生产无 gateway 路径未单测（等真实 A7 接线单补）。
