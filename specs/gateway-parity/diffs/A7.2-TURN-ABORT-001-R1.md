## Rust 行为

产品判定路径未改。该路径不创建 host factory、不创建 `TurnRunner`，`runner.rs` 的两处 `complete_turn` 都不执行；但 `live.rs` 的记录分支 `_ if terminal && self.accepted => Some(RecordingAction::Complete(...))` 会把合成的 `turn_completed` 交给 `Recorder::complete_turn`，追加**恰好一条** durable `turn_result`（`result.type=aborted`、`stopReason=aborted_streaming`），随后 `next()` 返回 `None`。与上文 TS 同格相比，次数与 `result.type` / `stopReason` 一致；本条不宣称其余字段逐字段对齐。
