## 类别

bug 修复（#1550）。R1 收窄后的剩余范围是「恢复投影（A7.5）」整体；本更正再收窄：`control_boundary`
条目（compact 边界）的恢复投影已对齐——TS restore 成功的形状 Rust 成功，TS 抛 TypeError 的形状
Rust 抛同名同文案错误。其余恢复投影差异（见范围节）维持 R1 的「不可避免（暂未移植）、前置于 A7.5」
定性，不新增豁免。

## Rust 行为

`src/pilotdeck-gateway/src/storage/transcript_adapter.rs` 的 `projection_supported` control_boundary
分支不再无条件 `ProjectionUnavailable`（原「Rust 行为」中『恢复投影超出当前恢复/列表形状集合时返回
显式 ProjectionUnavailable』对本类条目失效）：改为 `control_boundary_supported` 按注册序复刻会抛的
读取——boundary null/undefined 抛 `(reading 'kind')`；`kind:"compact"` + `subtype:"compact_boundary"`
时，合法 snapshot（readCompactSnapshot 端口）短路 replacementMessages 读取，非法 snapshot 对
replacementMessages 做 cloneMessages 抛错预判（truthy 非数组 `messages.map is not a function`、
nullish 消息/块、tool_result content nullish/非数组），compactMetadata null/undefined 抛
`(reading 'postTokens')`；其余形状（microcompact、缺失 subtype、resume/manual、原始值/数组 boundary、
原始值 compactMetadata、falsy replacement）放行。`project_session_info` 复用同一门，列表投影同步放行。
错误经 `AdapterError::Type` / `AdapterError::Range` 对齐 name+message；两条端口（本文件与
`session_model/replay.rs` 的同源 `checked_string`，`session_model_get` 读同一份 transcript）共用
`js_value::string_coercible_checked`（有界 2000 容器 + `toString` 属性判定，不物化 join 文本），深层
嵌套的 `block.type` 因此抛可捕获错误而不是 abort 进程；`session_model_get` 侧按 TS
`GatewayWsConnection.ts:251` 的包络折成 `code:"gateway_request_failed"` + message 原文。2000 容器
以外的「TS 仍成功、Rust 已抛」带属已人批的 `A6-JSVALUE-DEPTH-001`，不在本条目新增豁免。不可达于 JSON 值域的 clone 路径（原始值消息、内层
spread、structuredClone）不额外设卡。`restore_entries` 的 envelope→domain→状态安装→门 顺序不变。

## 范围

已消除：compact `control_boundary` 恢复/列表投影的显式拒绝（原条目「尚未支持的……恢复投影」的
control_boundary 切片）。仍未对齐、维持 R1 定性：其余条目种类的未支持形状仍返回
`ProjectionUnavailable`（accepted_input messages、assistant/tool_result/durable message、turn_result
usage/errors、session_metadata 的门仍在）；projection checkpoint 持久化与暴露给宿主的视图/finalize
API（WebHistory 视图输出等）；`real compaction` 之外的写入路径不在本单（写入端 recorder 已有
compactMetadata）。顺序注记：TS conversation cell 对全日志 reduce 完才轮 web-history cell，Rust 门
逐条目检查，多缺陷条目共存时先报哪条 message 可能不同（两边都失败）；单条目内按注册序对齐。
