## 类别

不可避免（本包限定范围下保留的既有运行时差异）：Node `process.cwd()` 有进程级缓存；Rust `std::env::current_dir()` 每次读取系统 cwd。另有一处构造时机差异（TS 在模块加载/构造时 throw，Rust 在首次构造默认 projector 时返回错误）。本条不认可该限制为最终行为，不增加判分豁免。

## 基线依据

cc7c4e6 的 `src/gateway/client/GatewayToolResultArtifactStore.ts:31-42` 构造器执行 `resolve(options.rootDir ?? resolve(tmpdir(), "pilotdeck-tool-results"))`；`src/gateway/client/GatewayAgentEventProjector.ts:34` 在未注入 store 时调用该构造器。两处 `resolve` 在输入为相对路径或相对 `TMPDIR` 时读取 `process.cwd()`。

Node v22.22.0 原入口 10 格实测（每格独立子进程，import 在 chdir 前，删除 cwd 前不读 `process.cwd()`）：

- 相对 `rootDir` + cwd 已删除：构造器抛 `Error` / `ENOENT` / `ENOENT: no such file or directory, uv_cwd` / `uv_cwd`；相对 `rootDir` + 健康 cwd 解析为 `<root>/files/artifacts`，`cwdReads=1`。
- 绝对 `rootDir`（含 `//`、`.`、`..`）：健康与删除 cwd 均成功，`cwdReads=0`，词法归一化为 `<root>/files/artifacts`。
- 默认 root + 相对 `TMPDIR=../tmp`：健康 cwd 解析为 `<root>/tmp/pilotdeck-tool-results`，`cwdReads=1`；删除 cwd 抛同一 `uv_cwd` 错误。
- 默认 root + 绝对 `TMPDIR`：删除 cwd 仍成功，`cwdReads=0`。
- 先成功读取 cwd、随后删除该空目录：Node 用缓存 cwd 成功（相对 `rootDir` 与相对 `TMPDIR` 两格均如此），不读真实 cwd。

原始输出：本任务 `_tmp/20261026-issue-879/node-projector-probe/{raw.log,out/oracle.json}`；持久金样与生成器：`src/pilotdeck-gateway/tests/fixtures/projector-cwd/{oracle.json,generate.mts}`（含固定基线与源码 SHA256）。

## Rust 行为

`src/pilotdeck-gateway/src/runtime/turn/projector.rs`：

- `GatewayToolResultArtifactStore::{new,with_io,with_default_root}` 现在返回 `io::Result<Self>`；`build` 只对相对 `rootDir` 实时查询 cwd，失败以 Node/libuv 消息 `ENOENT: no such file or directory, uv_cwd` 返回并向上传播，不再回退到 `.`。绝对 `rootDir` 与绝对 `TMPDIR` 走词法归一化短路，不读 cwd。两条分支都按 TS `resolve` 归一化 `.`/`..`/重复分隔符。
- `node_temp_dir` / `default_artifact_root` 同样返回 `io::Result`；相对 `TMPDIR` 的 cwd 读取失败传播到 `with_default_root`。
- `GatewayAgentEventProjector::new` 返回 `ProjectionResult<Self>`；默认 projector 的构造错误以 `Error: ENOENT ...` 文本返回，由 `map_agent_event` 的调用方看到。
- `is_os_temp_dir` 仅用于 writer 允许 OS temp dir 自身符号链接的例外；cwd 读取失败按「不是该目录」处理（不构造路径），不改变文件写路径。

暖缓存场景中 Rust 仍无法恢复旧 cwd；本包把原来错误的 `.` 回退改为显式错误。缓存差异在本包之前已存在，**暖缓存失败输出并非保持不变**。本包不新增跨调用缓存、不修改其他路径入口。`io::Error` 只承载消息，不新增 TS Error 的 `name`/`code`/`syscall` 字段；直接调用者看到 `message()`，projector 边界看到 `String(error)` 形状。

## 范围

两类入口：`GatewayToolResultArtifactStore::new` 的显式 `rootDir`（相对/绝对 × 健康/删除，含相对暖缓存组合），以及 `with_default_root` 的 `resolve(tmpdir(), …)`（相对 `TMPDIR` 健康/删除、相对暖缓存删除、绝对 `TMPDIR` 删除）。健康 cwd、冷缓存错误与绝对路径格按真实 TS 结果验收。stats、metadata、file_history 属 #879 其他包，本包不改。

构造时机差异仅覆盖默认 projector：TS 的 `DEFAULT_PROJECTOR` 在模块加载时构造，若此时默认 root 失败则导入即 throw；Rust 在首次使用默认 projector 时构造并返回 `ProjectionError`，之后缓存同一错误。注入 store 的路径不受影响，且本仓当前生产接线尚未经该默认入口（A7 待接）。此差异不扩大为「任意时刻错误可见」的声明。

## 机器判据

TS 金样：`src/pilotdeck-gateway/tests/fixtures/projector-cwd/oracle.json`，生成器 `generate.mts` 每格独立 Node 子进程，recursive mkdir + `oracle.json` `flag:'wx'`。Rust 10 格：

`runtime::turn::projector_cwd_tests::{relative_normal_cwd,relative_deleted_cwd,relative_warmed_normal_cwd,relative_warmed_deleted_cwd,absolute_normal_cwd,absolute_deleted_cwd,tmpdir_relative_normal_cwd,tmpdir_relative_deleted_cwd,tmpdir_relative_warmed_deleted_cwd,tmpdir_absolute_deleted_cwd}`（源码模块 `src/runtime/turn/projector_cwd_tests.rs`，由 `runtime/turn/mod.rs` 声明，不经 `projector.rs` 的 `#[path]` 挂载）。

每格父测试经共享 bounded worker 在独立子进程改 cwd；父进程 cwd 不变。相对 TMPDIR 删除两格先直接核对 `node_temp_dir` 的 cwd 错误传播，再走 store 构造，避免 `build` 的第二次 cwd 读取掩盖 `node_temp_dir` 回退。暖缓存删除两格明确核对 TS 成功金样，同时要求 Rust 返回对应冷缓存金样的 `uv_cwd` 消息。worker 的所有可失败调用带 `#879 projector cwd matrix: <case>` 专属断言，最终断言 `negative_assert_eq!(..., "#879 projector cwd matrix: <case>")`。

负控 `src/pilotdeck-gateway/tests/fixtures/projector-cwd/negative_controls.py`：8 项（root/tmpdir cwd 回退、`uv_cwd` syscall、Rust Display、绝对 root/TMPDIR 误读 cwd、相对 root 基准、默认 root 目录名），经 `negative_suite.matrix_main` 逐项 HEAD-only nonce 回执判杀，绑定被点名测试与专属矩阵消息；锚点过期直接失败退出，不记为 SURVIVED。调用方必须设置 `CARGO_TARGET_DIR`；源码未提交即拒跑，不建影子仓库/备用构建目录。ignored `projector_cwd_regenerates_identically` 要求重生成后 oracle 字节一致。冻结账本检查：`python3 -I scripts/gateway-parity/check_frozen.py --base origin/main`。

## 批准记录
