## Rust 行为

`src/pilotdeck-gateway/src/runtime/session/owner.rs` 的 SessionEvictionSnapshot 保存 SessionContext（工具列表为 Vec），回调只借用快照；调用方可 clone 保存，不能通过回调借用修改 owner 或调用者的工具数组。记录从缓存移除并完成 disposal 后，按 on_evict → snapshot → on_session_idle_evict 顺序执行；失败的 snapshot 只省略 message_count；Rust unwind 被 catch_unwind 隔离，但既有 panic hook 仍可写 stderr（本包未修改全局 hook），TS 的 catch 不输出 snapshot 异常。

## 范围

涉及 callback 参数的所有权/可变引用及 snapshot panic 的 stderr，不改变 has_active_user_turn 的用户轮判定或只读诊断值。没有把数组 alias 行为加入 Rust；Always-On/诊断消费方接线留 A7.8。Rust 沿用 on_evict 回调不得 panic 的合同，catch_unwind 只隔离诊断 snapshot 的 unwind；panic=abort 和 callback panic 不属于可恢复 JS 异常映射。
