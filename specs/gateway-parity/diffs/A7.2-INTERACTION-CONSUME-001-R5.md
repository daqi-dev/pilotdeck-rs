## 类别

测试与负控补齐（更正 R4「范围」的负控覆盖缺口；无产品行为变更）。

## 基线依据

同 R4 的固定基线 cc7c4e6 / Node v22.22.0 与 72 格金样 `src/pilotdeck-gateway/tests/fixtures/sidecar-payload/`。DeepSeek r2（PR #847 复核 ③）指出：oracle 六条路由中 wire-final、terminal-reader、terminal-cancelled 没有 omit-* 负控。terminal 两路的私有 reader 语义即 R4 已引的 `agentLoopSidecarClient.ts` readFinalTerminal:1338-1350；`{}` 与各非对象坏 payload 在该 reader 走同一「无 AgentLoop result」分支、cancelled+compaction 原因两形态均合成 aborted、其余取消原因仍报错——Node v22.22.0 对基线实测，输出 `_tmp/20261026-issue-856/probe-standin.log`。

## Rust 行为

产品行为不变。`host/execution.rs::validate_event` 的 final 分支是 readFinalTerminal（含 assertTerminalResult）的 Rust 对应，本单仅把可见性放宽为 `pub(super)`（先例 `module_response`）供 host 测试回放：terminal-reader / terminal-cancelled 两路由 `host/tests/event.rs` 的 `sidecar_payload_terminal_reader_matches_ts` / `sidecar_payload_terminal_cancelled_matches_ts` 回放，非对象 payload 以 wire 可表示的空对象代替（真实 wire 仍在 decoder 前置拒非对象，由 wire-final 路回放，R4 已登记）。

## 范围

（同步 R4「范围」）缺失、undefined、null、boolean、number、string、array 与合法对象正控按 wire-event / wire-final / embedded-reader / terminal-reader / terminal-cancelled / host-bridge 六路由区分，且六条路由**全部**有 omit-* 负控：`sidecar-payload/negative.py` 把对应路由的 missing 用例 route 改名为 omitted，由各自回放测试的 replayed 计数击杀（wire 24、embedded/module/terminal 各 12）。两个私有 terminal reader 仍是诊断入口：Rust 的真实非对象 wire 输入在 decoder 前置拒绝，不新增绕过生产校验的入口。不涉及 #821 pump、心跳、身份或对象内容合法性，也不关闭 #589 / A7.2 实效验收。

## 机器判据

`sidecar_payload_wire_matches_ts`、`sidecar_payload_embedded_reader_matches_ts`、`sidecar_payload_module_matches_ts`、`sidecar_payload_terminal_reader_matches_ts`、`sidecar_payload_terminal_cancelled_matches_ts`、`sidecar_payload_bridge_continues_after_known_failure`；既有 `final_event_payload_shape_is_left_to_inner_handler`、`embedded_final_uses_js_truthiness` 与取消回归保留。`sidecar_payload_regenerates_identically` ignored 守卫重生成金样。`sidecar-payload/negative.py` 配对 wire、embedded、模块、桥及 final 委派变异，另加六条路由各自的 omit 变异；omit-wire-final 本会话实测 KILLED（其余两格提交后由协调者宿主执行，证据目录 RESULT.md）。
