## 类别

更正（范围：原条目「范围」节「不含 `/api/web/`」与 -R1「范围」节
「不含 `/api/web/`」自本件起作废）。#2354 已把 `/api/web/` 路由组接进
原生监听器（`src/pilotdeck-gateway/src/native_http.rs:144`
`serve_with_body` 的 `/api/web/` 分支 + `native_process.rs` 生产挂载），
该前缀自此**在**本条登记的 hyper 1.7.0 编解码后面，继承本条全部
帧级/头级呈现差异（头名 Title-Case、chunk 大小十六进制、裸 400 的
`content-length: 0`、HTTP/1.0 状态行）——api-web 组件侧的继承登记由
A8.4-API-WEB-001（及其 -R1 状态更正）承载，金样回放按同一组归一化
规则折叠后字节一致，`http10` 钉死为继承差异。approvals、module-host
维持不在本条范围（A8.4 后续包）。

## 基线依据

固定基线 cc7c4e653b15c8b2cec7bcf2d15d41d69396ae85，Node v22.22.0，
与原条目一致。TS 侧 `/api/web/` 与 `/health`、`/feishu/webhook`

金样（`tests/fixtures/api-web/oracle.json`）的原始响应字节沿用
原条目引用的实测。

## Rust 行为

`src/pilotdeck-gateway/src/native_http.rs:132` `serve_with_body`：
`config.api_web` 存在且路径以 `/api/web/` 开头时进入 api-web 分支
（`:144`），其响应经与 `/health`、静态回退同一 `finish`/编解码路径
写出，帧级/头级呈现与本条 4 项登记逐项相同；#1765 准入闸先于
route handler（解析层在路由层之前，与 Node llhttp 位置一致）。
`api_web: None` 保持 #2354 前旧面（每个非 gateway 监听器与冻结
夹具钉住的形状）。api-web 写路由在此入口读请求体
（`read_json_body`，`api_web.rs:349`），`/feishu/webhook` 之外新增的
体读取点；两侧均无预算（A8.4-API-WEB-003 另立登记）。
