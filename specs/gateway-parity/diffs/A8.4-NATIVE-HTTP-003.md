## 类别

平台语义登记（非 Rust-TS 差异，非对拍豁免）：#1209 金样 fixture
`native-http-basic` 的 `static-upper-lower` cell（`GET /upper.txt`，夹具只写
`upper.TXT`）是 88 cell 中唯一随宿主文件系统大小写敏感性改变结果的 cell。
macOS 默认 APFS（大小写不敏感）上 TS 与 Rust **一致地**把小写查找解析到
`upper.TXT` 并服务该文件；金样（Linux cb8 录制，大小写敏感）记录的是
index 回退。两个栈在每类宿主上行为一致，被登记的是**金样字节的宿主依赖**
与回放期望的运行时选择，不构成对拍豁免：任何未登记差异仍会被逐 cell
回放或钉死测试击落。

## 基线依据

固定基线 cc7c4e653b15c8b2cec7bcf2d15d41d69396ae85，Node v22.22.0（实测
`node --version` = v22.22.0）：

1. 金样录制侧（Linux，大小写敏感）：`oracle.json` 的 `static-upper-lower`
   cell 记录 `content-type: text/html; charset=utf-8` +
   `<!doctype html><html>index</html>`（`existsSync` 未命中 →
   `resolve(root, "index.html")` 回退）。
2. macOS 侧实测（本单 #1359，加载真实 `GatewayServer.ts`/`staticAssets.ts`，
   与 #1209 生成器同一 stub 布线；证据
   `_tmp/20261026-issue-1359/probe-macos.out`，不进提交）：
   - `GET /upper.txt` → `HTTP/1.1 200 OK`、
     `content-type: application/octet-stream`、体 `upper\n`（chunk `6`），
     与 `static-upper`（`GET /upper.TXT`）cell 的金样字节相同；连接不关。
   - 夹具事实：`root/` 恰 9 个文件 + `sub/`（`ls -la`）；
     `existsSync(root/upper.txt)` = true、`statSync(root/upper.txt).isFile()`
     = true（解析到 `upper.TXT`）；临时目录 `/System/Volumes/Data`（apfs）；
     大小写金丝雀：只写 `probe-case-canary.txt`，
     `existsSync(parent/PROBE-CASE-CANARY.TXT)` = true。
   - TS `staticAssets.ts:20` 的 `existsSync`/`statSync` 是 OS 级解析，
     无自有大小写规则。
3. 复现（macOS，本树 ccb4d838a）：修复前
   `native_http::tests::static_upper_lower` 稳定 FAILED（left 为 upper 文件
   字节，right 为金样 index 字节；证据 `repro-static-upper-lower.log`）。

## Rust 行为

`src/pilotdeck-gateway/src/native_http.rs` 未改（两侧在每类宿主一致）：
`serve_static` 的 `is_file(candidate)`（`tokio::fs::metadata`）与 TS 的
`existsSync`/`statSync` 同为 OS 级解析。改动只在回放测试
`src/pilotdeck-gateway/src/native_http/tests.rs`：
`expected_response` 对 `static-upper-lower` 这一个 cell 按
`serves_upper_txt(&fixture.root)`（用路由自己的 `is_file(candidate)` 同款
查找探测夹具根）在两类期望间选择——命中（大小写不敏感宿主）取金样
`static-upper` 的响应（与第 2 点 TS 实测逐字节一致），未命中（录制平台）
保持金样原样。运行时探测，不写死 `cfg`；其余 87 cell 的请求路径要么与
夹具文件精确匹配、要么无大小写变体可碰撞（`/HEALTH` 等路由比较在内存中
进行，不涉文件系统）。

## 范围

仅 `native-http-basic` 金样的 `static-upper-lower` cell 的回放期望选择；
不改生产实现、不改默认代理路由、不改 `oracle.json` 与 `generate.mts`
（金样是录制平台正本）。`regenerates_identically`（ignore 守卫）须在
录制平台上跑：在大小写不敏感宿主上重生成，该 cell 得到 upper 文件字节，
逐字节比较在该宿主不成立（fixture README 已写明；共享重生成机制不在本条
范围）。生产 `NativeWsServer` 恒回环、无静态根，不受影响。
