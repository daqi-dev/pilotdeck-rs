## 机器判据

更正后的 R2 复算命令（工作目录一律 workspace 根 `src/`，须设**绝对路径**
CARGO_TARGET_DIR——fixture 的 cargo 子进程以仓库根为 cwd

退出 0 不得充数——与 R3 复算段同款告诫）：
