## 类别

向安全偏离。首版与 R1 的范围写明「不提供对抗并发改写、特殊文件的沙箱」；#564 起 Rust 对这两类也加了防护，本更正把由此产生的对 TS 可观察差异补登，原条目其余内容不变。

## 基线依据

cc7c4e6 的 `src/extension/plugins/loading/PluginCommandLoader.ts`：`:89-99` stat 跟随链接，`:68` 按词法路径 readFile，枚举与读取之间不复核。真实 TS 金样 `src/pilotdeck-gateway/tests/fixtures/plugin-loader/toctou.json`（生成器 `generate-toctou.mts`）：检查后把叶 / 祖先换成指向根外的符号链接（leaf-symlink、ancestor-symlink）或换成根外文件的硬链接（leaf-hardlink），TS 读到根外内容 `SECRET`；`static-fifo` 时 TS readFile 阻塞（1000 ms 探针截止仍未返回）；`static-socket` 时 TS open 失败（`Unknown system error -102`，syscall open），整次加载被拒。

## Rust 行为

`src/pilotdeck-gateway/src/runtime/plugins/loader/markdown.rs` 的 `read_markdown`：读前 `symlink_metadata` 要求普通文件，非普通文件（FIFO、socket、设备）直接跳过；经 `project_files::open_beneath` 逐级 NOFOLLOW 打开，ELOOP / ENOTDIR 视为检查后有链接换入并跳过该条，其余打开错误按 TS readFile 传播；打开后对句柄 fstat，与检查时的 dev / ino 与类型不一致（含硬链接到其他 inode、改名换入）即跳过。安全的兄弟条目照常读取。

## 范围

插件 commands / skills / output-styles 与 style-only 的 Markdown 读取。可观察差异：① 检查后叶或祖先被换成根外符号链接、或叶被换成其他 inode 的硬链接：TS 读到根外内容，Rust 跳过该条；② FIFO `.md`：TS 阻塞，Rust 跳过、不阻塞；③ socket `.md`：TS 整次加载因 open 失败而被拒，Rust 跳过该条、保留兄弟。独立技能 SKILL.md 不在本条范围（见 #594）。仅 Unix；非 Unix 保持原按路径读取。
