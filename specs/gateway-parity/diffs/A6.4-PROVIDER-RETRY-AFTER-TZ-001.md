## 类别

有意保留的子集差异（本地解析只认已对拍 TZif 子集，子集之外按不可解析处理、不猜 UTC/宿主偏移），未批准，非已接受差异；不新增豁免、不改判分语义。#360 fix-r2 补登：该 provider 侧差异此前只在代码注释与 fixtures README 自我披露，且误引 stats-only 的 A6.4-STATS-RETENTION-001 当作登记依据（评审 P2-3）。

## TS 依据

固定 OpenBMB/PilotDeck@cc7c4e65（`src/model/protocol/errors.ts` 的 `parseRetryAfterHeader`），Node v22.22.0（V8 12.4.254.21-node.33）。`Date.parse` 的本地解析跟随进程时区，且在非 ICU TZ 标识的环境下不返回 NaN、继续解析：`TZ=unsupported-profile`、`TZ=:/nonexistent` 下与 `TZ=UTC` 同值（两台机器实测一致）；`TZ=localtime` 的结果宿主相关——存在 `/usr/share/zoneinfo/localtime`（符号链接到 `/etc/localtime`，Asia/Shanghai）的机器按本地时区解析（`Date.parse("Sun Nov  6 08:49:37 2033")` = `2014850977000`，cb8 实测），不存在该文件的机器回退 UTC（同输入 = `2014879777000`，fix-r3 在无该文件的 macmini-01 以 Node v22.22.0 / ICU 78.2 重跑核实）。原始输出见 `_tmp/20261026-issue-360/fix-r2/deliver/node-tz-probe-macmini-01.log`（fix-r3 重跑的机器原始输出与探针脚本；cb8 类宿主的 r2 原始日志未随远端树同步，其上海值以 r3 评审 cb8 实测转录为准）。

## Rust 行为

`runtime/model/http/errors.rs` 的 `retry_after_header`（#360-2 fix-r2 起）对无时区方言（asctime、无时区 ISO）的本地解析复用 `stats::admitted_local_to_utc` 门槛：三标识 allowlist（`UTC`/`America/New_York`/`Asia/Shanghai`）、未设 TZ 时 `/etc/localtime` 须为指向同名 profile 的规范链接、1 MiB 读上界、`tests/fixtures/stats-dateparse/local-profiles.json` 的 SHA 配对。子集之外（POSIX TZ、自定义路径、不可读、可读但未对拍字节、`TZ=localtime` 等宿主相关别名）一律按不可解析处理、忽略该 header；delta-seconds、显式时区、数字偏移、ISO date-only 不走本地解析、不受影响。该门槛接在 `retry_after_header` 本体，因此其全部下游共享同一行为。

## 范围

`retry_after_header` 的全部 Rust 消费侧（r3 评审 opus P2 修正：原「仅 provider HTTP」写窄了）：① provider 流重试（`runtime/model/http.rs` 读 `retry-after` header 处，TS 对应 `streamModel.ts:231`）；② 共享 `retry_after_header_ms` 的调用方——MCP HTTP 重试延迟（`runtime/mcp/http.rs`）、web 网络重试延迟（`runtime/tools/builtin/web/network.rs`，TS 对应 `network/fetch.ts:82` 经其自带的同语义 `parseRetryAfterHeader` 副本）、web fetcher 的 `retryAfterMs` 错误字段（`runtime/tools/builtin/web/fetcher.rs`，TS 对应 `urlFetcher.ts:292`，经 `web_fetch` 失败文案渲染为 `Retry-After: …ms.`）。stats JSONL retention 的同一 TZif 子集差异仍由 A6.4-STATS-RETENTION-001 的历史条目登记；本条不沿用其批准（该条人批范围仅 stats retention），也不改其冻结字节。生产后果：子集之外环境下，TS 会从本地方言得到一个（可能按 UTC 回退的）延迟，Rust 忽略该 header、退回 `decide` / 重试策略的指数退避；`maxDelayMs` 钳制与 delta-seconds 语义两侧一致。

## 机器判据

`runtime::model::http::retry_after_dialect_tests::retry_after_dialects_production_wiring_matches_node_zone_children`：`TZ=UTC` / `TZ=Asia/Shanghai` 子进程仅在宿主 TZif 与 `local-profiles.json` SHA 配对时回放该 zone 的 oracle 列；未配对时子进程打印可机检的 `#360-2 PARTIAL` 降级标记行、父测试整段回放子进程 stdout（`-- --nocapture` 下可见），并按 fail-closed 断言 `None`，不冒充 Node 对拍通过（fix-r3 P2-2）；负控检测到该标记即把 `production-local-wiring` / `zone-child-admission-false` 显式拒跑为 INVALID（fix-r3 P2-3）。`TZ=localtime`、`TZ=:/nonexistent` 与 `TZ=Europe/London`（非 allowlist 但可读）子进程断言本地用例为 `None`、时区无关用例等于 UTC 列，且对可读别名先断言无门槛共享解析器能解析宿主 profile——`None` 必须来自 allowlist 拒绝而非文件缺席（fix-r3 P2-3，同 stats `dateparse_zone_child` 的做法）。快速回放 `retry_after_dialects_match_node_in_two_timezones` 另 pin oracle 的 `node`/`v8`/`icu`/`tzdata` 原数据。负控 `production-gate-bypass`、`production-utc-fallback`、`zone-child-admission-false` 见 `src/pilotdeck-gateway/tests/fixtures/retry-after-dialects/negative_controls.py`。
