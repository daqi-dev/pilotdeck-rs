`config.api_web` 存在且路径以 `/api/web/` 开头时进入本组件，#1765 准入闸

assembly}.rs` 中 requests/services/assembly 本身未改，但原条目
「native_process 不受影响」的范围声明作废——生产装配路径经
`production_api_web`/`production_listener` 落在 `native_process.rs`。
