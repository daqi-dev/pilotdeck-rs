## 基线依据

可核事实（#1383 本单只引用 #1359 的既有原件，不重跑）：

1. `.github/workflows/ci.yml`（6 处）与 `.github/workflows/pr-gate.yml`
   （1 处）共 7 处 `runs-on` 全为 `ubuntu-latest`，没有任何 macOS job。
2. macOS（APFS，大小写不敏感）侧的实测来自**宿主实跑**而非 CI：macmini 上
   `test native_http::tests::static_upper_lower ... ok`、
   `test result: ok. 3337 passed; 0 failed; 205 ignored; 0 measured; 0 filtered out`
   （主仓原件 `_tmp/20261026-issue-1359/remote-host/host-lib.log`）。
3. cb8（Linux，大小写敏感）同一测试 ok、
   `test result: ok. 3336 passed; 0 failed; 204 ignored; 0 measured; 0 filtered out`
   （`_tmp/20261026-issue-1359/remote-host-cb8/host-lib.log`）。

引用边界：上述 macmini / cb8 实跑属 **#1359 的树与提交**（日志路径即在
`_tmp/20261026-issue-1359/` 下），不是 #1383 的 head。#1383 改过
`serves_upper_txt` 的探测实现（`root.join("upper.txt") + metadata` →
`node_join` + `contained` + `metadata`，`native_http/tests.rs`）；在
`roots()` 生成的夹具根（绝对路径、无 `..`、UTF-8）上两者等价
（`node_join(root, "/upper.txt")` 即 `root/upper.txt`，`contained` 恒真），
但本条引用该日志只用于证明**宿主平台的大小写不敏感行为**与「CI 无 macOS
job」，不用于声称 #1383 head 的 macOS 回放结果。

## 机器判据

金样 index 期望通过，证大小写敏感一侧；macOS（APFS）侧的大小写不敏感

static-upper-lower normalized response`）不变。
