## Rust 行为

#1552 后 `runtime/model/http/tls.rs` 的模式来自 `NODE_OPTIONS` 分词：`--use-bundled-ca` 优先于 `--use-openssl-ca`，缺省 `Default`。`Default` 与 `Openssl` 读显式 `SSL_CERT_FILE` 与 OpenSSL hash 命名的 `SSL_CERT_DIR`（文件名须为八位小写十六进制 + `.` + 非空纯数字，排序后逐个加载）；`Bundled` 不读这两者；`NODE_EXTRA_CA_CERTS` 在所有模式追加。OnceLock 一次性快照不变。原文剩余差异第 4 条（bundled 根数据版本）仍保留。

按源码构建口径，`dir-unflagged` 上 Rust 会比 TS 多信任该目录（TS false / Rust true），属扩大信任集合而非对齐；按 Homebrew 口径则是对齐。处置随 #1640 的口径裁决，本条仍为未批准差异。
