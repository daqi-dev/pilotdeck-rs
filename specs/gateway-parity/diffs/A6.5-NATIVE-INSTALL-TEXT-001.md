## 类别

交付入口适配；已知模型输入差异，未批准，非已接受差异。Rust 源码代不包含旧 npm/Node 安装器，给出其命令会使模型调用不存在的文件；本条披露修正引导带来的字节差异，不以安装器实现不同自动豁免模型输入对拍。

## 基线依据

固定 `cc7c4e653b15c8b2cec7bcf2d15d41d69396ae85`：`src/gateway/dialog/GatewayAttachmentTurnComposer.ts:95,129` 与 `src/extension/plugins/builtin/funasr/funasr-local-mcp.mjs:12` 默认安装命令是 `npm run install:asr`；`skills/audio-transcription/SKILL.md`、`skills/browser-use/SKILL.md` 和 `src/extension/plugins/builtin/browser-use/skills/browser-use-install/SKILL.md` 含 TS 安装器路径。原件身份分别在 `skills/upstream-assets.json` 的 `upstream` 字段及 `.builtin-plugins/browser-use/SOURCE.json` 保留；FunASR 固定 TS 真实 13 项协议采集位于 `src/pilotdeck-gateway/tests/fixtures/native-funasr-mcp/oracle.json`，原样期望不因本条改写。

## Rust 行为

`runtime/mcp/native_builtins.rs` 显示同代源码 `scripts/install-asr.sh` 或用户明确配置的安装命令；该脚本使用已准备的固定版本 FunASR/llama.cpp 源码和模型文件，在目标机编译并安装。`native_process/services.rs` 的附件引导指向工具的实际安装诊断。两项默认技能及 builtin 浏览器安装技能解释源码安装形态；浏览器使用已经准备的第三方 SDK 与浏览器绝对路径，不把配置当作安装完成。

## 范围

仅上述模型可见安装引导及缺运行时错误中的命令部分。其余工具名称、请求 Schema、参数、音频结果和错误语义仍按固定 TS 验证。本条不把第三方依赖缺失当成功，不修改 150 入口分母、评分器或固定 TS 金样；交付技能哈希只验证交付完整性。

## 机器判据

`src/pilotdeck-gateway/src/native_process/skills_packaged_tests.rs` 核对 109 项交付资产与实际技能消费；`src/pilotdeck-cli/tests/fixtures/native-source-install/consumer-driver.py` 检验安装代完整资产及默认读取。`runtime/plugins/builtin_priority_tests.rs` 检查实际优先级与明确的交付文本身份。`native-funasr-mcp` 固定 TS 真实采集与 Rust 13 项协议消费者保持独立。源码安装实测原件在 cb8 本任务树 `_tmp/core-finish/source-build/`，包括真实编译、安装后动态链接检查；仅模型占位文件的安装验证不等于真实语音识别通过。新整合头回归仍须补齐。
