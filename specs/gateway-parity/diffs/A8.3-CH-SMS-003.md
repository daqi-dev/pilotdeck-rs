## 类别

组件接线差异（待批）：#1339 的 sms channel 发送方向没有真实 Twilio
REST 客户端。生产 loader 挂载（`register()`）以 `twilio_factory: None`
构建，`start()` 固定走 TS 的「twilio not installed」告警 + no-op handle
分支；真实 REST 发送（TS `client.messages.create`）由后续发送端单补齐。

## TS 依据

固定基线 cc7c4e653b15c8b2cec7bcf2d15d41d69396ae85。
`SmsChannel.ts:12-17` 模块加载期 `require("twilio")`，失败仅置空；
`SmsChannel.ts:61-63` `start()` 检查工厂为空则
`error("sms: twilio not installed; run \`npm install twilio\`")` 并返回
无操作 handle；`SmsChannel.ts:82` 成功时 `twilioFactory(sid, token)`
构造 REST 客户端。

## Rust 行为

`src/pilotdeck-gateway/src/channel/sms/sender.rs`：`SmsSender` /
`TwilioFactory` 端口 + `SmsOutgoingMessage`，无具体 REST 实现；
`mod.rs` `start()` 工厂为 `None` 时记录同一句
`sms: twilio not installed; run \`npm install twilio\`` 并返回
`NoopHandle`（stop 解析 Ok、无 stopping 日志，与 TS no-op handle 对齐）。
`register()` 传 `None`，即生产挂载与 TS 未安装依赖的分支逐字节一致；
测试注入 mock 工厂 / mock 发送。

## 范围

仅发送方向与依赖装载机制；webhook 入站、签名校验、会话映射、
elicitation / permission / cron 流程全部照 TS 移植并经 oracle 回放，
不受本条影响。

## 机器判据

`src/pilotdeck-gateway/src/channel/sms/tests.rs`：oracle 用例
`start-twilio-init-failed` 钉注入工厂 `Err` 分支（`sms: twilio init
failed: ...` + no-op handle）；各 start 早退用例断言 no-op handle 的
stop 不打 stopping 日志；`send-fail` / `turn-*` 用例经注入 mock 发送端
钉发送序列。真实 REST 发送不在任何用例内（mock-only，本单范围即 mock
外部服务）。

## 批准记录

未批准，不增加判分豁免；登记于 #1339 交付评审；真实 Twilio REST
发送端另单接线前，生产 sms channel 保持与 TS 未装依赖时相同的行为。
