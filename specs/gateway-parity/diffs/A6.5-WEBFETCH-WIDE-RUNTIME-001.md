## 类别

不可避免（domino 2.2.0 在 V8 上的数组长度运行时差异，不是 HTML 树构建规则差异）。Rust 的 arena + 迭代转换不经过 V8 的 `Array`，也没有等价的可移植上限。

## 基线依据

固定基线 cc7c4e653b15c8b2cec7bcf2d15d41d69396ae85，真实 `getURLMarkdownContent`（`src/tool/builtin/web/urlFetcher.ts`）→ domino 2.2.0 解析 + 默认 Turndown 转换。输入与 `src/pilotdeck-gateway/tests/html_markdown.rs::reparented_wide_html` 相同：240 个属性各异的 `<b a=i>` + `<p>` + 重复 `<span>x</span>` + 补齐 `x` + 240 个 `</b>`，精确补至指定字节数，元素深度 < 256。

本轮 Node v22.22.0 / V8 12.4.254.21-node.33 实测（探针 `_tmp/20261025-issue-677/probe-wide.mts`，原始输出 `ts-wide-2mib.json`、`ts-wide-4mib.json`）：

- 2 MiB：成功，11,721 ms，Markdown UTF-16 长度 150,546，SHA256 `a360461eeb361385cc8c9c45d3a2400364f48794eb9afd18b0ab61b05ab0c829`；Rust 同输入逐字节一致。
- 4 MiB：14,980 ms 后 `RangeError: Invalid array length`，栈顶为 `@mixmark-io/domino@2.2.0/lib/Document.js:774` 的 `root()`（`n.ownerDocument._nodes[n._nid] = n`），经 `recursivelyRoot()` 递归触发。8 MiB 同错（历史修复轮 7 / 9 原值）。

## Rust 行为

`src/pilotdeck-gateway/src/runtime/tools/builtin/web/html_dom.rs` 的节点存放在 `Vec<Node>` arena，重挂子树只改链接与高度元数据；`html_markdown.rs` 的转换与渲染是迭代遍历。同一 4 MiB 输入成功返回 Markdown；8 MiB 也成功。`reparented_wide_four_mib_succeeds` 断言 4 MiB 成功，`reparented_wide_subtrees_stay_fast` 按无损重复规则检查 8 MiB 输出与性能预算。

## 范围

仅「240 个属性各异的 `<b>` 包围一个宽 `<p>`、再逐个 `</b>` 触发 domino adoption agency 重挂」这一输入形状及其 4 / 8 MiB 尺寸。TS 在约 3.25–3.5 MiB 之间首次抛错（历史二分区间 `(3,407,872, 3,670,016]` 字节，限本形状与运行时，不是通用阈值）；Rust 继续成功，属向宽差异。2 MiB 两侧逐字节一致；小于断点的其他形状不受本条影响。本条不覆盖 `A6.5-WEBFETCH-DEPTH-001` 的深度向严差异，也不覆盖已对齐的 select/hr、search、select 内元素家族（见 `_tmp/20261025-issue-677/RESULT.md` 与 `src/pilotdeck-gateway/tests/html_markdown.rs::parser_version_gaps_match_real_ts`，99 条真实 TS 样例全部通过）。

## 机器判据

- `src/pilotdeck-gateway/tests/html_markdown.rs::reparented_wide_four_mib_succeeds`：同一配方 4 MiB 的 Rust 转换必须成功；把转换改回返回 TS 错误时失败（负控见 `_tmp/20261025-issue-677/RESULT.md`「负控」）。
- `src/pilotdeck-gateway/tests/html_markdown.rs::reparented_wide_subtrees_stay_fast`：8 MiB 输出必须等于 `**`×240 + `x`×598,972 + `**`×240 的无损重复规则，并在预算内完成。
- `large_shallow_pages_match_real_ts_bytes_and_stay_fast` 与 `large-oracle.json` 的 `reparent-wide-2mib` 钉住 2 MiB 真实 TS 完整输出的逐字节一致，证明差异只从更大尺寸开始。
- 真实 TS 原始输出与复算探针：`_tmp/20261025-issue-677/ts-wide-2mib.json`、`ts-wide-4mib.json`；重跑命令见 `RESULT.md`。
