## 类别

差异消除（连接生命周期·HTTP/1.0 帧化）。本条更正 R2「HTTP/1.0 的偏差」段
的口径：R2 写「Rust 现在与 Node 实测的可观察行为一致（`Connection:
close`，不复用）；响应行仍是 `HTTP/1.0` 而 Node 回 `HTTP/1.1`」，读作 1.0
仅剩状态行一项差异。实测并非如此——1.0 响应的**帧化**当时也差着：Node 的
1.0 回复（store 形态 `response.end(buffer)`，`_storeHeader` 决策时看不到
隐式 Content-Length，且 1.0 的 `useChunkedEncodingByDefault` 为 false）是
close 定界，**不带 `content-length`**；Rust 侧 hyper 知道 body 的精确长度，
在 1.0 回复上写了 `content-length` 行。该差异真实、可测，已由 #1947
（commit `53c04ac5f`）修掉；修后 1.0 才真的只剩状态行差异，R2 的口径至此
成立。

## 基线依据

- R2 自身的聚焦探针已给出 Node 侧依据（`_tmp/20261025-issue-679/fix-r2/
  probe/http10_focus.mjs`，输出 `node-http10-focus.out.txt`）：`res.
  shouldKeepAlive` 为 true 但 `_storeHeader` 在 keep-alive 决策时还看不到
  隐式 Content-Length（TS handler 只设 content-type 后
  `response.end(buffer)`），1.0 的 `useChunkedEncodingByDefault` 为 false，
  于是写 `Connection: close`——同一机制也决定了 1.0 回复**不写
  `content-length`**，体到连接尾。webhook 车道的同形态差异已由
  `A8.3-CH-WEBHOOK-004` 登记（close 定界、无长度行）；本条是 http_store
  车道的对应面。
- Rust 侧修前字节由开关 `http-store-http10-framing-off` 反证：恢复
  `size_hint` 的精确上报后，1.0 回复重新长出 `content-length` 行，
  `http_10_requests_close_like_node` 的整头集合断言变红——即修前 Rust 的
  1.0 回复带长度行、非 close 定界。负控本宿主复跑（2026-11-11，
  `_tmp/20261110-issue-1608/negctl-1947-httpstore/`）：KILLED。

## Rust 行为

`src/pilotdeck-gateway/src/user_dialog/http_store.rs`（commit `53c04ac5f`）：

- `KeepAliveBody` 增加 `unknown_size`：响应 map 时按
  `version == Version::HTTP_10 && !crate::mutants::on("http-store-
  http10-framing-off")` 决定；`size_hint` 在 `unknown_size` 时返回
  `SizeHint::default()`（未知），hyper 因此不写 `content-length`，1.0
  回复 close 定界、体到连接尾。帧与 end-of-stream 标志不变。
- 1.1 路径不动：`size_hint` 保持精确上报，`content-length` 照写。

同族收口（commit `cc1e59dd9`）：module_host finalize 的 1.0 包改 `Unsized`
（provider 值体不再带 `content-length`，streamed 体无变化），
native_http 的 webhook 分支窄包 `Unsized`，并在四个兄弟车道的
`http10_close_delimited_response` 测试补 `content-length` 缺席断言
（module_host / approvals / api_web / native_http）。

## 范围

仅 HTTP/1.0 响应的帧化：长度行缺席、close 定界。状态行仍回 `HTTP/1.0`
（Node 回 `HTTP/1.1`）——这是 `A8.3-CH-WEBHOOK-004` 已登记的 hyper 版本
回写差异，http_store 车道同族，维持 R2 的「不改也不新登」。连接复用、
空闲期限、keep-alive 广告头与 shutdown 交错分别归 R2/R3/R4，本条不重登。
`A7.4-HTTPSTORE-KEEPALIVE-001-R2:147` 的段落以本条为准。
