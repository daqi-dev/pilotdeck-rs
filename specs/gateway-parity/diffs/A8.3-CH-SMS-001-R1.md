## 机器判据

更正后的覆盖形状（`tests/fixtures/channel-sms/`，均可机检）：22 个
`crate::mutants::on("sms-…")` 编译期开关中，18 个绑定 17 个 oracle 重放
cell（`valid-signature` 由 `sms-twiml-body` 与 `sms-signature-key-order`
双绑），4 个绑定重放表外的专属测试（`json_null_body_is_unhandled_destroy`
、`logger_panic_does_not_poison_boundaries`、`port_busy_preflight_fails_fast`
、`oracle_case_count_is_recorded`）。全部 55 个 oracle cell 每次运行都
与 `oracle.json` 记录逐字节比较（正控）；无专属开关的 cell 依赖该字节
比较钉漂移，不声称每个 cell 各有 KILLED 开关。用例计数由
`EXPECTED_CASE_COUNT = 55` 在生成器与重放测试双侧断言（开关
`sms-oracle-declaration-count` 变异 +1 即被 `oracle_case_count_is_recorded`
击落）；`negative_controls.py --check` 钉 22 个开关与绑定文件唯一锚点。
