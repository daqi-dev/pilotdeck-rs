## 类别

#1082 fix-r2 修复 R5 同线程跨代 Drop 可能自锁的问题，补显式 close 的争锁格并加强 Drop 判据。R5 原字节保留；不改评分、阈值、分母或归一化，不增加已接受差异。

## 基线依据

固定 cc7c4e6 / Node v22.22.0，复用 R5 的真实 serial、threaded 与 lifecycle 12 格。本次新增同 fixture 的 `closeCallbacks`：在真实 MemoryRepository.insertL0Session 的 nowIso/toISOString 边界关闭另一代，分别正常返回、抛错、另一数据库。输出包括钩子进入次数、抛错、行 ID 及后继读写。TS 无 Rust 的公开原子 predicate API，也无 Arc 最后 owner 的 Drop；只比较可见结果，不把 Rust 锁内部事件当作 TS 行为。提前返回格仅为 Rust 原子 predicate 的 RAII 清理回归，不宣称有 TS 同形 API。

## Rust 行为

公开 `insert_l0_session_if_new` 的 predicate，以及 insert/trace/settings 的注入 clock，会在 ConnectionGuard 存活时运行。默认 heartbeat predicate 目前只比较数据，但公开 API 可以捕获并释放同根另一代最后 owner；旧实现在真实公开回调测试中发出自竞争事件，随后会永久阻塞。

每个共享锁增加线程本地持有标记及 ProcessGuard：同线程跨代重入复用外层锁，Drop/close/SQL 调用保持同步；仅最外层 guard 移除标记并解锁。ConnectionGuard 仍先释放 connection mutex 再释放 process mutex，poison 恢复保留；其他线程继续严格串行。回调正常返回、提前返回、panic、连续两个 peer、显式 close 后立即再次 close，以及不同数据库均有用例。对同一个 storage 自身 connection mutex 的递归调用是原有边界，本条不宣称修复。

## 范围

只适用于同 rootDir 多代 EdgeClaw SQLite storage 的进程内串行化与跨代析构重入；对同一个 storage 自身 connection mutex 的递归调用是原有边界，本条不宣称修复。

## 机器判据

R5 所列 8 个 storage 用例及 12 个 lifecycle 用例保留。`runtime::memory::edgeclaw::storage::same_root_tests::` 新增：

- `same_root_close_serializes_with_in_flight_write`
- `same_root_drop_from_locked_callback_completes`
- `same_root_drop_from_locked_callback_early_return`
- `same_root_drop_from_locked_callback_unwinds`
- `same_root_close_from_locked_callback_is_synchronous`
- `other_root_drop_from_locked_callback_completes`
- `same_root_reentrant_guards_preserve_outer_owner`

显式 close 必须观测 CloseContended；隐式 Drop 必须观测 DropContended、DropClosed，并核 repository Weak 失效。try_lock 的 WouldBlock 才发争锁事件，禁止通用 conn() 事件代替 Drop 证据。回调复现收到自竞争事件后直接失败，不以挂起超时判杀。握手、completion 和 join 上限均 5 秒，异常清理不无界 join。

`edgeclaw-same-root-generation/negative.py` 从 13 增为 17 个预编译开关：新增 close-unserialized、reentrant-lock-blocking、inner-releases-owner、stale-thread-owner；Drop 既有开关改绑专属断言。使用同一个 feature binary、调用方 CARGO_TARGET_DIR，不改源码、不另建仓库。逐项正控/负控/恢复及最后汇总沿用共享执行器。完整名与专属失败消息以 switches 表为正本。既有 ignored `same_root_generates_identically` 同时覆盖新增金样节。
