## 类别

bug 修复：补齐 HTTPS 代理的 TLS CONNECT，消除非 http 代理静默直连。

## 基线依据

TS `src/cli/proxy.ts:122-145`、`undici/lib/dispatcher/proxy-agent.js:166-214`（cc7c4e6）。真实 import 的 22 场景金样见 `src/pilotdeck-gateway/tests/fixtures/mcp-proxy-schemes/oracle.json`；原始输出 `_tmp/20261025-issue-676/ts-wire/https-stream/`、`https-sse/`、`https-auth/`、`https-untrusted/`、`https-reject/`。

## Rust 行为

`runtime/model/http.rs` 的 `ProxyConfig::tunnel` 使用已锁定的 tokio-rustls 0.26.6（MIT OR Apache-2.0）对代理校验证书并建 TLS，在其上 CONNECT，再按目标 scheme 建目标 TLS。有效代理的真实 wire 与目标收据已对齐；未经信任的代理和 CONNECT 拒绝均失败，不直连。

## 范围

共享连接器覆盖 MCP streamable/SSE、model、count、hook。CA 使用现有 roots 配置，本条不改变已有 CA 加载政策；错误诊断字符串不声称全面一致。旧条目“HTTPS 不支持而直连”的结论被本条更正。

## 机器判据

`tests/mcp_proxy_schemes.rs::replays_ts_proxy_schemes`（22场景）；`runtime/model/http.rs` 代理来源/非法URL/无直连/超时单测；`runtime/model/proxy_socks.rs` 协议应答单测。真实TS两次复采一致；负控删协议支持、恢复非法直连、禁用config补装及协议校验/默认端口变异均须测试转红并逐字节还原，原始证据 `_tmp/20261025-issue-676/negative-controls.json`。定向测试与全量lib/fmt/clippy/frozen结果见 `_tmp/20261025-issue-676/RESULT.md`。
