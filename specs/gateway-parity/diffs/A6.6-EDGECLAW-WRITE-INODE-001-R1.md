## 类别

更正：原条目 `:25` 将 `read_at` 与 `regular_files_at` 合并描述为「祖先不可达（EACCES/ENOTDIR）按 TS existsSync 吞掉化为 ENOENT」，v2 修复轮（3f4b2721）后两函数在叶阶段行为一致，但 v2 同步提交并未对 read_at 补叶阶段 statat 探针；修复轮 gate9（P1×2）发现该遗漏，fix 轮（本 PR 当前 HEAD）已补全并回写此更正。另：原条目 `:26` 对 `read_dir_files` 的描述「`read_dir_files`（`:888`）」未反映 v2 收窄为 NotFound-only 的事实（v1 起是吞 PermissionDenied|NotADirectory，v2 补丁回退为 NotFound-only，消费者改由 `regular_files_at` 叶 statat 探针区分祖先不可达与叶不可读）。

## 基线依据

TS existsSync（cc7c4e6 `node/fs.js`，`try { fs.accessSync(path) } catch { return false }`）对不可搜索祖先返回 false；readFile（同版本）在祖先不可达时抛 ENOENT/EACCES，父目录可搜索但文件本身 mode 000 时抛 EACCES。测试负控实测：`mutation_read_inaccessible_parent_is_none`（parent mode 0o600 → None，与 existsSync false 一致）；`mutation_read_unreadable_leaf_keeps_open_error`（parent 可搜索、leaf mode 000 → EACCES 保留，与 readFile 一致）。

## Rust 行为

`src/pilotdeck-gateway/src/project_files.rs`（`#[cfg(unix)]`）：

- `read_at`（fix 后 `:320`）叶 openat 返回 EACCES/ENOTDIR 时，用 `statat(&parent, name, AtFlags::SYMLINK_NOFOLLOW)` 探测叶是否存在：探针失败（祖先不可达）→ 映射为 ENOENT（无文件）；探针成功（叶存在但父不可搜索或叶本身不可读）→ 保留原 EACCES 错误经 `leaf_open_error` 上报。与 `regular_files_at` 叶阶段（`:399-408`）行为对齐。macOS `O_SEARCH` 在 `walk_beneath` 阶段即映射为 ENOENT，探针在 macOS 上不改变结果，为 no-op。
- `file_memory.rs` `read_dir_files`（`:888`）：v2 起仅吞 `NotFound`，不再吞 `PermissionDenied | NotADirectory`；祖先不可达由 `regular_files_at` 叶 statat 探针映射为 ENOENT → read_dir_files 解读为「无文件」返回空列表；叶目录本身不可读（EACCES）由探针确认存在后保留错误，read_dir_files 按原有路径上报。

## 范围

- 仅修正原条目 `:25`（`read_at` 叶阶段描述）与 `:26`（`read_dir_files` 消费者描述）。
- 写侧（`overwrite_at`）、`walk_beneath` 走向层、FIFO/硬链接/符号链接竞态场景描述不变。
- Linux 独有：macOS 上祖先不可达在 walk 阶段即报 ENOENT，不经叶 statat 探针路径；非 Unix 路径（`#[cfg(not(unix))]`）不受影响。

## 机器判据

- `mutation_read_inaccessible_parent_is_none`：parent mode 0o600 + `store.core.read_file("Project/blocked/note.md")` → `Ok(None)`。
- `mutation_read_unreadable_leaf_keeps_open_error`：parent 默认权限、leaf mode 000 + `store.core.read_file("Project/note.md")` → `Err` 含「EACCES」且含「open」。
- 两测负控：去掉 `read_at` 叶阶段 statat 探针后，`mutation_read_inaccessible_parent_is_none` 在 Linux 上转红（macOS 因 walk 阶段即 ENOENT 不变红）。
- 复算命令：`cargo test -p pilotdeck-gateway mutation_read`
