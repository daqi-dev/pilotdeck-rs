## 类别

追加登记（范围收口）：#2455 / #2456（P2-跟进，p2batch-c1 批次）处置时实测
发现的两个邻接残余，均在原条目及 -R1 / -R2 覆盖的写路径表面内，本件登记
其存在与不追平口径；同批已**修复**两个命名格（#2455 代理对跨界截断、
#2456 缺根 + `path: "."`），并更正 -R2 的一处范围表述（见「范围」）。
原条目及 -R1 / -R2 的全部其余技术结论不变。

## 基线依据

固定基线 cc7c4e653b15c8b2cec7bcf2d15d41d69396ae85，Node v22.22.0，与原条目
一致。两格的 TS 侧实测（原始输出在案）：

- **残余一（#2455 邻接，输入孤立代理 + NUL）**：请求体
  `{"path":"a\ud83d\u0000b.txt"}`（JSON 转义送入孤立高代理）。TS
  `writeFile` 的参数校验 inspect 的是**原始 JS 字符串**，孤立代理渲染为
  ASCII 转义序列——响应体 message 为纯 ASCII：
  `…Received '<root>/a\ud83d\x00b.txt'`（hex 尾
  `…615c75643833645c783030622e74787427`）。实测
  `_tmp/20261108-p2batch-c1/s2-ts-probe/probe-adjacent-output.txt`。
- **残余二（#2456 邻接，根为既有普通文件 + `path: "."`）**：项目根本身
  已是普通文件（例如同 key 第一次缺根 `path: "."` 写建出的文件）时，TS
  第二次写 `{"path":".","content":"y"}` 答 200 `{"ok":true}` 并覆盖该文件
  （实测 size 1）。实测
  `_tmp/20261108-p2batch-c1/s3-ts-probe/probe-root-as-file-output.txt`。

## Rust 行为

- **残余一**：`api_web.rs` 写分支的 JS-to-fs 边界
  （`String::from_utf16_lossy(path.units())`）先于服务调用把输入的孤立
  代理折成 U+FFFD（对 fs 落盘本身与 Node 一致：Node 的 fs 边界同样替换，
  实测同文件 B 格 `62efbfbd632e747874`）。于是 `null_byte_refusal` 的报文
  inspect 的是 FFFD 替换形，携带原始 U+FFFD 字节（`efbfbd`），而非 Node 的
  ASCII `\ud83d` 转义。修复需把原始 UTF-16 units 穿过
  `write_file` → `node_normalize` → 拒绝渲染整条管道（units 版
  `node_normalize` / `resolve`），修法无界，登记不追平。
  #2455 的命名格（128 单元截断切开**代理对**产生的孤立代理）不属本残余：
  该格已由 `FilesError::MessageUnits(JsString)` + `error_body_units`
  （`quote_json_string` 的 well-formed `\ud83d` 转义）按 Node 字节修复。
- **残余二**：armed 走查的根 open（`open_directory_beneath`）对普通文件根
  答 `ENOTDIR … open '<root>'` 500。落在原条目「项目根本身是普通
  文件……诊断落在根路径上」的登记范围；但原条目把该格 TS 侧描述为「报的
  是目标路径的 `mkdir`」，对 `path: "."` 子格不成立（该子格 TS 实测为
  200 覆盖，mkdir 落在根**外**祖先上必成功），本件更正该描述并确认该格
  维持不追平。#2456 的命名格（**缺根** + `path: "."`）不属本残余：该格
  已由 `write_root_itself` / `create_root_file` 按 Node 语义修复（祖先建
  目录、根本身由写的 open 建为普通文件、答 200）。

## 范围

仅上述两个邻接格的登记与一处 TS 侧描述更正，不改任何判分语义、阈值或
负控绑定。更正 -R2 的范围表述：其「`path: "."` 一类落在钉住根本身的
形态由空 beneath 特判以同一 Node 文案拒绝」自本批起仅对**既有**根成立——
缺根形态已按 Node 修复为建文件答 200，不再是 EISDIR 形态（-R2 文件按
冻结规则原字节不动，以本件为准）。既有根（目录）的 EISDIR、根内目录链接
目标的字面路径报文等 -R2 结论全部维持。
