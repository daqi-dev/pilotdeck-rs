- Issue: #1841（`test(parity) 严格比较器把 context.budget 与 model.request/response 的先后竞态

- 理由: 录制侧（消息循环）调度竞态使 `context.budget` 偶发出现在 `model.request` 之前 /
  夹在 request 与 response 之间。native（TS 宿主录制）**75/75 稳定** request→budget；sidecar 侧
  75 轮/侧里 **15 轮偏离**（Rust 8、TS 7，两侧都踩 → 不是 Rust 产品缺陷）。所有偏离轮 G03
  配对全部 PASS（issue 正文已证），但严格比较器（`run.py` 的 native↔sidecar 比对，
  `run_py_exit` 报告）把位置竞态记成语义差异，读报告的人会把采集噪声误当产品缺陷重开排查
  ——#19 收口时它就是这样被提出来的。
